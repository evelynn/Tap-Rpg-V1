원본 크기는 대부분 **1254×1254 RGBA**, 걷기 12는 **1448×1086 RGBA**다. 32/48px는 미리보기의 표시 크기다. 네이티브 32/48px 시트 또는 indexed PNG로 오인하지 않는다. 콘텐츠 ID 대응은 [ASSET_MAP.md](ASSET_MAP.md), 원래 기본 48색은 [palette.reference.json](palette.reference.json)을 참고한다. 팔레트 파일은 명세에서 추출한 참고값이며 생성 이미지가 준수한다는 뜻이 아니다.

`items_ui_draft.png`, `fx_camp_draft.png`는 수정 전 비교 자료다. 미리보기는 v02를 사용한다. 이미지 수정은 내장 ImageGen으로만 수행했고 원본 파일을 그대로 복사했다. 별도 CLI/API는 사용하지 않았다. 프롬프트는 `prompts/`의 생성 8건과 수정 2건이다.

## 미리보기

`preview.html`을 브라우저로 연다. 서버·설치·게임 실행은 필요 없다.

- 39개 동작 선택, 32/48px 표시, 0.25~2배속.
- 일시정지·이전/다음 프레임·탐색 슬라이더.
- 배경 4종, 좌우 반전, 발 위치 정렬.
- 기본 창 520×64를 2배 확대해서 표시하고 별도 확대 창을 제공한다.
- 단발 동작 반복은 **검토용 옵션**이다. 게임의 공격 반복 규칙이 아니다.
- 발 정렬은 표시 좌표만 보정한다. 원화의 접지·몸 크기 문제를 수정한 것은 아니다.
- 접근성의 동작 줄이기 설정이면 처음에 멈춘다.

`atlas.preview.json`은 **이 미리보기 전용 좌표·시간 자료**다. 실제 콘텐츠 팩이나 캐릭터 `.anchors.json` 계약으로 사용하지 않는다. 미리보기는 게임 파일·저장 파일에 접근하지 않는다.

## 검수 결과와 한계

**출시용 검수는 미통과다.** 동작이 자연스럽다는 최종 판정도 아직 하지 않았다.

| 항목 | 결과 |
| --- | --- |
| 이미지 파일·디코딩·해시 | 검사함. 선정 8장, 지정 384칸 모두 비어 있지 않음. |
| 알파 채널 | 배경 외 7장에 실제 투명 픽셀이 있음. 캐릭터·적에도 반투명 가장자리와 반투명 내부 픽셀이 있어 명세 불충족. |
| 팔레트·색 수 | 명세 상한 캐릭터 20색·일반 적 12색 미충족. RGBA 색 수와 반투명 픽셀 수를 실측 파일에 기록. |
| 셀 규격 | 1254는 8로 나누어떨어지지 않는다. 미리보기는 156/157px 구간을 정수 좌표로 잘라 표시. 최종 고정 격자 아님. |
| 셀 넘침 | 기본 캐릭터·일부 적·보스 파동 등에서 경계 접촉/겹침 위험. 자동 경계 검사 값은 선별 지표이며 프레임 합격 판정이 아님. |
| 레이어 | 현재 합성 캐릭터. 몸체·얼굴·머리·방어구·무기 분리 및 손/머리 앵커 없음. |
| 동일성·연결 | 손·무기 각도, 얼굴·머리 비율, 걸음 연결에 흔들림이 남는다. 가죽복장 차이도 더 뚜렷하게 해야 한다. |
| 장비 정확성 | A07 후보가 은색 판금으로 나옴. 원래 ‘종소리의 청동 흉갑’에 맞춰 청동색과 형태 수정 필요. |
| 배경 | 4개의 합성본. 3층 패럴랙스, 무봉제 이음, 낮밤/계절 LUT, 13지역 변형은 미제작. |
| 대비·실사용 | L* 대비와 실제 모니터 100/125/150% 사용자 시험 미실시. |
| 브라우저 재생 | 연결 가능한 브라우저가 없어 자동 화면·시간 재생 검증 미실시. 정적 참조·스크립트 문법·이미지/시간 데이터는 검사. |

**생성 프레임을 균등 속도로 나열하는 것만으로 자연스러운 동작이 완성되지는 않는다.** 다음 작업은 원화 확장이 아니라 걷기·공격의 접지와 동일성 보정이 우선이다.

## 다음 제작 우선순위

1. **실사용 기준 캐릭터 1종**: 32/48 각각 네이티브 픽셀로 정리. 대기 8, 걷기 12, 공격 8부터 기준선·색·실루엣을 고정한다. O02 사용자 비교 시험 후 크기를 결정한다.
2. **레이어·장비**: A01/A02와 W02/W03의 같은 동작을 분리 제작하고 손잡이 정렬, 겹침, 좌우 반전을 검수한다. 26개 아이콘은 장착 레이어를 대체하지 않는다.
3. **생활 동작**: 식사·잠·독서·상호작용·환호·쓰러짐을 기준 캐릭터에 맞춰 정리한다.
4. **적 전투 세트**: 4계열의 대기·피격·달아남을 추가하고 EN01~EN10/EB01~EB02의 팔레트·소품 변형을 만든다. 일반 적 퇴장은 시체가 아니라 도주다.
5. **배경·효과**: 마을/들판/폐광의 3층 타일 9장 + 틈 먼 층 1장, 13지역 변형, 4계절·낮밤 변환. 효과는 셀 밖 빛 번짐을 제거한다.
6. **생애·UI**: 노화 4단계, 흡혈귀, 전문화, 머리 6종, 방어구 3계열, 무기 6외형, 초상 72장, 정식 UI 아이콘 42개 및 책 UI를 완성한다.

원래 아트 명세의 움직이는 그림 **592프레임**은 44프레임 몸체 기준의 전체 레이어 합계다. 이번 316칸과 직접 진행률을 계산하면 안 된다. 몸체 프레임을 늘리면 방어구·망토·무기·소품의 대응 프레임도 함께 늘어난다.
