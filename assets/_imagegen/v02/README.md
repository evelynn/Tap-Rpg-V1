# ImageGen v02 — 생성 원본과 프롬프트

2026-09-23. 사용자의 제작 방식 정정에 따라 **코드로 그림을 만드는 작업을 중단하고, 내장 ImageGen으로 생성·편집한 결과**다. 게임 소스와 `docs/art` 원문은 이 작업에서 수정하지 않았다.

`ASSET_REVIEW_v01.md`, `ASSET_ORDERS.md`, `ASSET_BACKLOG.md`의 형태·색·동작·금지 사항을 이미지 생성 프롬프트에 반영했다. 아래 세 장은 **검토용 생성 시안**이다. P0 전체 완료나 게임에 바로 넣을 수 있는 정본으로 판정하지 않는다.

## 프롬프트에 반영한 핵심

- 2.2등신, 짧은 밤색 HR01 머리, 오른쪽을 보는 캐릭터, 동일한 얼굴과 옷 유지.
- 제한된 색과 큰 픽셀 덩어리, 외곽선, 흐림·글로우·그라데이션·장식 배경 금지.
- 걷기: 접지·내려앉음·지나감·접지 직전의 12단계, 반대쪽 팔과 다리 움직임, 한 주기 660ms.
- 공격: 준비 → 머리 위 → 전방 위 → 수평 타격 → 아래로 따라감 → 복귀. 타격 뒤 다시 들어 올리지 않기.
- 앉기: 서 있을 때보다 낮은 높이와 고정된 엉덩이. 잠: 가로로 눕고 가슴만 미세하게 움직이기.
- 들쥐: 볼주머니, 둥근 귀 두 개, 긴 꼬리, 왼쪽 기본 방향. 마지막은 도토리를 안고 도망가기.

## 확인 결과와 남은 차이

이미지의 포즈 수와 행 구성을 눈으로 확인했다. 캐릭터와 들쥐의 외형, 공격의 손 위치 순서, 앉기·잠의 실루엣 대비를 검토할 수 있다. **실제 애니메이션 재생의 자연스러움은 검증하지 않았다.** 프롬프트의 시간 값은 재생 파일이 아니다.

| 파일 | 실제 크기 | 실제 형식 | 완전 투명 / 반투명 / 불투명 화소 수 |
| --- | --- | --- | --- |
| 걷기 | 1536 × 1024 | RGBA | 918,038 / 654,826 / 0 |
| 들쥐 | 1448 × 1086 | RGBA | 1,108,503 / 461,659 / 2,366 |
| 대기·공격·앉기·잠 | 1536 × 1024 | RGBA | 1,013,176 / 559,688 / 0 |

배경의 알파 0은 확인했으나 본체·테두리에 중간 알파가 남았다. 따라서 문서의 **PNG-8, 알파 0/255, 정확한 색 수와 지정 HEX, 네이티브 32/48 셀** 조건은 아직 충족하지 않는다. 생성기의 큰 출력물을 정확한 48px 원본으로 간주하지 않는다.

캐릭터 두 장은 외형과 동작을 보는 **합성 시안**이므로 몸체·얼굴·머리·옷·무기·책이 분리되어 있지 않다. AO-02 몸체 시트, AO-11 앵커, AO-16 무기 시트의 대체품이 아니다. 걷기도 AO-03 정본의 1행 12열 대신 생성 검토용 6열 2행이다. 각 포즈의 기준점·칼 길이·루프 이음·프레임 간 실루엣 차이는 수용 판정 전이다.

다음 제작 대상은 분리된 몸체·얼굴·머리·장비 이미지, 두 규격 비교용 시트, 들판 배경이다. O02의 실제 참가자 시험과 P1은 수행하지 않았다.

## 작업 구분

- 이 폴더의 PNG: 내장 **ImageGen**으로 생성하거나 편집한 이미지.
- `*-draft.png`, `*-attempt.png`: 편집 과정을 남긴 중간본. 최종 검토 대상은 위 표의 세 장.
- 앞서 `assets/_tools`와 `assets/sprites`에 만든 프로그램·그 결과는 사용자가 지적한 이전 제작 방식의 산출물이다. 이번 ImageGen 결과와 섞지 않았고, 사용자 요청 없이 삭제하지 않았다.
- 별도의 API/CLI 이미지 생성이나 외부 게시·전송은 하지 않았다.
