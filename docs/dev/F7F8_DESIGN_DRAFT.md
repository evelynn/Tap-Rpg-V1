## 1 F7 가호 (D77 후보)

### 1.1 기본 모양 (권장)

- **이름**: 행위는 `가호`, 모아 두는 것은 `별빛`(세계관 02 §1.2 "신비는 설명하지 않고 보여준다", 틈에서 새는 별빛과 맞춘다). 인물은 알아채지 못한다.
- **두 가지 쓰는 법** — 팝업 없이 쓰기 위해서다.
  - **걸어 두기**: 사용자가 상세 창에서 미리 걸어 두면, 조건이 오는 첫 순간에 저절로 발동한다(치명 전투 중처럼 사용자가 없을 때도 동작). 걸어 둔 것은 풀면 별빛이 돌아온다.
  - **즉시**: 사용자가 이미 보고 있는 상황(중상으로 쉬는 중, 운명 선택 창)에서 바로 쓴다.
- **화면**: 상세 창 방침 탭(03 §5.4)에 `가호` 칸 하나. `별빛 ◆◆◇`(보유/상한), 걸어 둔 가호 줄, 단추 4개. 기본 창에는 배지·점을 두지 않는다(03 §11.1). 별빛이 차오르면 `ⓘ` 안내만 8초(03 §11.2, 일지에 안 남김).

**치명 판정 제한**(극복 서사를 지우지 않기 위해, 권장 묶음):
1. `최후의 순간`은 **치명 관문에 들어가기 전에 걸어 둔 경우만** 발동한다. 전투 중에 걸면 다음 판단 지점부터(04 §10.2 규칙과 같음).
2. 가호가 걸려 있어도 AI의 EB03 진입 판단(치명 위험 허용·위험 한도, 01 §7.1)은 **바뀌지 않는다**. 가호를 믿고 무모해지지 않는다.
3. 구해져도 중상과 패배 손실은 남는다 — "살아 돌아와 다시 일어서는" 이야기가 된다.

#### ④ 기록 — 생애의 책(18)과 일지(14)

- 인물은 모른다 → **새 태그를 만들지 않고** 원래 사건의 태그를 쓴다(`[부상]`·`[판정]`·`[사냥]` 등). `journal_entry.sub = blessing_*`로 구별한다.
- 문장은 `이상하게도 …` 문형(14 §5에 5개 등록). 가호·별빛·신 같은 규칙 낱말은 문장에 쓰지 않는다(14 §8.1). 판정 식 펼침에만 `(별빛)` 표지.
  - 최후: `[부상] 이상하게도 쓰러진 자리에서 다시 눈을 떴다.` / 상세 `종의 방 바닥에 별빛 한 줄기가 비쳤다. {name:은/는} 어떻게 빠져나왔는지 기억하지 못했다.`
  - 치유: `[부상] 이상하게도 상처가 하룻밤 새 아물었다.`
  - 주사위: `[판정] 미끄러지던 발이 이상하게도 멈췄다.` / 식 `주사위 3 → (별빛) 14 + 민첩 3 = 17 / 난이도 14`
  - 누그러뜨림: `[사냥] 이상하게도 잃어버린 것이 하나도 없었다.`
  - 숨은 길: 선택 결과 기록 그대로(선택지 이름이 `별빛 길`임을 펼침에 표시).
- **책(18)**: 선별 점수표 §4.1에 `sub = blessing_*` 4점 추가. `최후의 순간` 기록은 필수 **BM9**(최대 1). 새 문장 틀은 만들지 않는다.
- **계승 1단계**(03 §8) `걸어온 길`에 `· 이상한 행운 {n}번` 한 줄(사용자는 알고 인물은 모르는 표현). `life_record.blessings`에 남겨 연대기에서도 보인다.

### 2.1 성장 전달 (F1과 함께, 규칙 변화 작음)

- 소유: 문형 14, 효과 줄 생성 규칙 05, 화면 03. `effect_line` 텍스트는 데이터 정의(직업·기술·특성)에 한 줄씩 둔다(16).

### 2.4 직업 효과 (데이터, M안)

## 4 사용자에게 물을 질문 (권장안이 첫 번째)

### F7 가호

1. **별빛은 어떻게 차오르고 얼마나 쓸까요?**
   - (권장) 가문에 최대 3개. 계승할 때 +1, 생애 안 극복 순간(중상 회복 뒤 귀환·관문 첫 격파·연속 사건 완결·극복 특성)마다 +1(생애 2회까지). 한 생애 3번까지 사용
   - 계승할 때만 +2, 생애 안에서는 안 참
   - 30·50·65세마다 +1(시작 1)
2. **죽음을 막는 가호(최후 판정)는 어떻게 할까요?**
   - (권장) 치명 관문 전에 미리 걸어 둔 경우만, 별빛 2, 생애 1번. 판정 실패를 성공으로(중상 입고 살아 돌아옴)
   - 걸어 두면 판정 +5(실패할 수 있음)
   - 살아 돌아오되 그 생애는 곧 은퇴
3. **생애 시작 축복은 어떻게 고를까요?** (목록: 타고난 재능 · 기울어진 재능 · 첫걸음의 보호 · 길의 씨앗 · 별빛 한 줌)
   - (권장) 5개 다 보여 주고 1개(무료, 안 골라도 됨). 능력치는 1점 옮기기라 총합 11 유지. 준 특성은 유전 안 함
   - 무작위 3개 중 1개
   - 능력치를 +1 올려 줌(총합 12, 가문 해금 원칙 12 §8 예외)
   - 별빛 1을 써야 내릴 수 있음
4. **오프라인 사용과 기록은?**
   - (권장) 미리 걸어 둔 가호만 오프라인에도 발동, 자동 사용은 기본 끔. 인물은 모르고 일지에 `이상하게도 …`만, 생애의 책에 선별 점수 4, 죽음을 막은 순간은 반드시 실음
   - 오프라인 중에는 걸어 둔 것도 멈춤
   - 자동 사용 기본 켬(최후 판정만)

### F8 성장 전달·직업

1. **직업 규모는?**
   - (권장) 1차 3갈래(수호자·길잡이·약초꾼) + 2차 각 2갈래 = 9직업
   - 1차 2갈래 그대로 + 2차 각 2갈래 = 6직업
   - 1차 4갈래(+행상) + 2차 각 2갈래 = 12직업
2. **2차 전직은 언제?**
   - (권장) 레벨 20(약 50세, 숙련기 입구) + 주 숙련 3단계. 새 운명 사건 `두 번째 갈림길`, 거절하면 지금 직업 유지
   - 레벨 18(약 45세, 금패 무렵)
   - 레벨 16(약 41세)
3. **기술은 어떤 모양으로?**
   - (권장) 자동 발동형(대부분 출정당 1회), 한 생애 최대 4개(전직 2 + 스승·유적·위기 극복 사건 2), 고르는 조작 없음
   - 상시 수치만(발동 순간 없음)
   - 확률 발동형
4. **계승 때 직업·기술은?**
   - (권장) 둘 다 처음부터. 대신 가문 수첩에 `요령` 1개가 남아 후계자가 배울 기회를 1번 얻음(능력 직접 이전 없음)
   - 둘 다 처음부터, 연대기에 이름만
   - 요령 + 은퇴한 교관 부모가 직접 가르칠 수 있음
   - 기술 1개 그대로 물려받음(원칙 예외)

## 5 사용자 확정 (2026-09-28, 세션 7)

- 번호: D77은 F1(세부 글 우선)에 썼다. **가호 = D78, 직업·성장 = D79**로 정한다.
- **F7 가호(D78)**: 네 질문 모두 권장안.
  1. 별빛은 가문 최대 3개. 계승 때 +1, 생애 안 극복 순간마다 +1(생애 2회까지). 한 생애 사용 3번까지. 켜 둬야 쌓이지 않는다.
  2. 최후 판정 구하기: 치명 관문 전에 미리 걸어 둔 경우만, 별빛 2·생애 1번. 실패를 성공으로(중상 입고 귀환). 가호가 걸려도 인물의 치명 진입 판단은 바뀌지 않는다.
  3. 시작 축복: 5종(타고난 재능·기울어진 재능·첫걸음의 보호·길의 씨앗·별빛 한 줌) 모두 보여 주고 1개 무료, 안 골라도 됨. 능력치는 1점 옮기기(합 11 유지), 준 특성은 유전 안 함. 계승 5단계·첫 실행에서 고른다.
  4. 오프라인: 걸어 둔 가호만 발동, 자동 사용 기본 끔. 인물은 모르고 일지에 `이상하게도 …`, 생애의 책 선별 점수 4, 죽음을 막은 순간은 반드시 싣는다.
- **F8 직업·성장(D79)**:
  1. **12직업**: 1차 4갈래(수호자·길잡이·약초꾼·**행상**) + 2차 각 2갈래. 초안의 "행상 제외" 근거(교섭 2단계가 약 Lv12라 F01 레벨 8과 안 맞음, 경제 균형)는 사용자가 넘겼으므로, 설계에서 F01 조건(교섭 포함)과 행상의 경제 효과 상한을 밸런스 시뮬레이터로 확인해야 한다. 행상 2차 2갈래 이름·효과는 새로 정한다.
  2. 2차 전직: 레벨 20 + 주 숙련 3단계, 새 운명 사건 `두 번째 갈림길`(거절하면 지금 직업 유지).
  3. 기술: 자동 발동형(대부분 출정당 1회), 한 생애 최대 4개(전직 2 + 스승·유적·위기 극복 사건 2), 고르는 조작 없음.
