# 04 생활순환과 행동 결정

버전 0.2 · 작성일 2026년 9월 22일 · 상위 문서 00_문서지도.md, 01_핵심규칙_수치기준.md

모험가가 사용자의 조작 없이 스스로 다음 행동을 고르는 규칙을 정의한다. 행동 상태와 전이, 판단 지점, 우선순위 기반 행동 결정 알고리즘, 활동과 장소 선택, 출정 구성, 귀환 후 마을 루틴, 태도와 위험 정책의 적용, 사용자 개입의 적용 시점을 다룬다. 이 문서는 행동 결정의 **상위 흐름**을 소유한다. 전투 세부 판정은 05, 사냥터·던전·모험 경로의 내용은 07, 구매와 가방 정리는 08, 사건 발생과 자동 선택은 10에 위임한다.

관련 문서: 01_핵심규칙_수치기준.md(§1 시간, §6 회복, §7 태도, §8 지역, §18 공유 명칭) · 05_인물_성장_판정.md · 07_전투_사냥_던전_모험.md · 08_아이템_경제.md · 09_생애_노화_기연_변이.md · 10_사건_시스템.md · 13_오프라인_저장.md

## 2 행동 상태

### 2.1 상태 정의

01 §18.1의 12개 상태를 쓴다. 한 시점에 인물은 정확히 하나의 상태에 있다.

| 상태 | 의미 | 대표 동작(15) | 유효 진행 흐름 | 나가는 계기 |
| --- | --- | --- | --- | --- |
| 마을 대기 | 마을에서 다음 행동을 고르는 순간 | 대기 | 흐름(3~5초) | 행동 결정 결과 |
| 마을 정비 | 휴식, 판매, 보충, 구매, 정비비, 편지 | 상호작용, 잠, 앉기와 식사 | 흐름 | 루틴 완료 |
| 이동 | 마을에서 장소로, 또는 던전 층 하강 | 걷기 | 흐름 | 도착 |
| 사냥 | 사냥터에서 조우를 반복 | 걷기, 공격, 피격, 발견 | 흐름 | 퇴각·목표 달성·사건 |
| 모험 | 모험 경로에서 장면을 진행 | 걷기, 발견, 상호작용 | 흐름 | 장면 소진·퇴각·사건 |
| 던전 | 던전 층의 방과 관문을 진행 | 상호작용, 공격, 피격, 발견 | 흐름 | 관문 종료·퇴각·사건 |
| 야영 | 현장에서 쉬는 60초 | 앉기와 식사, 잠 | 흐름 | 야영 종료 |
| 귀환 | 현장에서 마을로 돌아오는 중 | 걷기 | 흐름 | 마을 도착 |
| 치료 | 치료소 입원 또는 길드 무료 치료 | 잠 | 흐름 | 치료 완료 |
| 선택 대기 | 운명 사건이나 중대 분기의 사용자 결정을 기다림 | 앉기와 식사 + 책 소품 | **정지** | 사용자 선택 또는 사전 방침 |
| 계승 대기 | 생애 종료 후 후계자 확정을 기다림 | (계승 화면) | **정지** | 후계자 확정 |
| 일시정지 | 사용자가 모든 진행을 멈춤 | 현재 프레임 정지 | **정지** | 사용자 재개 |

- 선택 대기, 계승 대기, 일시정지에서는 나이, 피로, 회복, 계절이 모두 멈춘다(01 §1.1).
- 일시정지는 다른 모든 상태 위에 겹쳐진다. 재개하면 직전 상태의 남은 연출부터 이어간다.

### 2.3 판단 지점

행동 결정 알고리즘(3장)은 아래 시점에만 실행한다. 전투 라운드 도중에는 실행하지 않는다(도주와 관문 회복약은 05 §7의 라운드 규칙이 처리한다).

| 번호 | 판단 지점 | 먼저 실행하는 처리 |
| --- | --- | --- |
| J1 | 마을 도착(귀환 완료) | 10 §3 발생 판정(마을 귀환 사건, **귀환당 1회**) |
| J2 | 마을 루틴 완료 | 없음 |
| J3 | 사냥 조우 종료 + 숨 고르기 | 10 §3 발생 판정(조우 후 사건, 사냥터별 확률은 10 소유) |
| J4 | 던전 방 종료 + 숨 고르기, 관문 직전 | 전투·보물 방이 끝난 뒤에는 10 §3.1의 방 뒤 사건 검사(5%). 사건 방은 07 §5.3이 10 §3을 100%로 호출하고, 휴식 지점은 야영과 같은 검사(J6)를 한다. 함정 방 뒤에는 검사하지 않는다(D38) |
| J5 | 모험 장면 종료 | 없음(07 §6.1의 `사건` 장면이 10 §3을 호출. 그 밖의 장면 뒤에는 따로 검사하지 않음) |
| J6 | 야영 종료 | 10 §3 발생 판정(야영 사건) |
| J7 | 이동 도착 | 없음 |
| J8 | 치료 완료 | 없음 |
| J9 | 선택 대기 해소 | 선택 결과 적용 |
| J10 | 오프라인 정산 시작, 앱 재개 | 13 §정산 규칙 |

판단 지점에 들어가면 **사건 발생 판정 → 결과 적용 → 우선순위 평가** 순서로 처리한다(D39). 조우·방 뒤의 숨 고르기는 판단 지점에 들어가기 전에 끝난다. 현장(J3~J5)의 우선순위 평가는 7.5절 현장 판단이며, 그 안의 순서는 **회복약 → 퇴각·피로 → 즉시 귀환 명령 → 출정 목표 → 다음 방 진입**이다. 사건 피해를 입은 뒤에 회복약을 한 번에 판단하기 위해서다.

## 3 행동 결정 알고리즘

### 3.1 우선순위

v0.1 §5.2의 여섯 단계를 그대로 구현한다.

| 순위 | 내용 | 결과 |
| --- | --- | --- |
| 1 | 생애 종료 조건(사망 확정, 은퇴 대상, 긴 잠) | 생애 정리 또는 귀환 |
| 2 | 대기 중인 운명 사건·중대 분기 | 선택 대기 |
| 3 | 활동을 막는 부상, 체력·피로 기준 초과 | 귀환, 치료, 휴식 |
| 4 | 회복비와 필수 물품 확보 → 장비 정비 | 마을 정비 |
| 5 | 이어서 진행할 임무 | 임무 장소로 출정 |
| 6 | 태도, 적정 난도, 지역 조건에 따른 활동 선택 | 가중 선택 출정 |

### 3.2 의사코드

```text
function 다음_행동(인물, 상태):
    # 1 생애 종료
    if 인물.사망_확정:                       return 생애_정리(S04) → 계승 대기
    if 인물.긴잠_도래:
        if 상태 == 마을:                     return 생애_정리(S08) → 계승 대기
        else:                                return 귀환
    if 인물.나이 >= 인물.은퇴_나이 or 인물.조기은퇴_예약:
        if 상태 == 마을:                     return 생애_정리(S03) → 계승 대기
        if 현재_전투.치명 and 현재_전투.진행중: return 계속      # v0.1 §10.2
        return 귀환

    # 2 선택 대기
    if 대기중_선택 존재:                     return 선택 대기

    # 3 부상·체력·피로
    if 상태 in {사냥, 모험, 던전}:
        return 현장_판단(인물)                  # 7.5절
    if 상태 == 마을:
        if 인물.중상:                          return 치료
        # 경상 치료와 휴식은 마을 정비의 앞 단계에서 처리

    # 4 회복비·필수 물품·장비
    if 상태 == 마을 and not 이번_귀환_루틴_완료: return 마을 정비   # 8장

    # 5 임무
    임무 = 유효_임무(인물)                       # 3.3절
    if 임무:                                  return 출정(임무.활동, 임무.장소)

    # 6 태도 기반 선택
    시간대 = 시간대_결정()                         # 낮 70 / 밤 30, 흡혈귀는 09 §7.3
    if 인물.출정_횟수 == 0:                     return 출정(사냥, H1, 시간대)   # 11장 첫 출정 고정(D21)
    후보 = 후보_생성_및_필터(인물, 시간대)          # 4장
    if 후보 비어 있음:                          후보 = 빈_후보_처리(인물)   # 4.4절: 중상이면 치료, 고정 장소 탈락이면 고정 무시 재필터
    활동 = 가중_선택(가중치(후보, 인물))            # 5장
    장소 = 장소_선택(활동, 후보, 인물)              # 6장
    return 출정(활동, 장소, 시간대)
```

### 3.3 임무의 유효 조건

| 임무 종류 | 유효 조건 | 우선 처리 한도 |
| --- | --- | --- |
| 연속 사건 다음 단계 | 다음 단계의 발생 장소가 4장 필터를 통과 | 같은 임무로 연속 3회 출정. 이후에는 5장 임무 보너스로 전환 |
| 수락한 길드 의뢰(L06) | 의뢰 장소가 필터를 통과하고 의뢰 기한 안(기한과 실패 처리는 11 L06 소유) | 의뢰 완료 또는 기한 종료까지 |
| 사용자 목적지 고정 | 고정 장소가 해금 상태 | 해제할 때까지. 위험 경고는 10.2절 |

임무 장소가 필터에서 떨어지면(예: 안정적 태도에서 D2가 높음) 임무는 보류 상태로 남고, 해당 활동에 임무 보너스만 준다. 조건이 맞게 되면 다시 우선 처리한다.

## 4 활동 후보와 필터

### 4.1 후보 생성

해금된 모든 장소(H, A, D)를 후보로 올리고, 각 후보에 **위험 차**와 **위험 등급**(01 §7.2)을 계산한다. 던전 층 후보는 층 권장 중앙값으로, 관문 진입 여부는 07 §5.6이 따로 판단한다. 밤 출정이면 모든 후보의 위험 차에 +1을 더한다(01 §1.2의 밤 적 레벨 +1).

### 4.2 필터 순서

| 순서 | 필터 | 탈락 조건 |
| --- | --- | --- |
| F1 | 해금 | 01 §8.1의 해금 조건 미충족 |
| F2 | 길드 등급 | 던전 층의 필요 등급 미달(01 §8.3) |
| F3 | 파산 지원 | 지원 기간이면 H1·H2 사냥과 A1 모험 외 전부 제외(01 §9.6) |
| F4 | 부상 | 중상이면 전부 탈락(치료가 먼저). 경상 2개면 던전 제외 |
| F5 | 목적지 고정 | 고정 중이면 고정 장소만 남긴다. 남은 고정 장소는 F6·F7을 **경고 1회 후 통과**한다(10.2절). 치명 콘텐츠는 여전히 치명 위험 허용이 필요하다(01 §7.1) |
| F6 | 준비 상태 | 회복약 0개면 위험 등급 `보통` 이상 제외 |
| F7 | 위험 상한 | 위험 `무모` 제외. 유효 위험 상한(10.1절) 초과 제외. 모험적은 모험 활동에 한해 `높음` 허용 |
| F8 | 적자 | 4.3절의 적자 제외 목록에 있는 장소 |
| F9 | 변이 제약 | 흡혈귀는 시간대를 09 §7.3 확률(낮 20 / 밤 80, 굶주림 단계는 밤 100)로 정한다. 낮 출정의 불리는 09 §7.3이 적용한다. F9는 장소를 거르지 않는다 |

- **길드 순찰 구역**: H1과 A1은 F6·F7·F8을 항상 통과한다(01 §7.1, D24). 위험 허용 상한을 `낮음`으로 둔 Lv1 인물도 H1에 갈 수 있다.
- 치명 표식은 층 전체가 아니라 관문(EB03)에만 붙으므로 F7에서 D3 자체를 떨어뜨리지 않는다. 관문 진입은 07 §5.6이 막는다.

### 4.3 적자 활동 제외

- **출정 수지** = 출정 수입(동전 + 획득 장비의 판매가) − 출정 비용(소모한 회복약·야영 식량·붕대의 구매가 + 귀환 직후의 치료비·휴식비·정비비).
- 같은 장소에 대한 **최근 3회 출정 수지의 합이 음수**이면, 그 장소를 이후 **행동 결정 5회** 동안 후보에서 뺀다.
- 한 장소에 3회 출정하기 전에는 판단하지 않는다. H1과 A1은 적자 판단을 하지 않고, H2는 파산 지원 기간에 적자 판단을 하지 않는다.
- 제외된 장소는 일지에 `[마을] 늑대 언덕은 요즘 벌이가 시원찮다.` 형식으로 한 번 남긴다(14).

### 4.4 후보가 모두 탈락했을 때

H1과 A1은 F4(중상)를 뺀 모든 필터를 통과하므로, 후보가 모두 탈락하는 경우는 두 가지뿐이다.

1. **중상**: 치료로 간다.
2. **목적지 고정 장소가 F4에서 떨어짐**(예: D2 고정 + 경상 2개): 이번 출정에 한해 고정을 무시하고 F5 없이 다시 거른다. 고정은 해제하지 않는다. 일지: `[마을] 몸을 추스르려 가까운 길을 골랐다.`

사용자의 위험 허용 상한을 넘는 장소를 대신 넣는 규칙은 두지 않는다(v0.1 §6 "성격이 위험 금지를 무시하지 않는다").

위험 허용 상한 때문에 H1·A1만 남는 상태가 10회 연속 이어지면 일지에 한 번 `[마을] 방침대로 익숙한 길만 걸었다.`를 남긴다. 성장이 느려진다는 사실을 알리는 기록이다.

## 5 활동 가중치

### 5.1 계산식

```text
가중치(활동) = max(0, (기본 + 특성 + 전문화 + 임무 + 탐험 + 생애 단계)) × 반복 계수 × 적정도 계수
```

후보 장소가 하나도 없는 활동의 가중치는 0이다. 세 가중치의 합으로 나누어 확률을 만든다.

### 5.2 항목별 값

| 항목 | 값 |
| --- | --- |
| 기본 | 01 §7.1 태도 가중치. 안정 60/30/10, 모험 30/45/25, 도전 20/25/55 (사냥/모험/던전) |
| 특성 | TI06 `호기심 많음` 모험 +10(01). 그 밖의 특성 보정은 06 §행동 반응 표를 따르며, 특성 보정의 합은 활동당 −15~+15로 제한 |
| 전문화 | 수호자 던전 +5·모험 −5, 길잡이 모험 +10·사냥 −5 (05 §8.2) |
| 임무 | 3.3절에서 우선 처리 한도를 넘었거나 보류된 임무가 있는 활동에 **임무 보너스**(5.4절). 04 소유 값이며 10은 참조한다 |
| 탐험 | 해금 후 한 번도 가지 않은 장소가 있는 활동 +10(방문하면 소멸). 발견이 남은 모험 경로가 후보에 있으면 모험 +5 |
| 생애 단계 | 노년기(65세 이상): 던전 −10, 사냥 +5. 임무 보너스의 노년 배수는 5.4절 |
| 반복 계수 | 직전까지 같은 활동을 연속 k회 골랐다면 max(0.5, 1 − 0.15 × max(0, k − 1)). k = 0, 1 → 1.0 · 2 → 0.85 · 3 → 0.70 · 4 → 0.55 · 5 이상 → 0.5 |
| 적정도 계수 | 그 활동 후보 중 가장 좋은 장소의 위험 등급 기준. 매우 낮음 0.6 · 낮음 0.9(안정적은 1.0) · 보통 1.0 · 높음: 도전적 1.0, 안정적·모험적 0.8. 안정적·모험적이 `높음`을 고르는 경우는 모험적의 모험 활동 예외 상한과 사용자가 위험 허용 상한을 `높음`으로 올린 경우다(D40) |

### 5.3 계산 예

**예 1. 모험적 Lv9, TI06, 사냥을 연속 2회 고른 직후, D1 미방문, 낮 출정**

| 활동 | 후보(위험 차, 등급) | 계산 | 가중치 | 확률 |
| --- | --- | --- | --- | --- |
| 사냥 | H2(−3 낮음), H3(+2 보통) | 30 × 0.85(k=2) × 1.0 | 25.5 | 23.5% |
| 모험 | A1(−5 매우 낮음), A2(+3 높음) | (45 + 10 TI06 + 5 발견 남음) × 1.0 × 0.8 | 48.0 | 44.2% |
| 던전 | D1(0 보통, 미방문) | (25 + 10 탐험) × 1.0 × 1.0 | 35.0 | 32.3% |

**예 2. 안정적 Lv18, 수호자, 사냥을 연속 4회, 낮 출정, 길드 은패, D2 무사 귀환 3회 완료, EB02 미격파**

| 활동 | 후보(위험 차, 등급) | 계산 | 가중치 | 확률 |
| --- | --- | --- | --- | --- |
| 사냥 | H3(−7 매우 낮음), H4(−1 낮음). H5(+7)는 무모 탈락 | 60 × 0.55(k=4) × 1.0 | 33.0 | 49.3% |
| 모험 | A2(−6 매우 낮음), A3(+1 보통) | (30 − 5 수호자) × 1.0 × 1.0 | 25.0 | 37.3% |
| 던전 | 목표 층 D1(−9 매우 낮음, 6.2절). EB02 위험 차 21 − 18 = +3 > −1이라 관문 우선 규칙 미적용 | (10 + 5 수호자) × 1.0 × 0.6 | 9.0 | 13.4% |

반복 계수가 없었다면 사냥 확률은 약 64%였다. 같은 생활이 계속 이어지지 않도록 반복 계수가 모험 쪽으로 무게를 옮긴다.

### 5.4 임무 보너스

```text
임무 보너스 = min(60, (15 + (보류 경과 ≥ 60분 ? 15 : 0)) × (노년기 ? 2 : 1))
```

- 기본 +15. 임무가 보류된 채(3.3절) 유효 진행 60분이 지나면 +30이 된다.
- 노년기(65세 이상)에는 위 값에 ×2를 한다. 최댓값은 60이다. 끝나지 않은 이야기를 은퇴 전에 마무리하려는 경향이다.
- 계산 순서는 기본 → 60분 가산 → 노년 배수다. 결과는 5.1절 식의 `임무` 항에 더한다.
- 예: 70세 인물의 C01-3이 75분째 보류 중이면 (15 + 15) × 2 = 60.

## 6 장소 선택

### 6.1 사냥터와 모험 경로

장소 점수는 **가산식**이다. 곱셈 항을 두지 않으며 음수도 허용한다.

```text
점수(장소) = 10 − 3 × |위험 차 − 목표 위험 차|
           + 10 (그 장소에 진행 중 연속 사건 단계가 있음)
           + 5  (미방문)
           + 3  (모험 경로이고 남은 발견이 있음)
           − 이동 시간(초) / 10          # 01 §8.1 이동 시간에 특성·전문화·유물·날씨 보정 적용 후
           + 특성 가산                   # 06 표. 단위는 점수, 장소당 합계 −15~+15
목표 위험 차: 안정적 −2, 모험적 0, 도전적 +2
```

- 점수 상위 두 곳을 70 : 30으로 고른다. 후보가 하나면 그곳으로 간다. 동점이면 권장 레벨 중앙값이 높은 곳을 앞에 둔다.
- 이동 시간 항은 먼 곳을 조금 덜 고르게 한다. TI03 `길눈이 밝음`이나 길잡이는 이동 시간이 줄어(05 §8.2, 하한 60%) 먼 장소의 감점이 작아진다.
- 특성이 장소를 좋아하거나 꺼리는 정도(예: TI02의 D2·축제, TI05의 폐광)는 06이 이 단위의 가산점으로 정한다. 04는 값을 정하지 않는다.

**예** — 모험적 Lv9, 낮 출정, 특성 없음: H3(위험 차 +2, 45초) = 10 − 6 − 4.5 = −0.5, H2(위험 차 −3, 30초) = 10 − 9 − 3 = −2. H3가 70%, H2가 30%다.

### 6.2 던전 층

목표 층은 아래 순서로 처음 맞는 규칙을 쓴다. 04가 소유하는 규칙이다(00 §2.4).

- **던전 묶음과 깊이**(D44): 층의 순서는 ID가 아니라 장소 정의의 `dungeon {group, depth}`로 정한다(같은 묶음 안에서 depth 1, 2, 3…). "깊은 층·얕은 층·첫 층"은 모두 같은 묶음 안의 depth 순서다.
- 아래 함수는 **묶음마다** 따로 실행해 묶음마다 목표 층 하나를 얻는다. 묶음이 둘 이상이면 각 묶음의 목표 층을 6.1절 장소 점수로 비교해 사냥터·모험 경로와 같은 방식(상위 두 곳 70 : 30)으로 고른다. 첫 검증판은 종소리 폐광 한 묶음(D1~D3)뿐이지만, 구현은 묶음 하나를 가정하지 않는다.

```text
function 목표_층(인물, 묶음):
    입장가능 = 묶음의 층 가운데 F1·F2·F4를 통과한 층
    # 1 관문 미격파 층 우선 (D19, 01 §7.1)
    for 층 in 입장가능 (깊은 층부터):
        if not 층.관문_격파(이번 생애) and 관문_위험_조건(층.관문, 인물):   # 07 §5.6 위험 조건, 01 §7.1 한도
            return 층
    # 2 새 층 적응
    for 층 in 입장가능 (얕은 층부터):
        if 층.무사_귀환_횟수(이번 생애) < 3 and 층.위험 등급 ≤ 태도 최대 위험(10.1절):
            return 층
    # 3 기본
    적정 = 위험 차 ≤ +2인 가장 깊은 층, 없으면 가장 얕은 층
    return 안정적 ? max(묶음의 첫 층, 적정 − 1) : 적정      # 첫 검증판에서 첫 층은 D1
```

- **관문 미격파 층 우선**: 관문을 아직 넘지 않은 층이 07 §5.6의 위험 조건(안정적 ≤ −1, 모험적 ≤ +2, 도전적 ≤ +5, 치명 관문은 01 §7.1 치명 한도와 치명 허용)을 만족하면, 태도별 목표 깊이보다 그 층을 먼저 고른다. 관문 앞의 체력 조건은 관문 앞에서 07 §5.6이 따로 판단한다.
- **새 층 적응**: 새로 열린 층은 그 층에서 무사 귀환 3회를 채울 때까지, 위험 등급이 태도 최대 위험 안이면 목표 층이 된다. 안정적 인물도 D2·D3를 직접 경험하고, D3 첫 진입으로 A4가 열리며(01 §8.1), 별패 조건(D3 무사 귀환 3회, 01 §8.3)을 채울 수 있다.
- 목표 층이 F7에서 탈락하면 한 층 얕은 층을 쓴다. 그것도 없으면 던전 가중치는 0이다.
- 층의 방 수는 입장할 때 01 §8.2 범위에서 정하고, 방 구성은 07 §5.2가 만든다.

**예 — 안정적 인물이 EB02를 치르는 시점**: 안정적 Lv18(유효 18)은 EB02 위험 차 +3이라 관문 우선 규칙이 적용되지 않고 목표 층은 D1이다(5.3절 예 2). Lv22(유효 22, 약 57세)가 되면 EB02 위험 차 21 − 22 = −1 ≤ −1이 되어 목표 층이 D2로 바뀌고, 관문 앞 체력 조건(07 §5.6)을 만족하면 EB02에 도전한다. 격파하면 금패(01 §8.3)를 받고 D3가 열린다. 이어서 새 층 적응 규칙에 따라 D3(위험 차 25 − 22 = +3, 높음)는 안정적 최대 위험 `보통`을 넘으므로, 유효 레벨 23 이상이 되면 D3에 들어간다.

## 7 출정 구성

### 7.1 출정 준비

마을 루틴(8장) 5단계의 필수 물품 보충이 출정 준비를 한다. **물품별 목표 수량과 돈이 모자랄 때의 구매 우선순위는 08 §8이 소유한다.** 04는 루틴의 순서만 정한다. 회복약 목표 소지의 태도별 값은 01 §7.1이다.

회복약을 하나도 사지 못하면 다음 출정은 F6 필터에 따라 위험 `낮음` 이하 장소만 간다(H1·A1은 항상 통과).

### 7.2 사냥 출정

- **목표 조우 수** = 태도 기준(안정 8, 모험 10, 도전 12) + 무작위 −2~+2. 출정 시작 때 정한다.
- 한 조우는 07 §사냥터 조우 표에서 적과 수(1~2체)를 뽑고, 전투는 05 §7로 처리한다.
- 조우가 끝나면 숨 고르기(5초, HP +4% × 회복 계수) → J3 판단 지점.
- 목표 조우 수를 채우면 귀환한다. 목표 전에 7.5절 조건에 걸리면 퇴각한다.
- 목표 조우 수는 04가 소유하는 값이다(00 §2.4). 07 §3.4의 `조우 18회 또는 15분`은 이 값이 어떤 이유로 늘어나도 넘지 않는 안전 상한이다.
- **첫 출정의 목표 조우 수는 태도와 무관하게 8회로 고정**한다(무작위 가감 없음). 새 인물(첫 가문의 첫 인물과 후계자)의 첫 출정(11장, H1 사냥)에 적용한다. 조우 1회 30~50초이므로 이동 20초를 더해도 출정은 약 4.5~7분에 끝나고, 여관 휴식(90초)까지 약 9분 안에 마친다. v0.1 §2.1의 "약 10분 안에 귀환과 휴식 확인"을 보장하는 값이다. 03 §12.2 첫 실행 타임라인은 이 값을 쓴다.
- 첫 가문의 첫 인물은 이 출정의 2번째 조우 뒤 L01, 3번째 조우에서 A02를 반드시 만난다(01 §9.5, 10).

### 7.3 모험 출정

- **장면 수** = 태도 기준(안정 3~4, 모험 4~5, 도전 5~6). 07이 경로별 장면 범위를 정하면 그 범위 안으로 자른다.
- 장면 내용(발견, 길 선택, 채집, 조우, 사건)은 07 §모험 경로와 10 §발생 판정이 정한다.
- 장면을 모두 마치면 귀환한다. 길 선택 장면의 자동 선택은 10 §자동 선택 규칙을 따른다.

### 7.4 던전 출정

던전은 한 번의 출정에 한 층만 들어간다(목표 층은 6.2절). 방마다 J4 판단 지점에서 **다음 방 진입 판단**을 한다.

- **다음 방 진입 판단은 07 §5.5를 호출한다.** 예상 손실률 E, 가용 체력률, 태도별 안전 계수와 회복약 반영 개수는 07 §5.5가 소유한다(00 §2.4). 04는 식을 따로 두지 않는다.
- 방의 적 레벨은 01 §5.2의 "적의 등록 레벨 + ⌊방 순번 / 2⌋"다(예: D2 방 2의 EN09는 L19, 방 4는 L20).
- 마지막 방 뒤의 **관문 도전 판단은 07 §5.6**을 호출한다. 태도별 관문 위험 한도와 치명 관문 한도는 01 §7.1이다. 이미 격파한 층의 관문 자리는 `관문 잔당`이다(01 §8.2).
- 07 §5.5·§5.6이 귀환을 돌려주면 확보한 전리품을 들고 귀환한다. 관문 앞 귀환 기록은 07 §5.6의 문장을 쓴다.

### 7.5 현장 판단 (사냥·모험·던전 공통)

J3~J5 판단 지점에서 아래 순서로 확인한다.

```text
function 현장_판단(인물):
    if 인물.중상:                                   return 귀환
    회복약_자동_사용(인물)                            # 7.6
    if 인물.HP ≤ 최대HP × 퇴각 기준:
        if 인물.태도 == 도전적 and 야영_가능(인물):    return 야영    # 7.7
        return 귀환 (퇴각)
    if 인물.피로 ≥ 피로 기준:
        if 야영_가능(인물):                          return 야영
        return 귀환
    if 즉시_귀환_명령:                               return 귀환
    if 출정_목표_달성:                               return 귀환
    if 상태 == 던전 and not 07_다음_방_진입(인물):    return 귀환    # 07 §5.5
    return 계속
```

가방이 가득 차는 것은 귀환 조건이 아니다(D25). 08 §9.3의 현장 정리로 처리한다.

### 7.6 회복약 자동 사용

- J3~J5에서 HP가 **퇴각 기준 + 10%p 이하**이고 회복약이 있으면 마신다(01 §4).
- HP가 퇴각 기준 + 10%p를 넘거나 회복약이 떨어질 때까지 한 병씩 반복한다. 한 병에 3초.
- 가진 회복약 중 기준선을 넘기는 가장 낮은 단계부터 쓰고, 한 병으로 넘기지 못하면 가장 높은 단계를 쓴다.
- 전투 중 사용은 관문·보스 전투에서 1회만 허용한다(05 §7.7).

### 7.7 야영 판단

야영 가능 조건(모두 만족):

1. 현재 활동이 사냥 또는 모험이다. 던전에서는 휴식 지점 방에서만 쉰다(07).
2. 이번 출정에서 아직 야영하지 않았다.
3. 출정 경과 시간이 10분 미만이다.
4. HP 회복 목적의 야영(7.5절 도전적 분기)은 야영 식량이 1개 이상 있을 때만 한다.

야영은 60초, 피로 −40, HP +30% × 회복 계수다. 야영 식량이 없으면 효과가 절반이다(01 §6.1). 야영이 불가능한 날씨는 없고, 비와 눈은 야영 효과만 줄인다(01 §1.3). 야영이 끝나면 J6에서 다시 판단한다.

### 7.8 시간대와 날씨

- 시간대는 출정 결정 때 정한다(낮 70%, 밤 30%, 흡혈귀는 09 §7.3). 한 출정 안에서 바뀌지 않는다.
- 밤 출정: 위험 차 +1, 인물의 은밀 판정과 매복 대응 판정 +2, 시야 탐색 −1(01 §1.2). 매복 시도 확률은 07 §2가 올린다.
- 날씨는 **출정을 시작할 때** 01 §1.3의 계절별 확률로 정하고 출정 동안 유지한다. 이동 시간, 판정 보정, 야영 효과, 일부 사건 가중치는 01 §1.3 표를 따른다. 04는 날씨 효과를 따로 정하지 않는다.

## 9 태도별 행동 차이

같은 상황에서 세 태도가 어떻게 다르게 움직이는지를 보여준다. 퇴각 기준과 피로 기준은 01 §7.1, 던전 진입 계수는 07 §5.5 값이다.

| 상황 | 안정적 | 모험적 | 도전적 |
| --- | --- | --- | --- |
| 사냥 중 조우 뒤 HP 55%, 회복약 2 | HP ≤ 70%이므로 회복약을 마신다. 회복약이 없었다면 귀환 | 계속(퇴각 기준 40%, 회복약 기준 50%) | 계속 |
| D1 방 3개를 지나 HP 65%, 회복약 T2 2병(30 HP씩), 최대 HP 90, 다음 방 E = 0.060 | 0.65 − 2.0 × 0.060 = 0.53 < 0.60 → **귀환** | 0.65 + 30/90 − 1.3 × 0.060 = 0.905 ≥ 0.40 → 진입 | 0.65 + 60/90 − 1.0 × 0.060 = 1.257 ≥ 0.25 → 진입 |
| 흔들리는 다리(L08) | 손해·부상 회피 선택지(우회) 우선 | 정보·새 길 선택지 우선 | 높은 보상·정면 해결 선택지 우선 |
| Lv12, 소지금 1,000, T2 장비 | 예약 40% → 예산 600. 방어·회복 효율 장비 우선(08) | 예약 30% → 예산 700. 탐색·범용 장비 우선 | 예약 20% → 예산 800. 공격·핵심 조합 우선 |
| Lv16, EB01을 막 격파해 D2가 열림(D2 위험 차 +1, EB02 위험 차 +5) | 새 층 적응으로 D2(보통)에 무사 귀환 3회까지 들어간다. EB02는 한도 −1을 넘어 도전하지 않는다 | 목표 층 D2. EB02는 한도 +2를 넘어 도전하지 않는다 | 목표 층 D2. EB02는 한도 +5 안이므로 관문 앞 체력 조건(07 §5.6)을 만족하면 도전한다 |
| 사냥 중 피로 70 | 이미 60에서 귀환했다 | 야영 가능하면 야영, 아니면 귀환 | 계속(기준 80) |

`D1 방 3개` 줄의 E = 0.060은 07 §5.5 계산 예 1과 같은 층·같은 순번의 값이다. 가용 체력률에는 안정적 0개, 모험적 1개, 도전적 2개의 가장 큰 회복약만 넣는다(07 §5.5).

## 10 위험 정책과 사용자 개입

### 10.1 유효 위험 상한

```text
유효 위험 상한 = (방침 '위험 허용 상한' == 태도 기본) ? 태도 최대 위험 : 방침 값
태도 최대 위험: 안정적 보통 · 모험적 보통(모험 활동만 높음) · 도전적 높음
```

- 사용자는 태도보다 높은 상한을 줄 수 있다(예: 안정적 + 높음). 이때도 퇴각 기준과 07 §5.5의 던전 진입 계수는 태도 값을 쓴다.
- `무모`는 상한과 관계없이 자동 선택하지 않는다. 사용자가 목적지를 고정한 경우만 10.2절에 따라 경고 후 허용한다.
- H1과 A1은 상한과 관계없이 후보가 된다(4.2절 길드 순찰 구역).
- **치명**은 위험 등급과 별개다. `치명 위험 허용`이 켜져 있고 대상 `관문 전투`가 체크된 경우에만 EB03 관문에 자동 진입한다(07 §5.6, 01 §7.1 치명 관문 한도: 안정·모험 −1, 도전 +2).
- 첫 검증판의 치명 대상은 EB03 관문뿐이다. `운명 사건 선택지` 체크는 확장용으로 숨긴다(D26, 01 §18.2).
- 한 생애에서 처음으로 치명 관문에 자동 진입할 때 기본 창에 중요 표식을 한 번 띄운다. 진행을 멈추지는 않는다. 일지: `[중요] 방침에 따라 부서진 종 앞에 섰다.`

### 10.3 가호 (D78)

수치·목록은 01 §19가 소유한다. 이 절은 절차다.

1. **별빛**은 가문에 모인다(상한 3). 첫 가문은 1개로 시작하고, 계승 5단계 `출발`에서 +1, 극복 순간(01 §19)마다 +1(한 생애 2번까지) 차오른다. 쓰지 않은 별빛은 다음 세대로 넘어간다.
2. **걸어 두기**(최후의 순간·기적의 주사위·누그러뜨림): 걸 때 별빛을 떼고, 풀면 돌려준다. 같은 가호는 하나만 걸린다. 걸어 둔 뒤에 시작한 행동의 결과를 정할 때 조건이 오면 발동하고, 그때 사용 1번으로 센다. 생애가 끝날 때 발동하지 않은 걸어 둔 가호의 별빛은 가문에 돌려준다(상한 3).
3. **바로 쓰기**(상처 치유·숨은 길): 조건이 맞으면 즉시 효과가 난다. 상처 치유는 중상이 있을 때, 숨은 길은 별빛 길이 있는 사건의 선택 창에서만 쓴다.
4. **사용 상한**: 이번 생애에 쓴 수 + 걸어 둔 수 ≤ 3. 넘으면 단추를 흐리게 한다.
5. **최후의 순간을 지킨다**: 치명 활동의 HP 0에서 R01 방울 → 최후 판정 → 실패일 때만 발동한다(방울·판정이 먼저 막으면 별빛을 쓰지 않는다). 결과는 성공과 같은 처리(중상 + 탈출 + 일반 패배 손실)다. 생애 1번. **가호가 걸려 있어도 치명 관문 진입 판단(10.1절)은 바뀌지 않는다** — 인물은 가호를 모른다.
6. **기적의 주사위**: 다음 중요 판정(연속·운명 사건 판정, 부상 판정, 공포 판정)이 실패·대실패면 같은 난수 흐름으로 한 번 더 굴려 합계가 높은 쪽을 쓴다(05 §6.2). 성공하면 가호는 걸린 채 남는다.
7. **궂은일을 누그러뜨린다**: 다음 일반 패배(손실 없음, 부상 판정의 중상은 경상) 또는 사건이 입히는 부상(중상은 경상, 경상은 없음) 가운데 먼저 오는 한 번에 발동한다. 첫걸음의 보호(시작 축복)가 남아 있으면 그것이 먼저다.
8. **방침 `가호 자동 사용`**이 `최후의 순간만`이면 치명 관문에 들어가기로 한 순간 별빛이 2개 이상이고 사용 상한이 남았을 때 스스로 걸어 둔다. 기본은 끔이다.
9. **오프라인**: 걸어 둔 가호는 오프라인 정산에서도 같은 규칙으로 발동한다(13 §2). 바로 쓰는 가호와 시작 축복은 사용자가 있을 때만 쓴다.
10. **기록**: 인물은 알아채지 못한다. 새 태그를 만들지 않고 원래 태그에 `sub = blessing`과 `이상하게도 …` 문형(14 §5.1)으로 남긴다. 문장에 가호·별빛 같은 규칙 낱말을 쓰지 않는다.
