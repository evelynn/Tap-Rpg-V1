# 12 세대 계승과 가문

버전 0.2 · 작성일 2026년 9월 22일 · 상위 문서 00_문서지도.md, 01_핵심규칙_수치기준.md

한 인물의 생애가 끝난 뒤 다음 인물이 출발하기까지의 절차와, 세대를 넘어 남는 것과 남지 않는 것을 정한다. 가정 형성, 후계 후보 생성, 선천 특성 유전, 유품과 재산 정산, 가문 기록, 가문 해금을 다룬다. 원칙은 v0.1 §12의 한 줄로 요약된다. **"부모와 닮은 면이 있지만 다른 삶을 사는 인물"을 만들고, 세대 수만으로 강해지는 구조는 만들지 않는다.**

관련 문서: 01_핵심규칙_수치기준.md(§9.7 시작 소지품, §12.4, §14), 05_인물_성장_판정.md(§2.2 출생 능력치 분배), 06_특성.md(출생 추첨), 08_아이템_경제.md(§7 장비 평가, 판매가), 09_생애_노화_기연_변이.md(은퇴·사망·긴 잠·은퇴 역할), 10_사건_시스템.md(§7.3 미완 연속 사건, §9.2 플래그 종류), 11_사건_목록.md(S01·S02·S05 원문, 후손 반응 장면 원문), 13_오프라인_저장.md(자동 계승과 오프라인), 03_화면_UI_UX.md(계승 화면·가문 탭), 02_세계관_지역_인물.md(이름 풀, NPC 교대), 18_생애의_책.md(계승 2단계의 책 엮기, 선별 점수)

## 1 계승 절차

### 1.1 다섯 단계

v0.1 §12.1의 순서를 그대로 따른다. 1단계부터 5단계까지 인물 상태는 `계승 대기`이며 유효 진행과 나이는 멈춘다.

| 단계 | 이름 | 확정되는 데이터 | 사용자 입력 |
| --- | --- | --- | --- |
| 1 | 생애 종료 | 종료 유형(S03 은퇴 / S04 사망 / S08 긴 잠), 종료 나이·레벨·장소, 미완 연속 사건 정리, 방계·입양 후보 생성(직계가 없을 때), 넘길 유품·기념품 전환 대상 계산(§5.2·§5.3·§6.1, 4단계는 옮기기만 함) | 없음 |
| 2 | 마지막 일지와 업적 정리 | 생애의 책 엮기(18 §2.1: 별칭·업적 → 마지막 장 지정 → 책 → 일상 기록 정리), 가문 업적 판정, 도감·발견·인연 갱신, 별칭 부여, 가문 플래그 기록 | 책 보기(건너뛰기 가능) |
| 3 | 후계자 결정 | 후계자 1명 확정. 사망이면 그 전에 다음 세대 방침 확인(09 §5.5) | 후보 선택 |
| 4 | 유전과 유품 확정 | 유품 이전, 잠재 상태 계산, 돈 이전, 소멸 항목 제거, 출신 배경·이름·외형 확정 | 출신 배경·이름·외형(기본값 있음) |
| 5 | 새 인물의 출발 | 18세, 레벨 1, 출발 계절(부모 생애 종료 계절의 다음 계절), 방침 이어받기, 시작 축복(01 §19, D78), 별빛 +1, 출발 장면 | 시작 축복 고르기(고르지 않아도 됨), `출발` 확인 |

- 미완 연속 사건은 10 §7.3 규칙으로 닫고, 연대기에 `끝나지 않은 이야기`로 남긴다. C01만 가문 플래그 `fam.c01_unfinished`로 후계자가 **같은 단계부터 한 번** 이어받는다. C02는 후계자에게 다시 나오지 않는다(`fam.c02_unfinished`는 장면 반응만, 7.6절).
- 2단계의 별칭은 7.5절 규칙으로 정한다.

### 1.2 기다림과 자동 계승

| 방침 | 동작 |
| --- | --- |
| 자동 계승 끔(기본) | 1~2단계를 자동 처리한 뒤 3단계에서 사용자를 기다린다. 기본 창은 중요 표식과 `계승을 기다리는 중`만 보여준다. 대기에는 만료가 없다 |
| 자동 계승 켬 | 3단계에서 기본 후보(4.2절)를 고르고, 4단계는 모든 기본값으로 확정한 뒤 5단계로 넘어간다 |
| 오프라인 중 생애 종료 | 자동 계승이 켜져 있어도 후계자를 5단계 직전까지만 준비한다(3·4단계를 기본값으로 확정하고 `출발` 확인에서 멈춤). 남은 오프라인 시간으로 후계자의 생애를 진행하지 않는다(01 §15). 이 범위는 12가 소유하며 13이 따른다 |

- 자동 계승 여부와 무관하게 완료된 생애의 책(18)과 마지막 장은 가문 탭 서가에서 다시 볼 수 있다.
- 계승 화면을 닫았다 다시 열거나 프로그램을 재시작해도 후보, 특성, 유품 계산 결과는 바뀌지 않는다(10절).

### 1.3 출발 장면

5단계 출발 시 기본 창에 한 줄, 상세 일지에 두 줄을 남긴다.

- 한 줄: `[계승] {heir:은/는} {parent_call}의 수첩을 펼쳤다.`
- 상세: `첫 장에는 {first_page:이/가} 있었다.` — `first_page`는 이전 인물 연대기에서 가장 먼저 기록된 발견·유품·인연 중 하나다. 예: v0.1 §15.1 `[계승] 아린은 어머니의 수첩을 펼쳤다.` + 상세 `첫 장에는 폐광 지도가 있었다.`
- 출발 확정 때 앞 세대 책의 받은 사람 줄을 한 번 채운다(18 §7.2).
- **출발 풍경**(D76): 수첩 한 줄(ES16) 다음에 한 줄 `[계승] {heir:은/는} 마을 어귀를 나섰다.`를 남기고, 보이는 동안 계승 출발 장면 ES21(15 §9.3)을 그린다. 새 인물은 5단계 자동 장착을 마친 모습(유품 포함)으로 제자리 걷기를 하고, 은퇴한 부모가 살아 있으면(09 §4.1) 길가에서 손을 흔든다. 사망·긴 잠으로 끝난 생애면 부모 자리는 비어 있다. 오프라인 자동 계승은 `출발` 확인에서 멈추므로(1.2절) 이 풍경은 늘 사용자가 보는 앞에서 나온다.

### 2.2 S02 아이의 소식

| 항목 | 규칙 |
| --- | --- |
| 첫 번째 | S01 이후 유효 진행 12분(1년) 안의 첫 귀환에서 반드시 발생 |
| 추가 | 이후 마을 귀환마다 8% 확인. 최소 간격 36분(3년). 부모 45세 이하 |
| 횟수 | 1~3회, 회당 자녀 후보 1명. 첫 S02는 S01 뒤 반드시 일어난다. 자녀 후보 최대 3명(01 §14). S01은 자녀를 만들지 않는다 |
| 처리 | 자동 사건. 자녀 후보 1명을 생성하고(3절), 가문 탭 `다음 세대` 목록에 올린다 |

- 첫째 기록: `[가족] 작은 울음소리가 여관까지 들렸다. {child:이/가} 태어났다.`
- 둘째 이후: `[가족] {child:이/가} 가족이 되었다. 집이 조금 좁아졌다.`
- 자녀 후보는 생성 즉시 선천 특성과 **능력치 분배 난수**(05 §2.2의 5회 추첨에 쓸 난수)가 정해진다. 능력치 값은 4단계에서 출신 배경을 반영해 확정하며, 같은 배경을 고르면 항상 같은 값이 나온다. 부모가 살아 있는 동안 가문 탭에는 **경향 문장**으로만 보여준다. 예: TI02 보유 → `발소리를 누구보다 먼저 알아듣는다`, 힘이 가장 높음 → `물통을 번쩍 든다`.
- 부모 생애 중에 자녀의 어린 시절 기록이 가끔 나온다(마을 귀환 시 5%, 생애 최대 4회). 예: `[가족] {child:이/가} 처음으로 목검을 쥐었다.`

### 2.3 가정 형성을 끈 경우

방침 `가정 형성 끔`이면 S01·S02가 일어나지 않고, 생애 종료 1단계에서 방계 → 입양 순서로 후보를 만든다(3.3절). 후보가 없어서 진행이 끝나는 일은 없다(v0.1 §12.2).

| 경로 | 서술 | 유전 |
| --- | --- | --- |
| 방계 | 형제자매의 아이(조카) | 그 부모(형제자매)의 기록을 따른다. 이전 인물에게서 직접 물려받지 않는다 |
| 입양 | 가문이 맡아 키운 아이 | 생물학적 유전 없음 |
| 제자 | 길드가 추천한 견습생(입양 경로의 서술 변형, 33%) | 입양과 같다 |

## 3 후계 후보 생성

### 3.1 후보층

후보는 한 층에서만 나온다. 위 층에 한 명이라도 있으면 아래 층은 제시하지 않는다.

| 순서 | 후보층 | 생성 시점 | 인원 |
| --- | --- | --- | --- |
| 1 | 직계 자녀 | S02마다 1명 | 1~3 |
| 2 | 방계(조카) | 생애 종료 1단계 | 1명 60%, 2명 40%. 단 `형제자매 없음` 10%이면 0명 |
| 3 | 입양·제자 | 생애 종료 1단계(방계 0명일 때) | 1명 55%, 2명 45% |

### 3.2 직계 자녀의 선천 특성 유전

유전은 **출생 기록**의 선천 특성을 대상으로 한다. TA07로 대체된 TI07처럼 활성 목록에서 빠진 선천 특성도 대상이다(06 문서).

| 출처 | 대상 | 특성별 성공 확률 | 채택 상한 |
| --- | --- | --- | --- |
| 이전 플레이 인물 | 출생 기록 선천 특성(최대 3) | 긍정·혼합·성향 35%, 부정 18% | 1개 |
| 동반자 | 동반자 선천 특성(1~2) | 긍정·혼합·성향 35%, 부정 18% | 1개 |

```text
inherited = []
for 출처 in [이전 인물, 동반자]:
    성공 = [t for t in 출처.선천 if rand() < (0.18 if t.부정 else 0.35)]
    if 성공: inherited.append(random_choice(성공))
inherited = 중복 제거(inherited)          # 같은 특성이면 하나로 합침
신규 개수 = 06 §6.2 표(len(inherited))
신규 = 06 §6.3 가중치로 추첨(보유 특성 제외)
06 §6.4 금지 조합 검사 → 확정
```

- 이전 인물이 긍정 특성 2개를 가졌을 때 그중 하나 이상을 물려받을 확률은 약 58%다(1 − 0.65²).
- 부정 특성 TI05 하나만 가진 부모에게서 약한 폐를 물려받을 확률은 18%다.
- 유전된 특성은 출처를 저장한다: `{parent_call} {name}에게서`, `{partner}에게서`.

### 3.3 방계와 입양 후보의 특성

| 후보층 | 규칙 |
| --- | --- |
| 방계 | 먼저 형제자매 NPC를 만든다. 형제자매의 선천 특성 = 이전 인물의 출생 기록 중 **부모 출처** 특성 각 50% 공유 + 신규 1개(06 §6.3). 방계 후보는 형제자매로부터 3.2절 확률로 최대 1개, 형제자매의 배우자(자동 생성, 선천 1개)로부터 최대 1개를 물려받는다 |
| 입양·제자 | 유전분 0. 06 §6.2의 `유전분 0` 행으로 신규 특성만 뽑는다 |

- 방계 후보가 이전 인물과 같은 특성을 갖게 되는 경우는 형제자매를 거친 결과일 뿐이며, 이전 인물에게서 직접 물려받은 것으로 표시하지 않는다(v0.1 §12.3).

### 3.4 능력치 경향

- 출생 능력치는 **05 §2.2 분배 알고리즘**이 유일한 기준이다(모두 1에서 시작, 출신 배경 능력치에 1점 고정 + 나머지 4점 가중 추첨, 출생 최대 4). 12는 그 입력만 정한다.
  - 출신 배경의 고정 1점 능력치: 8.1절 표(여울의 아이는 무작위 — 5점 모두 추첨).
  - 직계 자녀의 부모 닮음 가중(이전 인물의 최고 능력치): 05 §2.2. 방계·입양에는 적용하지 않는다.
- 능력치는 4단계에서 출신 배경을 고른 뒤 확정한다. 후보 카드에는 그 전까지 경향 문장만 보인다.

### 3.5 외형과 가족 호칭

| 요소 | 직계 | 방계 | 입양·제자 |
| --- | --- | --- | --- |
| 머리색 | 이전 인물 50%, 동반자 35%, 무작위 15% | 이전 인물 25%, 무작위 75% | 무작위 |
| 머리 모양 | 무작위(15 문서 6종), 4단계에서 가문 해금 외형으로 바꿀 수 있음 | 같음 | 같음 |
| 눈 모양 | 이전 인물 50%, 무작위 50% | 무작위 | 무작위 |

- **가족 호칭**: 모든 인물은 자녀가 자신을 부르는 호칭을 하나 가진다. `어머니` 45%, `아버지` 45%, `부모님` 10%로 무작위 생성하고, 인물 탭에서 바꿀 수 있다. 문장 템플릿은 `{parent_call}` 변수로 쓴다(후계자가 이전 인물을 부르는 호칭). 이 규칙은 12가 소유하며 14는 이 변수를 쓴다. 이 게임은 인물의 성별 체계를 따로 두지 않는다.
- 방계 후보가 이전 인물을 부르는 호칭은 `이모`, `삼촌`, `큰 어른` 중 이전 인물 호칭에 맞춰 고른다(어머니 → 이모, 아버지 → 삼촌, 부모님 → 큰 어른). 입양·제자는 `스승님` 또는 이전 인물 호칭을 그대로 쓴다(50%씩).

### 3.6 이름 추천

- 02 문서 이름 풀에서 3개를 추천한다. 새 인물 바로 앞 5대(이전 인물 포함) 가문 인물 이름(02 §9.1)과 이전 두 세대 동반자 이름은 제외한다. 그보다 오래된 이름은 다시 나올 수 있다(풀 56개를 영구히 줄이면 20여 대에 바닥난다).
- 사용자는 직접 입력할 수 있다. 입력 이름은 1~6자, 가문 안 중복 금지.

### 3.7 후보 카드

```text
┌ 리아 · 첫째 아이 ──────────────────────┐
│ [초상]  ● 튼튼한 체질 ⁂  어머니 모라에게서 │
│         ● 호기심 많음 ⁂  보리에게서       │
│ 힘이 세다 · 눈치가 빠르다                │
│ 출신 배경 [광부 집안 ▾]                 │
│                              [이 아이로] │
└────────────────────────────────────────┘
```

- 3단계 후보 카드는 기본 배경(`여울의 아이`) 기준 능력치를 보여주고, 4단계에서 배경을 바꾸면 그 배경 기준 값으로 다시 보여준다(부모 생애 중에는 경향 문장만).
- 유전된 특성은 출처를, 신규 특성은 `타고남`을 적는다.

## 4 후계자 결정

### 4.1 제시

- 후보는 최대 3명이다(3.1절 후보층 하나에서만).
- 3단계 화면 상단에 한 줄로 후보층을 설명한다: `직계 자녀가 모험을 이어받습니다.` / `{name}에게는 자녀가 없어 조카가 뒤를 잇습니다.` / `가문이 맡아 키운 아이가 뒤를 잇습니다.`

### 4.2 기본 후보

1. 생전에 가문 탭에서 지정한 후보.
2. 지정이 없으면 가장 먼저 소식이 온 자녀(직계), 또는 후보 목록의 첫 번째(방계·입양).

자동 계승은 기본 후보를 고른다. 기본 후보는 특성 점수로 고르지 않는다. 자동 계승이 "가장 좋은 특성" 선택기가 되지 않게 하기 위해서다.

### 4.3 이른 생애 종료와 시간 도약

연대기는 절대 연도를 쓰지 않는다(D05). 대신 자녀가 아직 어릴 때 생애가 끝난 경우를 다음 규칙으로 서술한다.

| 조건 | 처리 |
| --- | --- |
| 직계 후계자의 S02 이후 유효 진행 216분(18년) 미만에 부모 생애 종료 | 5단계 출발 장면 앞에 시간 도약 서술 1줄 |
| 그 외 | 시간 도약 서술 없음 |

- 시간 도약 서술: `[계승] 열여덟 해가 지나는 동안 {guardian:이/가} {heir:을/를} 길렀다.` — `guardian`은 동반자, 없으면 N04 도담.
- 시간 도약은 돈, 장비, 경험치, 숙련, 모험 보상을 **만들지 않는다**(v0.1 §12.2). 돈 이전과 유품은 일반 규칙 그대로다.
- 연대기 기록 형식은 `제{n}대 {name} ({start}~{end}세)`이며 세대 사이의 햇수를 적지 않는다.

### 5.1 등록

| 항목 | 규칙 |

| 변경 | 마을에 있을 때만(마을 대기·정비). 출정 중 변경 불가 |

| 안내 | 65세 도달 시 1회, 치명 위험 허용을 처음 켤 때 1회 `남길 물건을 정해 두세요` 안내 |
| 표시 | 인물 탭 장비 이름 앞에 `유품 1`, `유품 2` 표식 |

### 5.2 이전

| 종료 유형 | 이전 개수 | 대상 |
| --- | --- | --- |
| 은퇴(S03), 긴 잠(S08) | 2개 | 등록 1·2위. 빈 자리는 자동 선택으로 채움 |
| 사망(S04) | 1개 | 등록 1위. 등록이 없으면 자동 선택 1개. 길드가 회수하는 서술(09 §5.3) |

- F02 `마신다`로 바친 유물이 등록 유품이었다면 그 자리는 비고, 은퇴 시 자동 선택으로 채운다.
- 이전된 유품은 후계자 가방에 들어가고, 5단계에서 자동 장착 판단을 한다(08 §7 장비 평가, 저주 장비는 자동 장착하지 않음).

### 5.3 자동 선택 기준

```text
유품 점수 = 등급 점수 + 고유 보너스 + 단계 값 + 사연 점수
  등급 점수  : 일반 1, 좋은 3, 희귀 6, 전설 10
  고유 보너스 : 고유 장비 +4
  단계 값    : T1~T5 → 1~5
  사연 점수  : min(5, 착용 누적 유효 진행 분 ÷ 60) + min(3, 이 장비가 등장한 [장비]·[중요]·[인연] 기록 수)
제외 : 저주 장비, 이미 등록된 유품
동점 : 무기 > 유물 > 장신구 > 방어구 → 먼저 얻은 것
```

- 무기를 우선하는 이유는 v0.1 마지막 문장의 장면("부모의 검을 들고 걷는 모습")이 가장 잘 보이기 때문이다.

### 5.4 변이 효과 제거

장비 효과 중 **변이 조건부 효과**(예: R04의 흡혈귀 저주 면제)는 이전 시 사라진다. 장비의 이름, 외형, 사연은 그대로다. 09 §7.10 체크리스트와 같은 항목이다.

### 5.5 잠재 상태

01 §14: 유품 단계가 후계자의 레벨 기준 단계(T1 1~5, T2 6~11, T3 12~17, T4 18~23, T5 24~30)보다 높으면 성능을 레벨 기준 단계의 같은 등급 값으로 제한한다.

| 요소 | 잠재 상태 | 개방(레벨 기준 단계 = 유품 단계) |
| --- | --- | --- |
| 이름·외형·사연 | 처음부터 유지 | — |
| 무기 피해·방어구 방어·체력 | 레벨 기준 단계의 같은 등급 값 | 원래 값 |
| 등급 명중·방어 보정 | 유지 | 유지 |
| 특수 효과 | 잠듦 | 깨어남 |
| 장신구·유물 효과 | 잠듦(효과 자체가 성능) | 깨어남 |
| 저주 효과 | 잠듦 | 깨어남 |

- 표시: 이름 뒤 `(잠든 힘)`. 항목을 누르면 `레벨 {n}에 깨어납니다`.
- 개방 기록: `[장비] {item:이/가} 손에 맞기 시작했다.` 상세 기록 `{parent_call}의 검이 맑게 울렸다.`
- 레벨 기준 단계가 한 칸 오를 때마다 제한값도 한 칸 오른다.
- 값 계산의 반올림은 08 문서 규칙을 따른다. 아래 예시는 `반올림, 0.5는 올림`으로 계산했다.

**예시 1 — W07 종이 달린 짧은 검(T3 희귀 고유)을 레벨 1 후계자가 받음**

| 후계자 레벨 | 적용 단계 | 피해(희귀 ×1.3) | 명중 보정 | 특수 효과 |
| --- | --- | --- | --- | --- |
| 1~5 | T1 | 2~5 → 3~7 | +1 | 잠듦 |
| 6~11 | T2 | 5~10 → 7~13 | +1 | 잠듦 |
| 12 이상 | T3(개방) | 8~16 → 10~21 | +1 | 공포 판정 +2, 종소리로 매복 1회 무효 |

비교: 같은 시점 W01 녹슨 검은 1~4, 명중 0이다(01 §10, D16). 잠재 상태의 W07도 T1 구간에서는 가장 좋은 무기이며, 개방 전까지 "좋지만 특별하지는 않은 검"으로 쓰인다.

**예시 2 — W10 파수꾼의 종추(T5 전설 고유)를 레벨 1 후계자가 받음**

| 후계자 레벨 | 적용 단계 | 피해(전설 ×1.45) | 명중 보정 | 특수 효과 |
| --- | --- | --- | --- | --- |
| 1~5 | T1 | 2~5 → 3~7 | +2 | 잠듦 |
| 6~11 | T2 | 5~10 → 7~15 | +2 | 잠듦 |
| 12~17 | T3 | 8~16 → 12~23 | +2 | 잠듦 |
| 18~23 | T4 | 12~22 → 17~32 | +2 | 잠듦 |
| 24 이상 | T5(개방) | 17~29 → 25~42 | +2 | 관문 첫 라운드 적 명중 −3, 공포 면역 |

전설 유품도 후계자의 초반을 건너뛰게 하지 않는다. 각 구간에서 같은 단계 좋은 장비(×1.15, 명중 +1)보다 조금 나은 정도다.

### 5.6 유품이 돌아오는 순간

물려받은 유품을 찬 후손이 아래 순간을 맞으면 `[장비]` 기록 한 줄을 더한다(D76). 물건이 세대를 건너 같은 자리로 돌아오는 사연을 남긴다.

| 항목 | 규칙 |
| --- | --- |
| 대상 | 5.2절로 이전받아 **착용 중인** 유품(이전 세대 어느 쪽이든) |
| 순간 | ① 관문 첫 격파(`[던전]` gate_first) ② 최후 판정 성공(07 §8) |
| 횟수 | 생애마다 유품 하나당 1회. 두 유품이 같은 순간이면 하나만 남기고, 고르는 순서는 5.3절 동점 순서(무기 > 유물 > 장신구 > 방어구)다. 다른 유품은 다음 순간에 남는다 |
| 문형 | 14 §5.1 `[장비]` 유품 귀환. `sub` = `relic_return`(16 §5.6), `refs.item_uid` = 그 유품 |
| 오프라인 | 같은 규칙으로 남긴다(13) |

## 6 재산 정산

### 6.1 공식

```text
정산 총액 = 소지금
          + Σ(착용·가방·창고·수령 대기함의 유품 아닌 일반·좋은 장비 판매가)
이전액    = min(⌊정산 총액 × 비율⌋, 360)
비율      : 은퇴·긴 잠 20%, 사망 10%
```

- 판매가는 08 장비 표의 판매가를 그대로 쓴다(기준 구매가 × 25%, 08의 반올림). TA06 판매가 보정은 정산에 적용하지 않는다(생애가 끝났으므로).
- **소모품(CP01~CP08)은 정산하지 않는다.** 08의 "소모품은 되팔 수 없다" 규칙을 따른다. 생애 종료 시 사라진다.
- **희귀 이상·고유 장비 중 유품이 아닌 것**은 정산하지 않고 `기념품`으로 바꾼다. 기념품은 가문 탭 `기념품 선반`에 이름·외형·사연으로 전시되며 성능이 없고 장착할 수 없다.
- 잠긴 장비, 착용 중 장비도 정산 대상이다. 잠금은 자동 판매만 막을 뿐 계승 정산을 막지 않는다.
- 후계자 시작 소지금 = 01 §9.7 시작 소지품의 동전 30 + 이전액. 시작 소지품의 회복약·식량·W01·A01도 함께 받는다(유품이 같은 슬롯이면 W01·A01 대신 유품).

### 6.2 예시

**은퇴(20%)**

| 항목 | 값 |
| --- | --- |
| 소지금 | 1,240 |
| A07 종지기의 청동 흉갑(T5 일반, 착용) | 1,688(08 표 판매가) |
| W08 은빛 광맥 장검(T4 좋은, 가방) | 1,650(08 표 판매가) |

| 회복약 T5 × 2 | 소모품, 정산 제외(사라짐) |
| J05 속삭이는 종 조각(희귀 고유, 수령 대기함) | 기념품 전환, 정산 제외 |
| 정산 총액 | 4,721 |
| 20% | 944 |
| **이전액** | **360(상한)** |

**사망(10%)**

| 항목 | 값 |
| --- | --- |
| 소지금 | 410 |
| 가방 장비 2개 판매가 합 | 380 |

### 6.3 우회 방지

| 우회 시도 | 막는 규칙 |
| --- | --- |
| 창고·수령 대기함에 장비를 모아 두고 넘기기 | 모두 같은 세대 자산으로 통합 정산. 실물 장비로 넘어가는 것은 유품 2개(사망 1개)뿐 |
| 장비를 잠가 두기 | 잠금은 계승 정산을 막지 않는다 |
| 생애 끝에 고가 장비를 사서 판매가로 넘기기 | 이전액 상한 360 |
| 유품 등록 교체로 더 넘기기 | 생애 종료 후 등록 변경 불가. 개수 상한 고정 |
| 기념품을 다시 장비로 | 기념품은 장착·판매·재전환 불가 |
| 은퇴 부모에게 물건 맡기기 | 은퇴 인물은 NPC다. 물건을 주고받는 기능이 없다(S07 선물은 고정 목록) |

```text
  마지막 기록 [은퇴] 리아는 오늘부터 길드 앞 작은 여관을 맡기로 했다.
```
- 주요 기록은 `[중요]`, `[인연]`, `[발견]` 첫 기록, 유품 획득, 특성 변화, 운명 사건 결과에서 18 §4.1 선별 점수 상위 `n = min(후보 수, clamp(점수 5 이상 후보 수, 4, 6))`개(맺는 장 기록 제외, 동률은 18 §4.1)를 고른다. 점수 5 이상이 4개 미만이면 다음 점수 순으로 4개까지 채우고, 6개를 넘으면 6개에서 자른다. 후보가 4개 미만이면 있는 만큼 싣는다.
- 연대기는 영구 보존한다. 일상 기록의 보존 정책은 13 문서를 따른다.
- 끝난 생애는 서가에 생애의 책으로 꽂힌다(18).

### 7.3 인연 기록

- NPC 9명(01 §13)과 가문 인물의 동반자들을 목록으로 보여준다.
- 항목마다 처음 만난 인물·나이, 마지막 사건, 가문 플래그 한 줄을 적는다. 예: `세나 — 모라가 36세에 아버지의 흔적을 찾아 주었다. 가문을 기억한다.`

### 7.4 발견 지도

- 가문이 발견한 장소는 후손에게 `알려진 장소`로 표시된다.
- 01 §8.1 해금 조건 중 **발견형 조건**(`A1 발견`, `A2에서 폐광 입구 발견`)은 후손에게 면제된다. **레벨·길드 등급·관문 격파 조건은 그대로**다. v0.1 §12.5의 "길의 존재를 알지만 실제 출정에는 자신의 준비가 필요하다"를 규칙으로 옮긴 것이다.
- 예: 가문이 폐광 입구를 발견했다면 후손은 A2를 거치지 않고 동패(레벨 6)가 되자마자 D1에 들어갈 수 있다.

### 7.5 별칭

별칭의 종류·조건·부여 시점은 이 절이 **단일 출처**다(00 §2.4). 02 §9.3은 별칭이 세계 안에서 불리는 방식만 적고, 09는 이 표를 참조한다.

- **부여 시점**: 생애 종료 2단계에서 한 번. 아래 표의 위에서부터 조건을 확인해 첫 번째로 맞는 별칭 1개를 준다. 생애 도중에는 별칭을 붙이지 않는다.
- 별칭은 연대기 제목, 가계도, 여행 수첩의 이름 항목에 쓴다. 능력치나 판정에는 영향이 없다.

| 순위 | 조건 | 별칭 |
| --- | --- | --- |
| 1 | TM01 보유 + 이전 인물의 R04를 유품으로 받음 | `{parent_call}의 잔을 비운 {name}` |
| 2 | TM01 보유 | `달그늘의 {name}` |
| 3 | EB03 격파 | `종지기 {name}` |
| 4 | F02 마심 | `별잠의 {name}` |
| 5 | F02 양보 | `샘을 양보한 {name}` |

| 7 | TA01 보유 | `다리의 은인 {name}` |
| 8 | D3에서 사망 | `심층에 잠든 {name}` |
| 9 | D3 무사 귀환 10회 이상 | `폐광의 {name}` |
| 10 | 길드 별패 도달 | `별패 {name}` |

- 1순위처럼 `{parent_call}`을 쓰는 별칭은 앞 세대가 있는 인물(2대 이후)에게만 준다. 앞 세대 호칭이 없으면 그 순위를 건너뛰고 다음 순위를 본다(빈 호칭으로 `의 잔을 비운 …`이 되지 않게).
### 7.6 후손 반응 플래그

이 표가 후손 반응의 **유일한 정의**다(00 §2.4, D29). 10 §9.3과 02의 NPC 후손 세대 서술은 이 표를 참조한다. 반응 장면의 문장 원문은 11이 쓴다.

**원칙**

1. 가문 플래그는 능력치, 동전, 장비, 판정 보정, 이동·발견 보정을 **주지 않는다.** 장면, 문장, 선택지만 바꾼다(v0.1 §11.4).
2. 플래그 자체는 가문 기록에 **영구** 보존한다(연대기·인연 기록).
3. 반응이 **일어나는 기간**은 아래 `반응 기간` 열이 정한다. 세대는 플래그를 남긴 인물의 다음 세대를 1로 센다. 반응을 맡는 NPC는 02 §8.10 교대 규칙대로 그 대수의 담당자다.
4. 플래그 키 형식은 `fam.snake_case`다(16 §플래그 키 등록표).

| --- | --- | --- | --- |
| `fam.c01_rescue` | C01-3 구조 | `감사의 식탁` 마을 장면: 후손이 **D1에 처음 들어간 뒤 첫 마을 귀환** 때 광부 집안이 식탁에 부른다. 1세대(2대)는 노년의 세나와 아들 도윤, 2~3세대는 도윤이 맡는다. 기록 `[인연] 광부의 딸이 기억하고 있었다.` 상세 `"우리 집을 도운 분과 닮았네요."`(도윤이면 `광부의 아들이 기억하고 있었다.`) | 3세대 |

## 8 가문 해금

가문 해금은 **선택의 폭**을 넓힌다. 능력치 총합, 레벨, 장비 성능을 올리는 해금은 없다(v0.1 §12.5).

### 8.1 출신 배경

4단계에서 해금된 배경 하나를 고른다. 효과는 시작 숙련 1단계 1개와 능력치 1점 고정(05 §2.2)이다. 능력치 총합은 모든 배경이 같다(11).

| 배경 | 시작 숙련 | 능력치 1점(05 §2.2) | 해금 조건(가문 업적) | 출발 서술 |
| --- | --- | --- | --- | --- |
| 여울의 아이 | 없음 | 무작위(5점 모두 추첨) | 처음부터 | `여울가 풀밭에서 뛰놀며 자랐다.` |
| 여관집 아이 | 교섭 1단계 | 사교 | 업적 10 | `'도토리 모자' 부엌에서 손님 이야기를 들으며 자랐다.` |
| 대장간 도제 | 근접 1단계 | 힘 | 업적 9 | `보름의 망치 소리를 자장가 삼아 자랐다.` |
| 길드 사환 | 탐색 1단계 | 지식 | 업적 4 | `하델의 심부름으로 게시판을 오가며 자랐다.` |
| 광부 집안 | 생존 1단계 | 의지 | 업적 6 | `세나네 광부들 틈에서 등불 켜는 법을 배웠다.` |

- 출생 최대 4 규칙은 05 §2.2 분배 알고리즘이 지킨다(값이 4인 능력치는 후보에서 빠진다).
- 시작 숙련 1단계는 누적 사용 횟수 15로 시작하는 것과 같다(01 §2.3).

## 9 계산 예시 — 모라에서 리아로 (v0.1 §17)

이 절은 문서 묶음 전체의 **기준 시나리오**다(00 §2.4). 다른 문서(03, 05, 13, 14, 16)의 모라·리아 예시는 이 값에 맞춘다.

### 9.1 모라(1대)의 생애 요약

| 항목 | 값 |
| --- | --- |
| 선천 특성 | TI01 튼튼한 체질, TI08 대식가(타고남) |
| 가족 호칭 | 어머니 |
| 태도 | 안정적 → 모험적(29세) |
| 전문화 | 수호자(25세) |
| S01 | 28.4세, 배우자 `보리`(약초꾼, 선천 TI06 호기심 많음) |
| S02 | 29.2세 첫째 `리아`, 37.5세 둘째 `하온` |
| 주요 사건 | C01-3 구조(36세) → TA01, W07 획득. EB02 격파(47세). F02 양보(60세) |
| 목적지 고정 | 34세에 C01-2를 마친 뒤 사용자가 목적지를 D2로 고정했다(위험 차 +3, `높음` 경고 1회 후 허용, 01 §7.1). 그래서 모험적 표준(38.5세, 09 §9)보다 이른 36세에 C01-3에 닿았다. C01-3 뒤 목적지를 `자동`으로 되돌렸다 |
| 가문 플래그 | `fam.c01_rescue`, `fam.f02_gave_yuan`, `fam.specialist_guardian`, `fam.retired_{role}`(길드 교관) |
| 후천 특성 | TA01 다리의 은인, TA04 여울의 단골, TA05 백전의 감각 |
| 종료 | 68세 은퇴, 레벨 26 |

### 9.2 자녀 후보 생성 (S02 시점)

| 후보 | 모라 출처 굴림 | 보리 출처 굴림 | 유전분 | 신규 개수 굴림 | 결과 |
| --- | --- | --- | --- | --- | --- |
| 리아 | TI01 성공(0.21 < 0.35), TI08 실패(0.62) → TI01 | TI06 성공(0.30) → TI06 | 2 | 신규 0(60% 구간) | TI01, TI06 |
| 하온 | TI01 실패(0.71), TI08 성공(0.12) → TI08 | TI06 실패(0.88) | 1 | 신규 1(50% 구간) → TI02 | TI08, TI02 |

리아는 v0.1 §17대로 "부모의 튼튼한 체질을 물려받았지만 호기심이 많다". 모라의 레벨과 후천 특성(TA01, TA04, TA05)은 물려받지 않는다.

### 9.3 은퇴 역할 (09 §4.1)

| 역할 | 점수 |
| --- | --- |
| 작은 여관 주인 | TA04 +2, TI08 +1, 여관 휴식 60회 이상 +1 = 4 |
| 길드 교관 | 근접 4단계 +1, TA05 +2, 수호자 +1, EB02 격파 +1 = **5** |
| 편지를 보내는 가족 | 기본 1 + S01 +1 + 60세 이후 은퇴 +1 = 3 |

→ 모라는 **길드 교관**이 된다. 리아는 30세까지 교육 사건 2회(근접·탐색 각 +20회)를 받는다.

### 9.4 유품

| 순위 | 장비 | 이전 | 리아 레벨 1 시점 |
| --- | --- | --- | --- |
| 1 | W07 종이 달린 짧은 검(T3 희귀 고유) | 이전 | 피해 3~7, 명중 +1, 특수 효과 잠듦(레벨 12에 개방) |
| 2 | J04 광부의 등불(T3 좋은) | 이전 | 효과 잠듦(레벨 12에 개방). 외형은 허리춤 등불로 보인다 |

- 리아는 출발 시 W01 대신 W07을 장착한다(3~7·명중 +1 > 1~4·명중 0). 유품이 무기 칸을 채우므로 시작 소지품의 W01은 받지 않는다(01 §9.7).
- J04는 효과가 잠들어 있지만 비어 있는 장신구 칸에 장착한다(손해가 없으므로).

### 9.5 재산

6.2절 은퇴 예시와 같다. 정산 총액 4,721 × 20% = 944 → **360동전**(상한). 회복약 T5 2개는 소모품이라 정산 없이 사라진다. J05 `속삭이는 종 조각`은 기념품 선반으로 간다.

### 9.6 출발

| 항목 | 값 |
| --- | --- |
| 출신 배경 | 광부 집안(업적 6 해금) → 생존 1단계, 능력치 1점 의지(05 §2.2) |
| 능력치 | 05 §2.3 예시: 배경 1점 의지 1 → 2. 가중치 힘 10 + 5(TI01) + 3(모라 최고 능력치 힘) = 18, 민첩 10, 지식 10 + 5(TI06) = 15, 의지 10 + 5(TI01) = 15, 사교 10, 행운 6 + 5(TI06) = 11. 추첨 4회(힘, 민첩, 힘, 행운) → **힘 3 · 민첩 2 · 지식 1 · 의지 2 · 사교 1 · 행운 2** (합 11) |
| 태도 | 도전적(사용자가 바꿈) |
| 출발 계절 | 모라 은퇴가 가을 → 겨울 |
| 소지품 | 동전 30(01 §9.7) + 360 = **390동전**, 회복약 T1 2개, 야영 식량 2개, A01 누빈 천옷, 유품 W07·J04 |
| 출발 기록 | `[계승] 리아는 어머니의 수첩을 펼쳤다.` 상세 `첫 장에는 폐광 지도가 있었다.` |

### 9.7 폐광의 후손 반응

- `fam.c01_rescue`(반응 1세대째): 리아가 D1에 처음 들어간 뒤 첫 마을 귀환 때 `감사의 식탁` 마을 장면이 나온다. 노년의 세나가 아들 도윤과 함께 리아를 식탁에 부른다. `[인연] 광부의 딸이 기억하고 있었다.` 상세 `"우리 집을 도운 분과 닮았네요."`(v0.1 §15.1). 모라가 C01을 완료했으므로 리아의 생애에 C01-1~3은 다시 나오지 않는다(10 §7.1).
- `fam.f02_gave_yuan`(반응 1세대째): 리아가 A3와 A4에 처음 들어갈 때 유안이 나타나 길을 안내하는 장면이 나온다(수치 보정 없음). 리아가 50세 이후 F02를 만나면 `유안에게 묻는다` 선택지가 생긴다.
- 발견 지도: 모라가 폐광 입구를 발견했으므로 리아는 동패(레벨 6)가 되면 A2를 거치지 않고 D1에 들어갈 수 있다(7.4절).
- 가문 연대기에는 v0.1 §17의 마지막 문장처럼 "두 사람이 같은 검으로 걸었던 서로 다른 길"이 두 항목으로 남는다.

## 10 악용 방지 요약

| 악용 | 규칙 | 근거 절 |
| --- | --- | --- |
| 조기 은퇴 반복으로 보상 수집 | 조기 은퇴 25세 이상, 업적·해금에 은퇴·세대·생애 수 조건 없음, 은퇴는 자원을 만들지 않음 | 09 §3.4, 8.4 |
| 계승 화면 재진입·재시작으로 후보 다시 뽑기 | 후보·특성·능력치 분배 난수는 생성 시점에 확정해 저장. 난수 시드는 생성 시 소모하고 다시 쓰지 않음(13 문서) | 2.2, 3 |
| 가정 형성 끔으로 후보층 바꾸기 | 후보층은 생애 종료 시점의 가족 기록으로 정한다. S01 이후 방침을 꺼도 이미 생긴 자녀가 후보다 | 3.1 |
| 입양 반복으로 부정 특성 세탁 | 입양은 직계·방계가 없을 때만. 입양 후보의 신규 특성 분포는 첫 인물과 같아 긍정 특성이 더 잘 나오지 않는다 | 3.1, 3.3 |
| 창고·수령 대기함·잠금으로 장비 넘기기 | 통합 정산, 실물 이전은 유품 2개(사망 1개)뿐 | 6.3 |
| 고가 장비 매입 후 판매가 정산 | 이전액 상한 360 | 6.1 |
| 전설 유품으로 초반 건너뛰기 | 잠재 상태 | 5.5 |
| 은퇴 부모 효과 누적 | 후계자 30세까지, 한 숙련에 한 번, 능력치·특성·종족 보너스 없음 | 09 §4.1 |
| 자동 계승을 특성 선택기로 쓰기 | 기본 후보는 특성 점수가 아니라 생전 지정 또는 첫째 | 4.2 |
| 시작 축복 `타고난 재능` 후보 다시 뽑기 | 후보 3개는 계승 계획을 만들 때 확정해 저장한다. 축복으로 얻은 특성은 유전하지 않는다 | 1.1, 01 §19 |
| 걸어 둔 가호 되돌려 받기 반복 | 풀면 별빛만 돌아오고 사용 수는 발동 때만 센다. 생애 사용 상한 3은 걸어 둔 수를 포함한다 | 04 §10.3 |
