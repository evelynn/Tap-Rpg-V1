# 텝 게임 기획 및 설정 문서

버전 0.1 · 작성일 2026년 9월 22일 · 프로젝트 가칭 텝

**작업 화면 한쪽에서 작은 SD 모험가가 스스로 살아가고, 그 삶의 특성과 유품이 다음 세대의 모험으로 이어지는 방치형 판타지 RPG.**

플레이어는 모험가의 성장 방향과 위험을 감수할 태도를 정한다. 모험가는 사냥하고, 쉬고, 장비를 마련하고, 던전을 탐험한다. 평소에는 짧은 동작과 한 줄 기록으로 자신의 삶을 보여주며, 운명을 바꿀 만한 순간에 플레이어의 결정을 기다린다.

이 문서는 세계관, 반복 플레이, 성장, 아이템, 수명, 사건, 세대 계승, 화면 구성과 콘텐츠 제작 범위를 구체화한 초기 기획안이다. 수치와 추가 설정은 검증 전 제안이며, 실제 플레이를 통해 조정한다. 구현 기술이나 출시 일정은 확정하지 않는다.

## 1 게임의 중심 경험

게임을 켜두고 다른 일을 하다가 잠깐 시선을 옮기면, 작은 모험가가 모닥불 옆에서 졸거나 검을 휘두르고 있다. 조금 뒤에는 낡은 투구가 새 투구로 바뀌어 있다. 기록을 열면 그 사이에 무슨 일이 있었는지 알 수 있다.

한 인물을 오래 지켜보면 전투력뿐 아니라 성격과 사연이 쌓인다. 결국 그 인물은 은퇴하거나 죽고, 다음 세대는 부모의 버릇과 오래된 장비를 물려받아 다른 길을 걷는다. 장기적인 수집 대상은 장비 도감과 함께 **우리 가문의 연대기**다.

### 1.1 지켜야 할 원칙

1. **곁에 두는 즐거움** — 조작하지 않아도 표정, 움직임, 장비 변화만으로 캐릭터의 상태와 성장을 느낀다.
2. **방향을 정하는 재미** — 클릭 속도보다 태도와 위험 정책, 중요한 사건에서의 선택이 삶을 바꾼다.
3. **읽고 싶어지는 기록** — 같은 보상이라도 인물의 특성과 과거 사건에 따라 다른 사연으로 남는다.
4. **끝이 있는 인물과 이어지는 가문** — 현재 인물의 성장은 유한하지만 발견과 기억은 다음 세대로 이어진다.
5. **작업을 방해하지 않는 진행** — 보지 않았다는 이유로 중요한 선택권이나 한정 보상을 빼앗지 않는다.

### 1.2 사용자가 제시한 핵심과 구체화 방향

| 핵심 아이디어 | 기획에서의 구체화 |
| --- | --- |
| 작업 표시줄 정도의 작은 화면 | 화면 가장자리에 붙이는 낮고 긴 독립 창과 필요할 때 여는 상세 창 |
| 귀여운 SD 캐릭터와 많은 스프라이트 | 작은 기본 몸체에 머리, 장비, 효과를 조합하는 애니메이션 구성 |
| 자동 사냥과 휴식, 던전, 모험 | 생존 조건을 먼저 확인하고 태도에 따라 다음 행동을 고르는 생활 순환 |
| 안정적, 모험적, 도전적 성장 | 행동 비중, 던전 진행 깊이, 퇴각 기준, 사건 선택 기준의 차이 |
| 파밍과 자동 구매 | 활동별 보상 차이와 예산을 지키는 자동 장비 교체 |
| 노화와 은퇴 | 한 세대에 시작과 전성기, 노년과 마무리가 있는 생애 구조 |
| 수명 연장과 종족 변이 | 현재 생애에만 적용되는 희귀한 기연과 그에 따르는 대가 |
| 자동 사건과 특별한 사용자 선택 | 일상은 자동 처리하고 운명을 바꾸는 사건은 보류 가능한 선택으로 제시 |
| 랜덤성과 사망 후 계승 | 세대마다 바뀌는 조건, 부모의 일부 특성, 제한된 유품, 영구 연대기 |

## 2 플레이어의 역할과 사용 흐름

플레이어는 한 모험가를 실시간으로 조종하는 대신, 여러 세대의 여정을 지켜보는 **가문의 길잡이**다. 화면의 주인공은 한 번에 한 명이며, 다른 가족은 기록과 계승 후보로 등장한다.

플레이어가 자주 바꾸는 것은 태도다. 안정적으로 돈을 모으게 하거나, 낯선 곳을 돌아다니게 하거나, 어려운 던전에 도전하게 할 수 있다. 장비 구매와 회복은 기본적으로 자동이다. 장비를 직접 지정하는 기능은 선택 사항이다.

### 2.1 첫 실행

1. 가문 이름과 첫 인물의 이름, 기본 외형을 정한다. 무작위 생성도 가능하다.
2. 안정적, 모험적, 도전적 태도 중 하나를 고른다. 기본 제안은 모험적이다.
3. 캐릭터가 마을 외곽에서 쉬운 사냥을 시작한다.
4. 약 5분 안에 첫 장비 교체와 작은 사건을 경험한다.
5. 약 10분 안에 판정 기록, 태도 변경, 귀환과 휴식을 확인한다.

첫 위험 활동 전에 퇴각과 부상 회복을 짧게 안내한다. 첫 실행부터 복잡한 특성 조합이나 여러 구매 조건을 설정하게 하지 않는다.

### 2.2 확인하는 시간에 따른 경험

| 확인 시간 | 플레이어가 얻는 정보와 할 일 |
| --- | --- |
| 3초 | 무엇을 하는지, 건강한지, 중요한 선택이 있는지 확인 |
| 30초 | 최근 요약을 읽고 태도나 다음 목적지 변경 |
| 2분 | 특수 사건 선택, 장비와 특성 확인, 다음 세대 후보 검토 |
| 오래 열어둔 경우 | 상세 기록, 도감, 가계도를 읽고 캐릭터의 삶을 관찰 |

반복 클릭, 접속 시간 보상 수령, 매일 해야 하는 숙제는 기본 순환에 넣지 않는다. 사용자가 명시적으로 일시정지하면 모든 진행과 노화가 멈춘다.

## 3 세계관과 정서

### 3.1 세계의 기본 설정

세계 곳곳에는 오래된 길이 사라지고 새로운 길이 나타나는 현상인 **길바뀜**이 일어난다. 같은 숲도 세대가 바뀌면 다른 폐허와 연결되고, 이전에 봉인한 던전에서 새로운 입구가 발견된다. 지역의 얼굴은 익숙하지만 탐험 순서, 내부 구조, 사건과 보물은 달라진다.

모험가 길드는 이러한 변화를 조사하고 길을 유지한다. 평범한 모험가들은 마을 가까이에서 생계를 꾸리고, 일부는 미지의 길을 따라 오래된 비밀을 찾는다. 모든 인물이 세계를 구해야 하는 것은 아니다. 여관의 빚을 갚고 은퇴한 사람도, 이름 없는 다리에서 누군가를 구한 사람도 한 생애의 주인공이다.

가문에는 대대로 내려오는 **여행 수첩**이 있다. 수첩은 발견한 장소, 사람과의 약속, 유품의 사연을 기록한다. 이는 영구 도감과 연대기를 세계 안에서 설명하는 장치다. 부활을 보장하거나 모든 능력을 계승시키는 마법 물건은 아니다.

### 3.2 표현의 온도

외형과 일상은 포근하고 귀엽게 표현한다. 비를 피해 버섯 아래에 숨고, 몸보다 큰 배낭을 끌고, 모닥불 앞에서 빵을 먹는다. 노화, 저주, 실패와 죽음은 존재하되 잔혹한 묘사는 피한다. 죽음은 쓰러진 뒤 남은 소지품, 꺼진 등불, 길드의 편지로 전달한다.

글은 짧고 담백하게 쓴다. 모든 장면을 농담으로 처리하지 않고, 중요한 이별이나 약속은 차분히 기록한다.

### 3.3 주요 지역

| 지역 | 화면에서 보이는 특징 | 주된 활동과 보상 | 대표 사건 |
| --- | --- | --- | --- |
| 도토리 여울 | 작은 다리, 풀밭, 밝은 여관 | 기초 사냥, 생활비, 가족 기록 | 길 잃은 아이와 낡은 호각 |
| 안개 이끼숲 | 거대한 버섯, 반딧불, 짙은 안개 | 약초, 탐색 장비, 정령과의 인연 | 길을 바꾸는 흰 사슴 |
| 종소리 폐광 | 광차, 부서진 종, 광맥 | 광석, 방어구, 다층 던전 | 돌아오지 않은 광부의 지도 |
| 달그늘 영지 | 검은 장미, 저택, 긴 달빛 | 저주 장비, 비밀 계약, 변이 | 마지막 잔을 권하는 성주 |
| 별잠 유적 | 공중의 작은 파편, 별빛 문양 | 고난도 탐험, 생명 연장 기연 | 한 사람의 시간을 요구하는 샘 |

첫 제작 범위는 도토리 여울과 종소리 폐광 중심으로 제한한다. 나머지 지역은 확장 설정으로 남겨둔다.

## 4 작은 화면의 구성

### 4.1 기본 창

PC 바탕화면 위에 놓이는 낮고 긴 독립 창을 기본으로 한다. 화면 가장자리나 작업 표시줄 위쪽에 붙일 수 있다. 운영체제의 실제 작업 표시줄을 교체하거나 내부에 삽입하는 방식은 초기 범위에 넣지 않는다.

**제안 크기**는 기본 520 × 64 논리 픽셀, 축소 320 × 48 논리 픽셀이다. 표시 배율과 사용자의 조절에 따라 실제 화면 크기는 달라질 수 있다. 이 수치는 가독성 확인용 출발점이다.

```text
┌──────────────────────────────────────────────────────────┐
│ [작은 풍경과 SD 모험가]  리아 31세 · 탐색 중   [중요 선택 1] │
│                          낡은 종 아래에서 지도를 찾았다     │
└──────────────────────────────────────────────────────────┘
```

기본 창에는 현재 행동, 건강 상태, 한 줄 사건, 중요한 선택 표시만 둔다. 경험치, 모든 재화, 장비 목록과 상세 판정은 펼친 창에서 보여준다. 축소 모드에서는 긴 문장을 숨기고 캐릭터와 상태 아이콘을 우선한다.

### 4.2 상세 창

캐릭터를 클릭하면 일지와 상태를 여는 작은 창이 나타난다. 기본 제안 크기는 약 480 × 560 논리 픽셀이다.

- **일지** — 최근 요약, 특수 사건, 상세 판정.
- **인물** — 나이, 능력치, 특성, 부상, 현재 장비.
- **방침** — 태도, 구매 예산, 위험 허용, 다음 활동.
- **가문** — 이전 세대, 후계자, 유품, 도감.

현재 태도는 기본 창의 간단한 메뉴에서도 바꿀 수 있다. 태도 변경은 다음 행동 결정부터 적용하며, 진행 중인 전투를 즉시 취소하거나 보상을 다시 뽑지 않는다.

### 4.3 작업을 방해하지 않는 규칙

- 창은 위치를 잠글 수 있고, 항상 위에 표시는 사용자가 켠다.
- 기본 창이 키보드 입력을 가로채거나 다른 작업의 포커스를 가져오지 않는다.
- 중요한 선택도 점멸이나 강제 팝업 대신 작은 표식으로 알린다.
- 소리는 기본적으로 끄고, 켠 경우에도 반복 전투음의 빈도를 제한한다.
- 전체화면 작업 시 숨김, 화면 가장자리 정렬, 다중 모니터 위치 복구를 고려한다.
- 클릭 통과 모드를 제공한다면 트레이 메뉴로 반드시 해제할 수 있어야 한다.
- 상태는 색과 함께 모양이나 글자로 구분하고, 작은 글씨는 상세 창에서 확대해 읽을 수 있게 한다.
- 한 줄 기록은 자동 가로 스크롤하지 않는다. 긴 내용은 요약하고 원문은 일지에 보관한다.

## 5 자동 생활 순환

### 5.1 기본 흐름

```text
마을에서 준비 → 다음 활동 결정 → 이동 → 사냥 또는 모험 또는 던전
      ↑                                      ↓
구매와 장비 교체 ← 휴식과 치료 ← 귀환 ← 보상과 사건 처리

별도 분기: 중요한 선택 보류 / 은퇴 / 사망 → 생애 정리 → 다음 세대
```

한 번의 행동은 약 20~90초, 여러 행동이 이어지는 출정은 약 5~15분을 제안한다. 이는 관찰용 연출 단위이며, 화면에서 검을 한 번 휘두를 때마다 별도의 장기 판정을 하는 것은 아니다.

### 5.2 행동 결정의 우선순위

1. 사망, 은퇴 등 생애가 끝나는 조건을 처리한다.
2. 중요한 선택을 기다리는 중이면 해당 지점에서 멈춘다.
3. 활동을 막는 부상이 있거나 체력과 피로가 기준을 넘으면 귀환하고 치료한다.
4. 회복비와 필수 물품을 확보한 뒤 장비를 정비한다.
5. 이어서 진행할 임무가 유효하면 계속한다.
6. 그 외에는 태도, 적정 난도, 지역 조건에 따라 다음 활동을 고른다.

| 활동 | 주로 얻는 것 | 소모와 위험 | 작은 화면의 동작 |
| --- | --- | --- | --- |
| 사냥 | 일정한 돈, 기본 재료, 전투 숙련 | 낮은 위험과 피로 | 접근, 공격, 전리품 줍기 |
| 모험 | 사건, 지역 발견, 특성, 지도 | 결과 편차와 길에서의 부상 | 걷기, 주변 보기, 발견 |
| 던전 | 높은 등급 장비, 보스 보상, 유물 | 누적 피해와 깊이에 따른 위험 | 문 열기, 전투, 함정, 상자 |
| 휴식 | 체력과 피로 회복, 가벼운 생활 사건 | 진행 시간과 나이 | 식사, 잠, 모닥불 |
| 마을 정비 | 구매, 장비 교체, 치료, 가족 소식 | 돈과 시간 | 상인 만나기, 수선, 편지 |

휴식에도 생애 시간이 흐르므로 건강하게 복귀하는 것 자체가 운영의 일부다. 자금이 없을 때는 길드의 기본 숙식과 저위험 의뢰로 복구하며, 치료비 부족으로 영구적으로 멈추는 상태를 만들지 않는다.

## 6 태도와 인물 성격

**태도는 플레이어가 정한 행동 방침이고, 성격은 인물에게 붙은 특성이다.** 같은 도전적 태도라도 겁이 많은 인물은 퇴각을 더 일찍 고민하고, 호기심 많은 인물은 비밀 통로에 반응한다. 다만 성격이 플레이어의 위험 금지나 지출 한도를 무시하지는 않는다.

### 6.1 기본 태도

아래 비중은 회복과 준비가 끝난 뒤 선택 가능한 세 활동의 기본 가중치다. 휴식이나 강제 귀환의 확률을 뜻하지 않으며, 진입 조건을 만족하지 않는 활동을 제외하고 남은 비중을 다시 계산한다.

| 항목 | 안정적 | 모험적 | 도전적 |
| --- | --- | --- | --- |
| 사냥 / 모험 / 던전 비중 | 60 / 30 / 10 | 30 / 45 / 25 | 20 / 25 / 55 |
| 주요 목적 | 생활비와 꾸준한 성장 | 발견과 다양한 인연 | 깊은 던전과 강한 장비 |
| 체력 퇴각 기준 예시 | 60% 이하 | 40% 이하 | 25% 이하 |
| 일상 사건 선택 | 손해와 부상 회피 | 정보와 새로운 길 우선 | 높은 보상과 정면 해결 우선 |
| 구매 경향 | 방어와 회복 효율 | 탐색과 범용성 | 공격과 핵심 조합 |
| 예상 약점 | 희귀 발견이 느림 | 수입과 성장이 들쭉날쭉함 | 부상과 회복 시간이 늘어남 |

퇴각 기준은 다음 안전한 판단 지점에서 적용한다. 이미 받은 치명적인 공격을 소급해서 취소하지는 않는다. 태도 변경만으로 종족 변이, 유품 희생, 치명 위험 출정에 동의한 것으로 간주하지 않는다.

### 6.2 위험 정책

일반 활동의 위험은 낮음, 보통, 높음으로 표시한다. 별도로 사망할 수 있는 활동에는 **치명 위험** 표시를 붙인다. 초기 제안은 치명 위험 허용을 꺼두는 것이다. 이를 켠 사용자는 지정한 범위의 치명 위험 활동을 자동으로 진행하게 할 수 있다.

도전적 태도도 치명 위험 허용이 꺼져 있으면 높은 위험까지 선택한다. 따라서 도전적 태도는 단순한 사망 증가 모드가 아니라, 더 긴 회복을 감수하고 어려운 보상을 노리는 방식이 된다. 더 강한 긴장감을 원하면 별도의 위험 정책을 사용한다.

초기에는 세 가지 태도로 충분하다. 수집 중심, 연구 중심 같은 추가 태도는 기존 태도와 체감 차이가 생길 때 확장한다.

## 7 성장과 판정

### 7.1 인물의 구성

| 요소 | 역할 | 세대 변경 시 |
| --- | --- | --- |
| 레벨 | 생애 안에서의 전반적인 성장 | 초기화 |
| 능력치 | 전투, 탐색, 교섭 판정 | 새 인물의 기본값으로 시작 |
| 숙련 | 반복 활동에 따른 전투와 탐색 방식 | 초기화하며 일부 경험은 가문 기록으로 남김 |
| 선천 특성 | 체질과 타고난 경향 | 제한된 일부만 유전 가능 |
| 후천 특성 | 경험으로 얻은 버릇과 장단점 | 원칙적으로 유전하지 않음 |
| 종족 상태와 계약 | 해당 생애를 크게 바꾸는 조건 | 초기화 |
| 장비 | 전투력과 행동 방식 | 선택된 유품만 이전 |

기본 능력치는 **힘, 민첩, 지식, 의지, 사교, 행운** 여섯 가지를 제안한다. 힘과 민첩은 전투에, 지식과 의지는 함정과 마법에, 사교는 거래와 인연에 관여한다. 행운은 희귀한 기회와 일부 결과의 편차에 제한적으로 관여하며 모든 판정의 필수 능력치가 되지 않게 한다.

### 7.2 직업과 숙련

처음에는 공통 초보 모험가로 시작한다. 활동으로 검술, 기동, 탐색 등의 숙련이 쌓이고, 일정 단계에서 수호자, 길잡이, 술사 같은 전문 방향이 열린다. 태도와 직업은 독립적이다. 안정적인 술사도, 도전적인 수호자도 가능해야 한다.

전문화 기회는 큰 성장 변화로 분류한다. 사용자가 선택하거나, 사전에 지정한 자동 전문화 방침이 있을 때 그 방침을 따른다. 첫 범위에서는 전투형과 탐색형 두 갈래만 검증한다.

### 7.3 주사위가 남기는 TRPG 감성

전투와 사건의 중요한 장면은 다음 형태의 판정으로 설명한다.

**20면체 주사위 결과 + 관련 능력 보정 + 숙련 및 특성 보정 ≥ 난이도**

예를 들어 민첩한 인물이 낡은 다리를 건너는 판정은 `주사위 12 + 민첩 3 + 길눈 1 = 16`, 난이도 14이므로 성공한다. 상세 기록에서는 이 과정을 펼쳐 볼 수 있다. 기본 창에는 “흔들리는 다리를 무사히 건넜다”만 표시한다.

- 성공은 보상을 얻거나 안전하게 다음 장면으로 이어진다.
- 난이도에 1~2 모자라면 일부 사건에서 비용을 지불하는 부분 성공이 가능하다.
- 더 크게 부족하면 실패한다. 실패도 부상, 돈 손실, 우회로 발견 등으로 이야기를 이어간다.
- 자연 주사위 1과 20은 상황별 특별 문장을 만들 수 있으나, 1 한 번으로 평범한 활동에서 즉사하지 않는다.

일반 전투는 여러 교환의 결과를 요약하고, 함정·보스·협상 같은 중요한 장면에 판정을 강조한다. 단순히 모든 문장에 주사위 숫자를 붙이는 것을 TRPG 감성의 전부로 삼지 않는다.

### 7.4 특성 예시

| 특성 | 종류 | 효과와 이야기 반응 |
| --- | --- | --- |
| 튼튼한 체질 | 선천 | 회복 효율이 좋고 장거리 출정에 유리 |
| 예민한 귀 | 선천 | 함정과 매복 감지에 유리, 시끄러운 곳에서 피로 증가 |
| 호기심 많음 | 선천 성향 | 모험 사건과 비밀 통로를 선호 |
| 겁이 많음 | 선천 성향 | 위험 회피에 유리, 공포 판정에 불리 |
| 다리의 은인 | 후천 | 특정 마을의 호의와 관련 후속 사건 |
| 어둠을 견딘 자 | 후천 | 공포 저항과 폐광 관련 기록 변화 |
| 달의 갈증 | 변이 | 흡혈귀 상태의 장점과 제약, 현재 생애에만 적용 |

특성은 장점만 누적하지 않는다. 능력 상승에는 상한을 두고, 동일한 유전 특성은 중첩해서 강화하지 않는다.

## 8 사냥과 던전 그리고 모험의 차이

사냥은 다음 활동을 준비하는 안정적인 수입원이다. 같은 사냥터에서도 등장 적과 작은 사건은 바뀌지만, 장비와 회복에 필요한 돈을 예측할 수 있어야 한다.

모험은 길과 인연을 발견하는 활동이다. 사건, 지도, 지역 해금, 특성을 중심으로 보상한다. 전투력이 같은 두 인물도 성격과 이전 선택 때문에 다른 여정을 만들 수 있다.

던전은 **어디까지 들어갈 것인가**가 중심인 활동이다. 방을 통과할수록 보상 기대치와 누적 위험이 함께 올라간다. 태도는 다음 방으로 갈지, 확보한 전리품을 들고 돌아올지 결정하는 데 쓰인다.

던전은 3~7개 장면과 마지막 관문으로 구성하는 방식을 제안한다. 전투, 함정, 휴식 지점, 보물, 사건의 조합을 바꾸되 입구부터 모든 보상이 막히거나 반드시 죽는 조합은 제외한다.

길드 등급으로 각 지역의 난도 범위를 안내한다. 자동 선택은 장비와 건강 상태가 감당할 수 있는 범위에서 이루어지며, 사용자가 허용한 위험 수준도 함께 확인한다.

### 8.1 패배와 사망

- 일반 활동에서 체력이 0이 되면 구조되거나 탈출하고, 부상·치료 시간·일부 전리품 손실을 받는다.
- 치명 위험 활동에서는 체력 소진이나 명시된 실패 조건이 사망으로 이어질 수 있다.
- 영구적인 저주나 수명 단축처럼 생애를 끝낼 수 있는 계약은 수락 전에 결과 범위를 알린다.
- 사망은 되돌림 없는 생애 종료로 처리한다. 가문 전체는 계속된다.

사망 시 원인을 “운이 나빴다”로만 표시하지 않는다. 진입한 위험, 누적 부상, 결정적인 실패를 짧게 보여주고, 다음 세대에 바꿀 수 있는 방침도 함께 확인하게 한다.

## 9 아이템 파밍과 자동 경제

### 9.1 장비와 보상

장비 슬롯은 무기, 방어구, 장신구, 유물 네 개를 제안한다. 등급은 일반, 좋은, 희귀, 전설로 시작한다. 저주 여부는 등급과 별개다.

낮은 등급 장비는 자동 교체와 판매가 쉬워야 한다. 높은 등급 장비는 단순히 수치가 큰 것에 더해 특정 판정이나 행동을 바꾼다. 예를 들어 ‘귀환의 방울’은 전투력을 높이지 않지만 위험한 출정에서 한 번의 탈출을 도울 수 있다.

아이템마다 이름, 기본 성능, 특수 효과, 획득처, 해당 인물의 사용 기록을 둔다. 유품이 된 장비에는 “1대 모라가 종소리 폐광에서 발견했다” 같은 사연이 붙는다.

### 9.2 자동 구매와 장비 교체

구매 순서는 **필수 치료와 회복 확보 → 구매 예산 확인 → 충분한 개선이 있는 장비 선택**이다. 초깃값으로 소지금의 30%를 회복과 생활비용으로 남겨두는 방안을 제안한다. 다만 긴급 치료는 이 예약금을 사용할 수 있다.

장비 비교는 공격력 하나로 결정하지 않는다. 현재 전문 방향, 생존력, 핵심 특성과의 조합을 함께 평가한다. 자동 교체 이유는 “함정 감지가 높아져 장화를 바꿨다”처럼 읽을 수 있게 남긴다.

- 장착 장비, 유품 지정 장비, 사용자가 잠근 장비는 자동 판매하지 않는다.
- 저주 장비와 영구 계약은 자동 구매·장착하지 않는다.
- 한 번의 이동과 거래에서 사소한 차이로 장비를 계속 사고팔지 않게 최소 개선 기준을 둔다.
- 가방은 초기 20칸을 제안하며, 초과 시 잠금 없는 낮은 가치 장비부터 정리한다.
- 모두 잠긴 경우 새 일반 장비는 현장에서 환전하고, 고유 보상은 별도 수령 대기함에 보관한다.
- 수령 대기함도 해당 세대의 자산이다. 계승할 때 유품 제한을 우회하는 보관소가 되지 않는다.

### 9.3 돈의 역할

돈은 장비 구매, 치료, 수선과 여정 준비에 쓴다. 필수 회복비 때문에 계속 적자가 나는 활동은 자동 방침에서 제외한다. 파산 시 길드 지원으로 기본 장비와 생계를 복구하되 고급 보상을 얻는 지름길이 되지 않게 한다.

영구 성장에는 발견과 업적을 사용한다. 돈만 무한히 모아서 다음 세대의 초반을 모두 생략하는 구조는 피한다.

## 10 나이와 생애의 끝

### 10.1 시간의 의미

기본 제안은 **유효 진행 12분마다 한 살 증가**하는 것이다. 인물은 18세에 활동을 시작하고 기본 은퇴 나이는 68세다. 기연과 조기 은퇴가 없다면 한 생애는 약 10시간의 유효 진행에 해당한다.

유효 진행에는 게임이 켜진 동안의 사냥, 이동, 휴식, 마을 생활과 실제로 정산된 오프라인 진행이 포함된다. 일시정지와 중요한 선택 대기 시간은 포함하지 않는다. 화면의 짧은 행동들은 긴 여정과 생활을 압축한 장면으로 해석한다.

| 나이 | 생애 단계 | 체감 변화 |
| --- | --- | --- |
| 18~29세 | 새내기 | 숙련 성장과 생활 기반 마련 |
| 30~49세 | 전성기 | 전문화, 깊은 탐험, 가족과 후계자 형성 |
| 50~64세 | 숙련기 | 경험 관련 선택 확대, 회복 부담 증가 |
| 65세 이상 | 노년기 | 은퇴 준비, 유품과 마지막 목표 강조 |

나이가 들었다고 모든 능력이 동시에 떨어지지는 않는다. 육체 회복은 느려져도 지식과 교섭 경험은 남는다. 외형은 어린 모습, 성숙한 모습, 흰 머리 등의 소수 단계로 표현한다.

### 10.2 은퇴

은퇴 나이에 도달하면 새 출정을 잡지 않는다. 현재 활동의 다음 안전 지점에서 귀환을 시도하고, 생존해 마을에 도착하면 은퇴한다. 치명 위험 활동에서 진행 중인 위험까지 자동으로 무효화하지는 않는다.

플레이어는 마을에 있을 때 조기 은퇴시킬 수 있다. 잦은 조기 은퇴만으로 보상을 모으지 못하도록 가문 업적은 실제 발견과 생애 성과에 따라 주며, 은퇴 횟수 자체에는 반복 보상을 주지 않는다.

은퇴자는 가계도에 남아 여관 주인, 길드 교관, 편지를 보내는 가족처럼 등장할 수 있다. 이후 세대에 이야기로 등장하더라도 현역 때의 능력치와 종족 보너스를 영구적으로 제공하지 않는다.

### 10.3 기연에 의한 생명 연장

생명 연장 기연은 횟수를 제한하고 대가를 동반한다. ‘별잠 샘물’은 은퇴 나이를 10년 늦추지만 희귀한 유물 하나를 요구할 수 있다. 같은 샘물을 반복 획득해 무한히 연장할 수는 없다.

기본 종족은 연장된 은퇴 나이 98세를 초기 상한으로 제안한다. 연장은 현재 인물의 생애에만 적용되며, 자녀의 기본 수명이나 가문의 영구 능력이 되지 않는다.

### 10.4 종족 변이

| 변이 예시 | 변화 | 대가 | 생애의 끝 |
| --- | --- | --- | --- |
| 흡혈귀 | 밤의 전투와 회복에 유리, 달그늘 사건 개방 | 낮 활동과 일부 마을 이용 제약 | 정해진 갈증 한계 또는 자발적 은둔 |
| 정령화 | 특정 환경과 탐색 판정에 유리 | 일반 장비와 인간관계에 제약 | 인간 세계를 떠나는 의식 |
| 석화 혈통 | 방어와 부상 저항 상승 | 기동과 회복 속도 저하 | 몸이 굳기 전 마지막 은퇴 |

변이는 특수 선택으로만 발생한다. 흡혈귀도 한 회차를 영원히 점유하지 않도록 종료 조건을 둔다. 초기 제안은 기존 은퇴 예정 나이에 30년을 더하되 최종 118세를 넘지 않는 시점에 ‘긴 잠’에 드는 것이다. 기본 은퇴 나이가 68세인 인물은 98세에 긴 잠에 든다. 변이 후에는 일반 생명 연장 기연을 추가 적용하지 않는다. 정령화와 석화는 각자의 종료 조건을 별도로 정하고, 선택 화면에서 예정된 종료 조건을 알려준다.

변이, 갈증, 종족 전용 능력과 수명 연장은 다음 세대에 유전되지 않는다. 관련 장비도 변이 효과를 담고 있으면 계승 시 그 부분이 사라진다. 가문에는 발견 기록, 별칭, 외형 수집 요소만 남을 수 있다.

## 11 사건과 중요한 선택

### 11.1 사건의 세 단계

| 종류 | 예시 | 처리 방식 |
| --- | --- | --- |
| 생활 사건 | 길에서 약초 발견, 상인과 흥정 | 태도와 특성에 따라 자동 선택 |
| 연속 사건 | 광부의 지도, 오래된 빚, 정령과의 약속 | 보통 자동 진행, 중대한 분기에서만 사용자 선택 |
| 운명 사건 | 종족 변이, 수명 대가, 전설 유품 희생 | 명시적인 사용자 선택 또는 해당 사건에 대한 사전 방침 필요 |

자동 선택은 “안정적 방침에 따라 돌아가는 길을 골랐다”처럼 이유를 남긴다. 특성이 영향을 주면 함께 표시한다.

운명 사건은 보통 한 생애에 1~3회를 목표로 한다. 드문 사건을 만들기 위해 실시간으로 짧게 열렸다 사라지는 기회를 사용하지 않는다.

### 11.2 사용자가 없을 때의 선택

기본 방침은 **중요한 선택 지점에서 생애 진행을 보류**하는 것이다. 선택 전까지의 보상은 확정하고 이후의 시간, 노화, 전투와 다른 사건은 멈춘다. 작은 화면에서는 대기 자세나 책을 읽는 동작을 보여준다.

대기 자체에는 만료 시각이 없다. 사용자가 돌아와 선택하면 그 이후부터 진행한다. 이미 기다리느라 지난 현실 시간을 소급해서 경험치나 노화로 더하지 않는다.

계속 진행을 선호하면 ‘새로운 운명 제안은 거절하고 계속’이라는 방침을 켤 수 있다. 이 방침은 수락형 선택을 자동 거절하고 안전한 종료 경로가 있는 사건에만 적용한다. 반드시 새 진로를 정해야 하는 전문화 등의 사건은 별도 사전 방침이 없으면 보류한다.

한 번에 운명 사건 하나만 기다린다. 아직 방문하지 않은 장소의 선택을 여러 개 미리 쌓아두지 않는다. 보류를 택한 결과 성장 효율이 조금 줄 수 있음을 방침 설명에 표시한다.

### 11.3 운명 사건 예시

**사건 이름 — 마지막 잔을 권하는 성주**

달그늘 영지의 성주가 낡은 잔을 내민다. “너의 길은 아직 끝나지 않았구나.”

| 선택 | 즉시 결과 | 남는 변화 |
| --- | --- | --- |
| 잔을 받는다 | 흡혈귀로 변이 | 현재 생애의 능력과 사건이 바뀌며 긴 잠의 시점이 정해짐 |
| 잔을 내려놓는다 | 인간으로 돌아감 | 제안을 거절한 기록, 다른 후속 사건 가능 |
| 성주의 사연을 묻는다 | 지식 또는 사교 판정 | 성공하면 대가를 줄일 단서, 실패해도 변이를 강제하지 않음 |

선택 전에 알려진 이익, 알려진 대가, 되돌릴 수 있는지 여부를 표시한다. 숨겨진 이야기까지 전부 공개할 필요는 없지만, 사용자가 예상할 수 없는 즉사나 강제 변이를 평범한 선택 뒤에 숨기지 않는다.

### 11.4 연속 사건 예시

1. 폐광 입구에서 찢어진 지도를 발견한다.
2. 마을에서 지도 주인의 가족을 만난다.
3. 폐광 깊은 곳에서 돌아오지 못한 광부의 흔적을 찾는다.
4. 보물을 챙길지, 구조에 필요한 길을 열지 선택한다.
5. 구조를 도왔다면 다음 세대가 폐광을 방문했을 때 후손이 기억한다.

마지막의 가문 기록은 영구 능력치 보상 없이도 다음 생애의 장면과 선택지를 바꿀 수 있다.

## 12 세대 계승과 가문

### 12.1 계승 절차

**생애 종료 → 마지막 일지와 업적 정리 → 후계자 결정 → 유전과 유품 확정 → 새 인물의 출발** 순서로 진행한다.

기본 설정은 플레이어가 후계자를 확인할 때까지 계승 화면에서 기다리는 것이다. 자동 계승을 켜두면 생전에 정한 후보, 없으면 기본 후보로 진행한다. 자동 계승 여부와 무관하게 완료된 생애의 마지막 기록은 다시 볼 수 있다.

### 12.2 자녀와 후계자가 생기는 방식

부모와 자녀의 계승을 기본 경로로 한다. 인물이 30세 전후에 마을로 돌아오면 가족이 생기는 생활 기록과 자녀 후보를 소개하는 방식을 제안한다. 가족의 모습과 관계 서술은 여러 형태를 지원할 수 있다. 연애 상대를 반복 공략하거나 출산을 위한 재화를 관리하는 기능은 초기 범위에 넣지 않는다.

후계자는 성인이 되어 모험을 시작한다. 생애가 너무 일찍 끝나 자녀가 미성년자라면, 가문 기록에 시간이 흘렀음을 표시하고 성인이 된 시점으로 넘어간다. 이 이야기상 시간 도약은 돈, 장비와 모험 보상을 생성하지 않는다.

직계 자녀가 없으면 방계 친족, 그마저 없으면 가문을 이을 입양 자녀가 후계자가 된다. 입양 자녀에게는 이전 인물의 생물학적 유전을 적용하지 않는다. 가문 교육에 따른 작은 시작 선택지와 유품은 동일하게 받을 수 있다. 어떤 경우에도 후계자 부재로 전체 진행이 끝나지 않는다.

계승 후보는 최대 세 명만 제시하고, 하나를 기본 후보로 지정할 수 있다. 후보 수는 가족 사건에 따라 달라지며, 매 생애마다 세 자녀를 반드시 만들어야 하는 구조는 아니다.

### 12.3 유전과 가르침

- 새 인물은 기본 선천 특성과 일부 새로운 무작위 특성을 가진다.
- 직계 자녀는 부모의 유전 가능 특성 중 최대 2개를 이어받으며, 이전 플레이 인물에게서 이어지는 것은 최대 1개로 제한하는 방안을 제안한다. 다른 하나의 출처가 되는 부모의 선천 특성은 가족 기록에 표시한다.
- 방계 후계자의 유전은 그 인물의 부모 기록을 따른다. 이전 모험가의 특성을 직계 자녀처럼 그대로 물려받지는 않는다.
- 부정적 특성도 유전될 수 있으나 시작부터 정상적인 활동이 불가능한 조합은 제외한다.
- 학습한 기술, 특정 인연, 저주와 종족 변이는 유전하지 않는다.
- 은퇴자가 살아 있다면 교육 사건을 통해 초반 숙련을 조금 도울 수 있지만, 영구 누적 능력치로 남기지는 않는다.

유전의 재미는 매 세대 같은 최강 조합을 쌓는 것보다 “부모와 닮은 면이 있지만 다른 삶을 사는 인물”을 만드는 데 둔다. 혈통 특성의 개수와 수치에는 상한을 둔다.

### 12.4 무엇을 물려주는가

다음은 초기 밸런스 제안이다.

| 항목 | 은퇴 후 계승 | 사망 후 계승 |
| --- | --- | --- |
| 장비 | 유품 최대 2개 | 생전에 지정한 유품 최대 1개 |
| 돈 | 잔액 20%, 상한 적용 | 잔액 10%, 상한 적용 |
| 유전 가능 특성 | 후계자 관계에 따른 공통 규칙 | 같은 규칙 |
| 레벨과 일반 숙련 | 초기화 | 초기화 |
| 발견과 가문 기록 | 보존 | 보존 |
| 변이와 수명 연장 | 종료 | 종료 |

돈 상한은 초기 표준 무기 가격의 3배를 출발점으로 제안한다. 가방, 창고와 수령 대기함까지 같은 세대의 자산으로 묶어 정산한다. 유품으로 선택되지 않은 장비는 처분 또는 기록용 기념품으로 전환되며 다음 인물의 실물 장비가 되지 않는다.

유품은 한 번에 최대 두 개만 ‘다음 세대에 남길 물건’으로 등록할 수 있다. 사망 시에는 이 중 우선순위가 높은 하나만 길드가 회수한다. 지정이 없으면 자동 기준으로 하나를 고른다. 보관 장소를 바꾸거나 장비를 잠가 유품 개수 제한을 늘릴 수 없다.

고등급 유품은 어린 후계자가 즉시 전 성능을 사용하지 못하도록 잠재 상태로 전달한다. 인물의 등급과 숙련이 오르면 본래 성능이 열린다. 아이템의 이름과 외형, 사연은 처음부터 유지한다.

### 12.5 가문 단위로 남는 성장

가문에는 발견 지역, 아이템 도감, 인연의 기록, 외형, 호칭, 시작 선택지가 남는다. 이전 세대가 길을 발견하면 다음 세대는 그 길의 존재를 알지만, 실제 출정에는 자신의 준비가 필요하다.

가문 성장은 시작 직업이나 출신 배경 등 선택의 폭을 늘리는 방향을 우선한다. 세대 수만 늘리면 능력치가 끝없이 올라가는 구조를 피한다. 오래 플레이한 가문에서도 새 인물의 위험과 성장이 의미를 유지해야 한다.

## 13 랜덤성과 장기 목표

### 13.1 생애마다 달라지는 요소

출생 특성, 일부 외형, 출발 계절, 활동별 조우, 던전 방 구성, 장비 효과, 사건 순서, 기연의 등장 조건이 달라진다. 가문이 이전에 남긴 약속은 새로운 사건의 조건으로 작동한다.

같은 활동을 되풀이해도 발견 순서와 인물 반응이 달라야 한다. 다만 모든 요소를 완전 무작위로 섞지 않는다. 사건은 지역, 생애 단계, 위험 등급, 보유 특성과 이전 사건을 확인하고, 서로 충돌하는 계약은 동시에 등장하지 않게 한다.

### 13.2 실패와 반복의 관계

이 게임은 인물이 끝날 때 일부 진척이 남는 **세대 계승형 로그라이트**로 정의한다. 사용자가 말한 로그라이크의 핵심인 무작위 생애, 실패의 의미, 다시 시작하는 경험을 사용하되 가문 기록과 제한된 유산을 영구 진척으로 둔다.

목표는 한 번의 정답 빌드를 찾는 것에 그치지 않는다. 안정적으로 장수한 가문, 폐광을 개척한 가문, 여러 변이를 기록한 가문처럼 서로 다른 연대기를 만들 수 있어야 한다.

### 13.3 목표의 시간 규모

| 규모 | 목표 예시 |
| --- | --- |
| 짧은 관찰 | 새 장비, 처음 보는 동작, 흥미로운 한 줄 기록 |
| 한 번의 출정 | 던전 관문 돌파, 부상 없이 귀환, 지도 발견 |
| 한 생애 | 전문화, 희귀 유품, 기연, 만족스러운 은퇴 |
| 여러 세대 | 특정 인연의 결말, 지역 비밀 완성, 유품의 긴 역사 |

## 14 오프라인 진행과 기록 보존

### 14.1 오프라인 진행

프로그램을 닫은 동안도 기본 최대 8시간의 유효 진행을 계산하는 방안을 제안한다. 그 이상의 미접속 시간은 추가 보상과 추가 노화를 만들지 않는다. 오프라인 진행 자체를 끄는 옵션도 제공한다.

오프라인에서는 단순히 돈을 일괄 지급하는 대신, 온라인과 같은 태도·회복·위험·사건 규칙을 적용한다. 화면 연출만 생략하고 결과를 일지로 요약한다.

- 운명 사건에서 보류하도록 설정되어 있으면 그 지점까지 정산하고 멈춘다.
- 은퇴나 사망에 도달하면 최대 한 생애의 종료까지만 정산한다.
- 자동 계승이 켜져 있으면 후계자를 준비하되, 남은 오프라인 시간으로 그 후계자의 생애까지 진행하지 않는다.
- 치명 위험을 허용한 인물은 오프라인에서도 같은 위험을 받는다. 허용 시 이 점을 설명한다.
- 온라인에서는 자동 계승과 선택 방침에 따라 다음 생애를 계속 진행할 수 있다.

예를 들어 10시간 후 돌아왔지만 3시간 지점에 중요한 선택이 있었다면, 진행 결과는 3시간까지다. 남은 7시간을 선택 뒤에 소급 적용하거나 다음 접속까지 저장해두지 않는다.

복귀 화면은 “약 3시간 활동, 장비 2회 교체, 던전 1회 귀환, 중요한 선택 대기”처럼 요약한다. 금액만 나열하지 않고 왜 멈췄는지도 알려준다.

### 14.2 저장과 연속성

행동 결과, 큰 선택, 장비 거래, 생애 종료와 계승이 확정되는 지점에서 진행을 보존한다. 창을 닫았다 열었다고 이미 확정된 보상이나 선택지가 다시 뽑히지 않아야 한다. 비정상 종료 시 최근 정상 기록으로 복구할 수 있어야 한다.

캐릭터와 연대기는 로컬 저장을 기본 제안으로 한다. 계정, 온라인 경쟁과 클라우드 동기화는 초기 핵심 경험에 필요하지 않으며 별도 검토 대상으로 둔다.

## 15 일지의 구조와 문체

기록은 현재 상황 한 줄, 최근 활동 요약, 펼쳐 보는 상세 기록의 세 단계로 구성한다. 작은 화면의 문장은 약 15~25자에서 읽히도록 다듬고, 최소 몇 초 동안 유지해 계속 교체되는 자막처럼 보이지 않게 한다.

반복 사냥 열 번은 하나의 기록으로 묶을 수 있다. 첫 발견, 유품 획득, 특성 변화, 중요한 인연과 생애 종료는 개별 기록으로 남긴다. 일상 기록을 줄이더라도 주요 가문 사건은 장기 보존한다.

### 15.1 일지 예시

```text
[사냥] 리아가 여울가의 들쥐를 쫓아냈다. 동전 8개를 얻었다.
[휴식] 배낭을 베개 삼아 잠들었다. 오늘은 비가 오지 않았다.
[특성] 예민한 귀 덕분에 벽 너머의 발소리를 먼저 들었다.
[판정] 주사위 12 + 민첩 3 + 길눈 1 = 16 / 난이도 14. 다리를 건넜다.
[장비] 녹슨 검을 내려놓고, 어머니의 짧은 검을 다시 찼다.
[인연] 광부의 딸이 기억하고 있었다. “우리 집을 도운 분과 닮았네요.”
[중요] 성주가 마지막 잔을 내밀었다. 리아는 당신의 결정을 기다린다.
[은퇴] 리아는 오늘부터 길드 앞 작은 여관을 맡기로 했다.
[계승] 아린은 어머니의 수첩을 펼쳤다. 첫 장에는 폐광 지도가 있었다.
```

TRPG 감성은 판정의 결과와 인물의 특성, 선택의 후속 결과가 같은 기록 안에서 연결될 때 생긴다. 초기 콘텐츠는 작성된 사건과 조건별 문장 조합으로 충분히 검증할 수 있다. 실시간 생성형 AI에 대한 의존은 초기 범위에 넣지 않는다.

## 16 SD 캐릭터와 스프라이트 제작 방향

### 16.1 기본 형태

머리가 크고 팔다리가 짧은 2~3등신 SD 형태를 제안한다. 기본 화면에서 실루엣이 읽히는 약 32 × 32 또는 48 × 48 픽셀의 픽셀 아트를 우선 검토한다. 두 규격 중 하나를 실제 표시 크기에서 비교한 뒤 통일한다.

초기에는 좌우 방향만 사용한다. 정면 표정은 선택 창의 초상에 둘 수 있지만, 모든 행동을 여러 방향으로 제작하지 않는다. 좌우 반전으로 읽기 어려운 비대칭 장비와 문양은 별도로 처리한다.

### 16.2 조합 방식

기본 몸체 위에 머리와 얼굴, 복장, 무기, 장신구와 상태 효과를 결합한다. 모든 종족과 장비마다 전체 애니메이션을 새로 그리는 대신 몸체 동작을 공유한다.

장비의 움직임은 손, 머리, 몸 중심의 기준점에 맞춘다. 포즈마다 무기가 손에서 떠 있거나 방패가 얼굴을 가리지 않는지 확인한다. 팔 길이나 날개처럼 실루엣을 크게 바꾸는 변이는 공용 동작으로 처리할 수 있는 범위를 따로 정한다.

### 16.3 핵심 동작과 제작량 초안

다음은 공용 기본 몸체 한 종류, 한 방향의 프레임 수를 계산한 예시다.

| 동작 | 프레임 제안 | 주된 용도 |
| --- | --- | --- |
| 대기 | 4 | 호흡과 주변 보기 |
| 걷기 | 6 | 이동과 탐험 |
| 공격 | 6 | 기본 근접 공격 |
| 피격 | 3 | 전투 상태 전달 |
| 발견 | 4 | 아이템과 사건 반응 |
| 앉기와 식사 | 4 | 회복과 생활 |
| 잠 | 4 | 휴식 |
| 상호작용 | 4 | 상자, 문, 채집 |
| 환호 | 4 | 성장과 성공 |
| 쓰러짐 | 5 | 패배와 사망 연출의 기반 |
| 합계 | 44 | 좌우 반전을 기본으로 활용 |

44프레임은 기본 몸체 동작만의 수량이다. 머리와 복장 레이어, 무기 종류별 공격, 이펙트, 적과 배경, 변이 전용 동작의 제작량은 별도로 산정한다. 조합 방식을 쓴다고 모든 의상이 정지 이미지 한 장으로 해결되는 것은 아니다.

초기 에셋은 몸체 1종, 머리·얼굴 조합 6종, 복장 계열 3종, 무기 외형 6종, 적 4종, 배경 장면 3종, 공용 효과 6종 정도로 범위를 잡는다. 예를 들어 적 4종에 각각 대기 4·이동 4·공격 4·피격 2·퇴장 4프레임을 사용하면 적 기본 동작은 72프레임이다. 보스의 별도 패턴은 추가다.

### 16.4 노화와 변이의 시각화

노화는 머리색, 눈썹, 얼굴과 자세의 일부로 구분한다. 흡혈귀는 창백한 색, 붉은 눈, 망토나 달 효과처럼 작은 화면에서도 읽히는 표식을 쓴다. 캐릭터 크기를 크게 키우는 방식에 의존하지 않는다.

원화와 실제 스프라이트 사이에는 크기 통일, 투명 배경, 프레임 정렬, 팔레트와 레이어 규칙 검수가 필요하다. 대량 제작 전에 기본 몸체 하나와 장비 두 종류를 실제 크기로 움직여보는 것을 우선한다.

## 17 한 생애와 다음 세대의 예시

첫 인물 **모라**는 튼튼한 체질을 가진 안정적 모험가다. 여울가에서 돈을 모으고 길드의 기초 의뢰를 반복한다. 좋은 방패를 구한 뒤 폐광에 들어가 광부의 지도를 발견한다.

사용자는 모라를 모험적으로 바꾼다. 모라는 지도 주인의 가족을 만나고, 여러 번의 탐색 끝에 무너진 길을 복구한다. 이 과정에서 ‘다리의 은인’이라는 후천 특성과 종이 달린 짧은 검을 얻는다.

노년의 모라는 생명을 연장하는 샘에 도달한다. 사용자는 남은 삶을 늘리는 대신 샘의 물을 다친 길잡이에게 양보한다. 이후 모라는 은퇴하고, 검과 수첩을 자녀 **리아**에게 남긴다.

리아는 부모의 튼튼한 체질을 물려받았지만 호기심이 많다. 모라의 레벨과 후천 특성은 물려받지 않는다. 유품 검의 잠재력은 리아의 숙련에 맞춰 열린다. 폐광에서는 모라가 도왔던 가족이 리아를 알아본다.

리아의 태도는 도전적이다. 높은 난도의 탐험 중 달그늘 성주를 만나 흡혈귀의 잔을 제안받는다. 사용자가 수락하면 이번 생애의 규칙이 크게 달라지지만, 다음 세대의 자녀는 흡혈귀 능력이나 늘어난 생애를 물려받지 않는다. 가문 기록에는 두 사람이 같은 검으로 걸었던 서로 다른 길이 남는다.

## 18 초기 제작 범위와 확장 순서

### 18.1 첫 검증판의 목적

첫 검증판은 “작게 켜놓고 싶은가”, “태도가 삶을 바꾸는가”, “계승한 다음 인물이 궁금한가”를 확인한다. 기능의 개수를 늘리기 전에 한 생애가 끝나고 다음 생애가 시작되는 흐름을 완성하는 것이 중요하다.

| 구분 | 첫 검증판에 포함 | 다음 단계로 제안 |
| --- | --- | --- |
| 화면 | 작은 창, 상세 일지, 위치 고정 | 다양한 장식과 배경 꾸미기 |
| 인물 | 인간 기본형, 노화 표현, 전투형과 탐색형 | 여러 전문화와 기본 종족 |
| 행동 | 사냥, 모험, 던전, 휴식과 마을 정비 | 특수 직업 활동과 복합 임무 |
| 태도 | 안정적, 모험적, 도전적 | 수집과 연구 등 차별화된 추가 방침 |
| 지역 | 마을과 사냥터, 폐광 던전 1개 | 나머지 세 지역과 지역 간 사건 |
| 아이템 | 장비 정의 약 24개, 시각 외형은 공용화 | 고유 외형과 조합 확장 |
| 사건 | 생활 24개, 연속 사건 2줄기 각 3개, 운명 3개 | 장기 가문 사건과 지역별 결말 |
| 특성 | 선천 8개, 후천 8개 | 상호작용과 관계 특성 확대 |
| 생애 | 노화, 은퇴, 치명 위험 사망, 계승 | 은퇴자 생활과 가계도 연출 확장 |
| 기연 | 생명 연장 1개, 폐광에서 연결되는 흡혈귀 사건 1개 | 정령화와 다른 변이 |
| 방치 | 자동 구매, 기본 오프라인 정산, 선택 보류 | 더 세밀한 사전 방침 |

사건 수는 합계 33개의 개별 사건 정의를 뜻한다. 문장 변형과 각 선택의 결과 문장은 별도 제작량이며, 연속 사건 6개를 생활 사건 24개에 중복 집계하지 않는다. 운명 사건 3개는 전문화, 생명 연장, 흡혈귀 제안을 우선한다.

아이템 정의 24개가 반드시 고유 스프라이트 24개를 뜻하지는 않는다. 같은 외형을 공유하는 품질과 효과 변형을 허용하되, 주요 유품에는 나중에 고유 외형을 붙일 수 있다.

### 18.2 권장 제작 순서

1. 실제 크기의 캐릭터와 기본 창을 만들어 가독성과 존재감을 확인한다.
2. 사냥, 귀환, 휴식, 자동 구매가 멈춤 없이 이어지게 한다.
3. 태도와 특성에 따른 행동 차이, 판정과 사건 기록을 붙인다.
4. 나이, 은퇴, 사망과 한 번의 계승을 연결한다.
5. 연속 사건, 기연, 흡혈귀 변이와 세대 기록을 추가한다.
6. 오프라인과 선택 보류, 저장 복구까지 연결하고 콘텐츠를 늘린다.

이는 기획상의 단계 제안이다. 개발 착수, 사용 엔진, 작업 기간이나 출시를 승인한 계획은 아니다.

## 19 확인해야 할 재미와 실패 가능성

### 19.1 플레이 검증 기준

| 확인할 질문 | 관찰 방법과 초기 목표 |
| --- | --- |
| 작은 화면에서 무슨 행동인지 보이는가 | 실제 표시 크기에서 사냥·이동·휴식·위험 대기를 구별하는지 관찰 |
| 계속 곁에 두고 싶은가 | 다른 작업과 함께 사용한 뒤 숨기거나 닫은 이유를 확인 |
| 태도의 차이를 느끼는가 | 비슷한 시작 조건에서 세 태도의 활동 비중, 발견, 부상, 수입을 비교 |
| 한 생애에 변화가 있는가 | 초반 10분에 새 장비와 사건, 이후 전문화와 가족 및 노년 변화 확인 |
| 중요한 선택을 놓치지 않는가 | 오랜 부재 후에도 선택이 남고, 대기 중 노화가 멈추는지 확인 |
| 다음 세대를 시작하고 싶은가 | 유품과 특성의 출처를 이해하고 새 인물의 차이를 말할 수 있는지 확인 |
| 변이가 해당 생애로 끝나는가 | 다음 세대에서 종족 능력과 수명 보너스가 남지 않는지 확인 |
| 부재 중 여러 세대가 사라지지 않는가 | 긴 오프라인 정산이 첫 생애 종료에서 멈추는지 확인 |

이 기준은 이후 검증할 목표이며, 현재 검증을 마쳤다는 뜻이 아니다.

### 19.2 주요 기획 위험

**태도가 실제로는 보상 배율 차이만 되는 문제.** 지역 선택, 퇴각, 사건, 구매 이유가 함께 달라져야 한다. 어느 태도가 모든 면에서 이기면 수치 조절보다 역할 구분부터 다시 확인한다.

**귀여운 관찰과 죽음의 상실감이 충돌하는 문제.** 기본 위험 정책, 원인을 알 수 있는 기록, 유품과 마지막 일지가 필요하다. 사용자가 위험을 선택하지 않았는데 갑자기 캐릭터를 잃는 방식은 피한다.

**계승이 초반 성장을 지워버리는 문제.** 유품 수량과 성능 개방, 재산 상한, 유전 상한을 함께 적용한다. 창고를 통한 우회도 같은 규칙으로 막는다.

**중요한 선택이 너무 자주 진행을 막는 문제.** 운명 사건 수를 제한하고 일상 선택은 자동화한다. 같은 큰 선택을 매 생애 반복한다면 사전 방침을 제공한다.

**텍스트만 늘고 보는 재미가 부족한 문제.** 대표 사건마다 새 자세, 짧은 소품, 날씨나 표정 변화를 연결한다. 반대로 로그를 읽지 않아도 건강 상태와 현재 활동은 보여야 한다.

**스프라이트 조합이 제작량을 숨기는 문제.** 몸체 수보다 동작과 장비의 조합 수를 관리한다. 첫 캐릭터의 실제 애니메이션을 완성하기 전에 종족과 장비 종류를 대량으로 늘리지 않는다.

**성장 속도 때문에 삶이 너무 빨리 소모되는 문제.** 한 세대 약 10시간, 오프라인 8시간은 출발 수치다. 실제 관찰 시간을 기준으로 생애 길이와 오프라인 상한을 함께 조절한다.

## 20 후속 기획에서 정할 항목

이 문서로 기본 방향을 잡고 다음 세부 기획에서 아래 항목을 확정한다. 별도 결정을 기다리지 않고 기획을 읽을 수 있도록 현재 제안도 함께 둔다.

| 항목 | 현재 제안 | 이후 결정에 필요한 확인 |
| --- | --- | --- |
| 주 플랫폼 | Windows PC | 목표 사용자 환경과 실제 창 사용감 |
| 그래픽 규격 | 픽셀 SD, 몸체 32 또는 48픽셀 | 배율별 가독성과 장비 구별 |
| 세대 길이 | 기본 약 10시간 유효 진행 | 애착 형성과 반복 피로 |
| 위험 기본값 | 치명 위험 꺼짐 | 긴장감과 방치 스트레스의 균형 |
| 후계자 자동화 | 확인 후 시작, 자동 계승 선택 가능 | 관찰형과 완전 방치형 선호 |
| 대기 처리 | 운명 사건에서 진행과 노화 보류 | 선택 보존과 진행 중단 빈도 |
| 서사 분위기 | 포근한 일상과 차분한 이별 | 실제 사건 문체의 일관성 |
| 수익 모델 | 미정 | 핵심 플레이 검증 후 별도 검토 |
| 엔진과 구현 구조 | 미정 | 작은 창, 표시 배율, 자원 사용과 애니메이션 검증 |

최종적으로 남겨야 할 경험은, 다음 세대의 작은 인물이 부모의 검을 들고 걷는 모습을 보았을 때 그 검을 얻었던 장면이 떠오르는 것이다.
