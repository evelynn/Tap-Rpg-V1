# 밸런스 조정 백로그

17 §4·§5 검증에서 **목표 범위를 벗어났지만 규칙 구현 오류가 아닌** 항목을 모은다.
여기 적힌 것은 코드가 아니라 **수치·설계 문서의 소유자**가 고칠 몫이다(00 §2.4). 수치는 이 문서에서 바꾸지 않는다.

- 측정 조건: 기반 팩 `content/base`, 태도 3종 × 시드 100개 = 300생애 전수(별도 표기 없으면).
- 합격 기준: 17 §5.2 "생애 단위로 목표 범위 안에 드는 생애 ≥ 80%".
- 재측정 수단: 17 §5 헤드리스 시뮬레이터(`pnpm sim`)는 아직 스텁이다(B13). 지금은 검증자 하네스로만 잰 값이다.
- 아래 수치는 **웨이브 3 검증 시점(S06·흡혈귀·갈증 배선 수정 전)** 값이다. 수정 뒤 값은 B13이 생기면 다시 잰다.

## 설계 확정이 먼저 필요한 항목

수치 조정이 아니라 **규칙 문서의 빈칸**이라 코드로 먼저 고칠 수 없는 것들이다.

| ID | 항목 | 관측 | 필요한 확정 |

| B14 | 고레벨 파산이 길드 지원에서 빠져나오지 못한다 | 종료선은 레벨 비례(레벨 3=100 … 26=1071동전)인데 지원 중 갈 수 있는 곳은 `aid_allowed`인 H1·H2·A1뿐이다. 레벨 26 시나리오: 유효 진행 400.9분·출정 45회에도 종료선 미도달(레벨 20은 51.0분/5회, 14는 38.6분/4회로 종료) | 08 §11 `aid.end_coins`에 상한을 두거나, 지원 중 허용 장소를 인물 레벨 기준 단계까지 연다. 08 §11·01 §9.6을 함께 고쳐야 한다 |
