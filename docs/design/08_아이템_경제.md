## 1 설계 원칙

1. **낮은 등급은 쉽게 바꾸고, 높은 등급은 행동을 바꾼다.** 일반·좋은 등급은 수치만 다르다. 희귀 이상은 판정이나 행동을 바꾸는 효과를 가진다(01 §9.3).
2. **자동 교체는 이유를 말한다.** 모든 교체는 가장 큰 개선 요인을 한 문장으로 남긴다(v0.1 §9.2).
3. **사소한 차이로 사고팔지 않는다.** 최소 개선 8%, 정비 한 번에 슬롯당 1회 교체, 판매한 장비의 같은 계절 재구매 금지.
4. **돈은 세대를 건너 쌓이지 않는다.** 남은 돈은 계승 상한(360동전)으로 대부분 사라진다. 가문의 영구 진척은 발견과 유품이다(v0.1 §9.3).
5. **치료비가 없어 멈추지 않는다.** 치료와 회복약은 예약금과 무관하게 우선 확보하고, 부족하면 길드가 지원한다.

### 5.2 가격 계산 순서

1. 기준가 = 01 §9.2 단계·슬롯 가격 × 등급 배수(일반 1.0, 좋은 2.2, 희귀 5.0).
2. 상점 정가 할인·할증 합산(곱이 아니라 더한다): TA01 `다리의 은인` −10%, E12 `흥정꾼의 표식` −3%(착용 장비마다), 흡혈귀 낮 귀환 +20%(09 §7.4). **합산 할인 상한 −20%**. 할증은 상한 없이 더한다.
3. 반올림해 동전 단위로 만든다.

- **사건 가격은 예외다.** L02 흥정 성공가(75%), L10 실패작 가격(40%·60%)처럼 11의 사건이 정한 특가는 그 사건 한 번의 거래 가격이며, 위 할인과 합산하지 않고 상한도 적용하지 않는다. 사건 특가 거래는 사건 1회당 물건 1개다(11). 이 특가로 산 장비를 되팔아도 판매가는 기준가 × 25%라 차익이 생기지 않는다(14절).

여관비는 따로 계산한다: (5 + 2 × 레벨) × (1 + 0.5[TI08 대식가]) × (1 − 0.3[TA04 여울의 단골]), 반올림. 여관 휴식은 1회에 최대 HP × 회복 계수를 회복하고, 가득 차지 않으면 한 번 더 묵는다(최대 2회, 01 §1.2).

판매가 = 기준가 × 25% × (1 + 0.1[TA06 알뜰한 살림꾼]), 반올림.

| A1~A4 | 경로 중앙 단계 | 발견·사건 보상만(07 §6.3, 11) |

### 6.2 전설 결과 처리

전설 장비는 W10 하나뿐이다. 관문 분포에서 전설이 나오면 다음처럼 처리한다.

| 출처 | 처리 |
| --- | --- |
| EB03 첫 격파 | W10 고정 보상(07 §5.6). 굴림 없음 |
| EB03 이후 | 이 생애의 D3 관문은 관문 잔당이므로 해당 없음 |
| 정예 관문(2%) | 해당 단계 **희귀 장비 + 희귀 효과 2개**, 이름 앞에 `이름난`을 붙인다. 예: `이름난 은빛 광맥 장검` |

### 6.3 행운 보정

희귀·전설 비중 × (1 + 0.02 × 행운), 최대 × 1.16(01 §2.1). 늘어난 만큼 일반 비중에서 뺀다. 좋은 등급 비중은 그대로다.

**예**: 행운 4인 인물이 던전 보물 상자를 연다. 기본 65 / 28 / 7 / 0 → 희귀 7 × 1.08 = 7.56 → **64.44 / 28 / 7.56 / 0**.

### 6.4 첫 출정 보장 드롭 (D21, 01 §9.5)

- 첫 가문의 첫 인물은 첫 출정이 H1 사냥으로 고정된다(04). 이 출정의 **3번째 조우**의 드롭 판정을 A02 여울 가죽조끼(일반, 부가 효과 없음)로 대신한다.
- A01(방어 0)에서 A02(방어 1)로 바꾸는 개선률은 모험적 기준 +9.1%다(7.4 계산 예 1). 8% 기준을 넘고, 시작 지급 장비 교체 규칙(8절)으로도 교체가 보장된다. 교체는 조우 직후 판단 지점에서 일어난다. 장비 자동 교체가 꺼져 있으면 교체 제안(8.2)으로 남는다.
- 기록: `[장비] 누빈 천옷 위에 가죽조끼를 걸쳤다.`

## 7 장비 평가 점수

### 7.1 기준 적

평가는 **인물 레벨과 같은 레벨의 기준 적**(01 §5.1 일반 공식)을 상대로 한다. 레벨 L 기준 적은 방어 10 + ⌊L/3⌋, 명중 2 + ⌊L/3⌋, 평균 피해 ((1 + ⌊L/6⌋) + (2 + ⌊L/2.5⌋)) / 2, 체력 8 + 2.3L다.

**주 활동 장소** = 최근 출정 3회 중 가장 많이 간 장소(동률이면 가장 최근). 계열 대상 효과는 주 활동 장소 조우 표(07 §3.1, §5.1, §6.1)의 계열 비중만큼 반영한다.

### 7.2 슬롯별 전투 성분

| 슬롯 | 성분 | 식 |
| --- | --- | --- |
| 무기 | 라운드당 기대 피해 P | P = p_c × d_c. p_c = clamp((21 − (적 방어 − 명중 보정)) / 20, 0.05, 0.95). d_c = 무기 평균 피해 + ⌊무기 능력치 / 2⌋ + Σ(계열 대상 피해 보정 × 계열 비중). 계열 대상 명중 보정은 p_c 계산의 명중 보정에 (보정 × 계열 비중)으로 더한다 |
| 방어구 | 버팀 라운드 B | B = 최대 HP / (p_e × 적 평균 피해). p_e = clamp((21 − (인물 방어 − 적 명중)) / 20, 0.05, 0.95) |
| 장신구, 유물 | 없음 | 효과 가치만 계산. 명중·방어·HP를 바꾸는 효과가 있으면 해당 성분에 반영 |

### 7.3 효과 가치 V

V는 착용 장비 한 개가 가진 비전투 효과의 가치 합(%)이다. 기본값에 태도·전문화 배수를 곱한다. 한 장비의 V는 최대 30%다.

| 효과 | 기본 가치 | 배수 |
| --- | --- | --- |
| 탐색 판정 +1 | 3% | 길잡이 ×2, 모험적 ×1.5 |
| 기동 판정 +1 | 3% | 길잡이 ×1.5 |
| 행운 +1 | 2% | — |
| 공포 판정 +1 | 1% | 주 활동 장소가 D2·D3·H4·H5면 ×3 |
| 이동 시간 −10% | 3% (비례, +10%는 −3%) | 모험적 ×1.5 |
| 모험 발견 장면 가중치 +20% | 4% | 모험적 ×1.5, 길잡이 ×1.5 |
| 폐광 피로 −30% | 3% | TI05 보유 ×2, 주 활동 장소가 폐광이 아니면 ×0.3 |
| 광맥 채취 +50% | 2% | 주 활동 장소가 D1~D3이면 ×2 |
| 선제 명중 +1(W03) | 2% | — |
| 패배 손실 감소(J01) | 3% | 도전적 ×2 |
| 출정당 탈출(R01) | 8% | 도전적 ×1.5, 치명 위험 허용 켬 ×2 |
| 부상 판정 +2 | 3% | 수호자 ×1.5 |
| 함정 판정 +1 | 1.5% | 04의 던전 가중치 25 이상이면 ×2 |
| 밤 은밀 +1 | 1% | — |
| 3.6·3.7 표의 효과 | 표의 평가 가치 | — |
| 저주 불리(J05, R04) | 계산하지 않음 | 저주 장비는 자동 교체 대상이 아니다 |

### 7.4 개선률

**개선률 = 전투 성분 개선률 × 태도 배수 + (V_새 − V_현재)**

| 태도 | 무기 배수 | 방어구 배수 |
| --- | --- | --- |
| 안정적 | 0.8 | 1.2 |
| 모험적 | 1.0 | 1.0 |
| 도전적 | 1.2 | 0.8 |
| 수호자 전문화 | — | +0.2 |

- 전투 성분 개선률 = 새 성분 / 현재 성분 − 1.
- 장신구·유물은 전투 성분 개선률이 0이다(명중·방어·HP 효과가 없을 때).
- **교체 조건**: 개선률 ≥ 0.08, 또는 현재 슬롯이 비었거나 시작 지급 장비(W01, A01)일 때.

#### 계산 예 1 — 첫 인물, 모험적, 레벨 1, A01 → A02 (D21 첫 출정 보장 드롭)

- 최대 HP 33(힘 3), 민첩 2. 기준 적 L1: 명중 +2, 평균 피해 1.5.
- A01: 방어 11 → p_e = (21 − 9)/20 = 0.60 → B = 33 / (0.60 × 1.5) = 36.7.
- A02: 방어 12 → p_e = 0.55 → B = 40.0.
- 개선률 = (40.0 / 36.7 − 1) × 1.0 = **+9.1%** ≥ 8% → 교체. 기록 `누빈 천옷 위에 가죽조끼를 걸쳤다.`
- 같은 기준으로 W01(1~4) → W02(2~5)는 P 2.45 → 3.15, **+28.6%**다.

#### 계산 예 2 — 도전적, 레벨 14, H3 주 활동, W04 좋은(늑대 사냥꾼) → W06 일반

- 힘 5, 민첩 3, 근접 3. 기준 적 L14: 방어 14. H3 계열 비중: 늑대 100%.
- W04 좋은(6~12, 명중 +1, E07 늑대 대상 피해 +2): 명중 보정 9 → p_c 0.80. d_c = 9 + 2 + 2 × 1.0 = 13 → P = 10.4.
- W06 일반(8~16, 늑대 대상 명중 +2): 명중 보정 8 + 2 × 1.0 = 10 → p_c 0.85. d_c = 12 + 2 = 14 → P = 11.9.
- 개선률 = (11.9 / 10.4 − 1) × 1.2 = **+17.3%** → 구매(가격 1,100, 예산 안일 때). 기록 `늑대를 상대하려고 송곳니 창을 샀다.`

#### 계산 예 3 — 안정적 길잡이, 레벨 20, A05 희귀(귀환 발걸음) → A06 일반

- 기본 HP 118(힘 6), 민첩 4. 기준 적 L20: 명중 +8, 평균 피해 7.
- A05 희귀: 방어 10 + 7 + 2 = 19, HP 128 → p_e 0.50 → B = 36.6. V = 기동 +1(3% × 1.5) + 밤 은밀 1% + X03 4% = 9.5%.
- A06 일반: 방어 19, HP 133 → B = 38.0. V = 이동 +10% → −3%.
- 개선률 = (38.0 / 36.6 − 1) × 1.2 + (−3% − 9.5%) = 4.7% − 12.5% = **−7.8%** → 교체하지 않는다.
- 단계가 높아도 길잡이의 발걸음을 무겁게 만드는 갑옷은 고르지 않는다. 이 차이가 전문화마다 다른 장비를 입게 만든다.

## 8 자동 구매와 교체

04의 마을 루틴이 `마을 정비`에서 이 알고리즘을 호출한다. 04는 루틴의 순서만 정하고, 치료 기준·구매 목표·교체 판단의 값은 이 절이 정한다.

```text
function 마을_정비(인물, 방침):
    # 0. 판매 (9절)
    재료_주머니_전부_판매()
    가방_정리_판매()

    # 1. 필수 치료 — 예약금과 무관하게 소지금에서 지불

        elif 소지금 >= 중상_치료비: 치료소_입원(6분)
        else: 길드_무료_치료(12분)

    if not 인물.흡혈귀:

    회복약을 목표(4 / 3 / 2)까지: 레벨 기준 단계 또는 그 아래에서 살 수 있는 가장 높은 단계
    야영_식량을 2개까지

    예약_비율 = 방침.구매_예약금 ?? 태도별(40% / 30% / 20%)
    예약_비율 += 10%p if TA06 보유                                  # 06
    예산 = 소지금 × (1 − 예약_비율)

    # 4. 장비 교체 판단 (슬롯별 최선 후보)
    잠긴_슬롯 = {착용 장비에 잠금(🔒)이 걸린 슬롯}                 # 수동 장착 장비는 자동 잠금(8.1)
    제안_목록 = []
    바꾼_슬롯 = {}
    repeat 최대 3회:

               − 길드 등급 미달 품목
               − 이번 계절에 판매한 같은 정의·같은 등급의 상점 품목
               − 이번 계절에 `무시`한 제안과 같은 정의·같은 등급의 후보
               − 잠긴_슬롯 ∪ 바꾼_슬롯 에 속한 장비
               − 가격 > 예산인 상점 품목                          # 가방·대기함 장비는 가격 0
        가능 = [c for c in 후보
                if 개선률(c) >= 0.08 or 현재_슬롯이_비었거나_W01_A01(c.슬롯)]
        if 가능이 없음: break
        최선 = 개선률이 가장 큰 후보
               (동률이면 가격이 낮은 쪽, 그다음 무기 > 방어구 > 장신구 > 유물)
        if 방침.장비_자동_교체 == 끔:
            제안_목록.append(최선)                                   # 8.2
        else:
            구매·장착(최선); 예산 −= 가격
            이전_장비 → 가방(잠금·유품·고유면 보관, 아니면 다음 귀환 때 판매 대상)
            기록(교체_이유_문장(최선))                             # 7.5
        바꾼_슬롯.add(최선.슬롯)
    if 방침.장비_자동_교체 == 끔: 제안_갱신(제안_목록)               # 8.2
```

- **출정 중 획득 장비**: 다음 판단 지점에서 같은 개선률 계산을 한다. 8% 이상이고 그 슬롯이 잠기지 않았으면 비용 없이 바로 장착한다(자동 교체 켬일 때). 기록 `[장비] 주운 {item:을/를} 바로 찼다.` 자동 교체 끔이면 제안(8.2)으로 남긴다.
- **R01**은 길드 특별 상점의 유일한 상시 희귀 품목이다. 가치 8%(도전적·치명 허용이면 최대 24%)로 평가하므로, 도전적 인물은 은패를 받은 뒤 돈이 모이면 사게 된다.

### 8.1 수동 장착과 잠금 (03 §5.3.1과 연결)

| 사용자 동작(03 §5.3.1) | 이 문서의 처리 |
| --- | --- |
| `장착` | 그 장비를 입히고 **잠금(🔒)을 자동으로 건다**. 잠긴 착용 장비의 슬롯은 자동 교체 대상에서 빠진다. 출정 중이면 다음 마을 도착 때 마을 정비 0단계보다 먼저 적용한다 |
| `해제` | 가방으로 보낸다. 무기·방어구 칸이 비면 다음 정비의 4단계가 `현재_슬롯이_비었음` 규칙으로 채운다 |
| `잠금` / `잠금 해제` | 잠긴 장비는 자동 판매(9절)와 자동 교체 대상이 아니다. 착용 장비의 잠금을 풀면 다음 정비부터 그 슬롯을 다시 판단한다 |
| `유품 지정` | 9.1 보호 대상이 된다. 교체 판단에는 영향을 주지 않는다(착용 중인 유품은 잠금을 따로 걸지 않으면 더 나은 장비로 바뀔 수 있고, 바뀐 유품은 가방에 보관된다) |
| 저주 장비 `장착` | 사용자 확인 뒤에만 장착한다(01 §10). 장착하면 자동 잠금이 걸리므로 자동 교체가 벗기지 않는다. 벗는 것도 사용자가 `해제`로 한다 |

### 8.2 교체 제안 (장비 자동 교체 끔)

- 4단계에서 고른 최선 후보를 실행하지 않고 **교체 제안**으로 남긴다. 슬롯당 1건, 최대 4건이다. 새 판단이 나오면 같은 슬롯의 제안을 새 것으로 바꾼다.
- 제안에는 **만료가 없다.** 사용자가 `제안 수락` 또는 `무시`를 누르거나, 같은 슬롯의 새 제안이 생기거나, 제안 장비가 사라질 때(상점 재고 갱신, 가방 장비 판매·분실)만 지운다.
- `제안 수락`: 가방·대기함 장비는 마을에 있으면 즉시 장착, 출정 중이면 다음 마을 도착 때 장착한다. 상점 구매 제안은 다음 마을 정비 4단계에서 예산을 다시 확인해 산다. 예산이 모자라면 제안을 지우고 `[장비] {item:을/를} 살 돈이 모자랐다.`를 남긴다. 수락해 장착한 장비에는 수동 장착과 같이 잠금이 걸린다.
- `무시`: 제안을 지운다. 같은 정의·같은 등급의 후보는 그 계절 동안 다시 제안하지 않는다.
- 제안이 생기면 기록 `[장비] {item:이/가} 더 나아 보인다.`(제안당 1회)를 남기고, 인물 탭 장비 칸 아래 `교체 제안 N건 ›` 줄로 보인다(03 §5.3.1).

## 9 판매, 가방, 수령 대기함

### 9.1 보호 대상 (자동 판매하지 않음)

착용 중 장비, 사용자가 잠근 장비, 유품으로 지정한 장비, 고유 장비(W07, W10, J01, J05, R01, R03, R04), 이번 생애에 계승받은 유품.

### 9.2 귀환 시 자동 판매

1. 재료 주머니 전부.
2. 보호 대상이 아닌 **일반** 등급 장비 전부.
3. 보호 대상이 아닌 **좋은** 등급은 슬롯마다 개선률이 가장 높은 1개를 예비로 남기고 판다.
4. **희귀** 등급은 팔지 않는다. 가방이 16칸 이상이면 단계가 레벨 기준보다 2 이상 낮은 희귀부터 판다.
5. 기록은 묶어서 한 줄: `[마을] 쓰지 않는 장비 3개를 팔았다. 동전 212개.`

### 9.3 출정 중 가방이 찼을 때 (현장 정리, D25)

가방이 가득 차는 것은 **귀환 조건도, 던전 진입 조건도 아니다**(D25, 01 §2.5). 가방 20칸이 찬 상태에서 새 장비를 얻으면 그 자리에서 정리한다(v0.1 §9.2).

1. 새 장비와 가방 속 비보호 장비 가운데 판매가가 가장 낮은 1개를 **현장 환전**한다(판매가 × 80%, 내림).
2. 모두 보호 대상(9.1)이면 새 장비가 일반·좋은 등급일 때 현장 환전하고, 희귀·고유일 때 **수령 대기함**(9.4)에 넣는다.
3. 기록은 출정마다 묶어서 한 줄: `[장비] 가방이 차서 {count}개를 현장에서 팔았다.`

### 9.4 수령 대기함

- 용량 10개. 마을에 돌아와 가방에 빈칸이 생기면 오래된 것부터 자동으로 옮긴다.
- 대기함이 가득 차면 가장 오래된 희귀(고유 제외)를 판매가로 환전한다.
- 대기함의 물건도 **그 세대의 자산**이다. 유품 지정 대상이 될 수 있지만 유품 2개 제한에 같이 들어간다. 계승 때 가방·대기함을 같은 규칙으로 정산한다(12). 첫 검증판에는 별도 창고가 없다. 창고를 추가하면 같은 규칙을 적용한다.
- 계승 정산에서 12가 쓰는 장비 가치는 이 문서의 판매가(판매 불가 장비는 평가가 × 25%)다. 소모품(CP01~CP08)은 되팔 수 없으므로 정산 가치 0이다.

### 9.5 고유 장비 재획득 대체 (01 §9.5)

고유 장비(W07, W10, J01, J05, R01, R03, R04)는 **가문 안에 1개**만 있다. 가문에 이미 그 장비가 있을 때(착용·가방·수령 대기함·유품·다음 세대 대기 중인 유품 모두 포함) 같은 장비를 다시 얻게 되면 아래로 대신 준다.

| 장비 | 다시 얻는 경로 | 대체 보상 |
| --- | --- | --- |
| W07 종이 달린 짧은 검(T3) | C01-3 구조 선택(후계자가 C01을 이어받은 경우, 10) | T3 희귀 무기 1개(W06) |
| W10 파수꾼의 종추(T5) | EB03 첫 격파 | T5 희귀 장비 1개(W09 또는 A07, 균등) |
| J01 낡은 호각(T1) | C02-3 | T1 희귀 장신구 1개(J02) |
| J05 속삭이는 종 조각(T4) | D3 보물 방 | 그 상자의 일반 굴림 결과(J05 후보를 빼고 다시 굴림) |
| R01 귀환의 방울(T2) | 길드 특별 상점 | 판매 목록에 나오지 않는다(14절) |

- 대체 보상의 희귀 효과(3.7)는 새로 굴린다. 한 줄 기록 `[장비] 대신 {item:을/를} 받았다.`, 상세 기록 `같은 물건은 이미 집에 있었다.`
- 고유 장비를 판매·분실·소멸로 잃었으면 가문에 없는 것으로 본다. 단 W07·W10·J01·R03·R04는 판매 불가이고 고유 장비는 패배 손실이 없으므로(07 §8.1) 실제로 잃는 경로는 R03 사용과 J05 판매뿐이다.

| 조건 | 기록 문장 예 |
| --- | --- |

### 13.3 보존 규칙

- 유품 지정, 희귀 이상, 고유 장비는 모든 필드를 영구히 보존한다. 판매하거나 잃어도 가문 도감의 기록으로 남는다.
- 일반·좋은 등급은 획득 한 줄만 두고, 판매하면 기록을 지운다.
- 유품 사연 표시 문장 = 첫 획득 문장 + 가장 최근 주요 순간. 예: `1대 모라가 종소리 폐광에서 받았다. 리아가 이 검으로 부서진 종을 멈췄다.`
