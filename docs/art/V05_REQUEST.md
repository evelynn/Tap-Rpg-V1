# V05_REQUEST — 이미지 생성 AI에게 넘기는 v05 요청 묶음

버전 1.0 · 2026년 9월 24일 · 받는 쪽: 이미지 생성·편집 모델을 쓰는 제작 AI
근거: v04 검토(`PROMPTS.md` §2.4), 규격 고정 절차(`PROMPTS.md` §0.4), 몬스터 표준(`prompts/P2_world.md` §2.0). 이 문서는 **순서·입력·틀·합격**만 가진다. 영어 문장은 「프롬프트」 칸이 가리키는 문서 절에서 **전문 그대로** 옮긴다(여기에 다시 적지 않는다).

## 0 먼저 지킬 것

**하지 않는다**

1. 코드로 그림을 만들거나 고치지 않는다. 자르기·크기 바꾸기·배경 지우기·색 바꾸기·합치기·옮기기를 하지 않는다. 생성·편집 결과를 **그대로** 낸다(D56).
2. 한 요청 = 한 장. 두 시트를 한 이미지에 담지 않고, 한 시트를 여러 장으로 나누지 않는다.
3. 투명 배경을 요청하지 않는다. 배경은 불투명 `#FF00FF` 한 색이다(v04 투명 배경 → 그림 속 반투명 화소 38만~64만 개).
4. 출력 크기를 「자동」으로 두지 않는다. 틀 항목은 틀의 캔버스(1536 × 1024 가로, 1024 × 1536 세로)로, 편집 항목은 입력과 같은 크기로 지정한다(v04는 장마다 크기가 달랐다).
5. 옷·무기 레이어 떼기, 32 규격, 「틀 필요」 시트(`PROMPTS.md` §0.4.3)는 이번 묶음에 없다. 요청하지 않는다(옷·무기는 게임 쪽 도구 `derive`가 뗀다).

**한다**

- 글 조립: `PROMPTS.md` §0.1 순서(A + B + **T + NUM** + C + 본문 + D). T는 `PROMPTS.md` §1, NUM은 `PROMPTS.md` §8의 해당 코드 블록을 그대로 붙인다.
- 입력 1 = 틀 이미지(항목의 「틀」 칸). 틀의 청록 눈금과 자리표시 인물은 결과에 남기지 않는다(T가 말한다).
- **문**: 틀 항목은 결과마다 `pnpm art:gate <png> --spec <시트>`를 돌린다(명령 실행이지 코드 작성이 아니다). 종료 코드 0이면 육안 기준으로 간다. 떨어지면 출력의 `Regeneration feedback:` 문단을 GF 블록(`PROMPTS.md` §1)으로 같은 글 끝에 붙여 다시 생성한다. **최대 3번**(처음 + 다시 2번, 파일 `-r2`·`-r3`). 세 번째도 떨어지면 멈추고 보고한다.
- 편집 항목: 입력 캔버스·칸·위치를 그대로 둔다. 결과를 입력과 겹쳐 차이가 요청한 곳에만 있어야 한다. 결과 크기가 입력과 다르게 나오면 멈추고 보고한다.
- **한 계보**: 기준 시트를 색 교체한 결과(V05-01~04)가 그 시트의 새 원본이다. 그 시트의 몸체·가림막(V05-07~09)은 모두 그 결과에서 만든다.
- 저장: `assets/_imagegen/v05/<파일>.png` + 같은 이름 `.prompt.txt`(보낸 글 전문) + 폴더 `README.md`(항목마다: 입력 파일, 문 결과 전문, 몇 번째 시도, 눈으로 본 결과, 남은 차이).
- 순서는 표 순서다. 「선행」이 합격하기 전에 시작하지 않는다.

**보고할 때**(멈춤): 세 PNG, 각 `art:gate` 출력, 보낸 글 전문, 한 줄 원인 추정. 같은 지적이 두 번 되풀이되면 게임 쪽이 틀·수치·문장을 다시 본다.
