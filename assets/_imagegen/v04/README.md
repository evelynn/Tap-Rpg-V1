# v04 — 추가 스프라이트 및 배경 재제작

2026-09-24. 내장 ImageGen 생성·편집 원본. 기존 v03와 assets/game 파일은 교체하지 않았다.

## 배경 품질 기준

사용자가 지정한 최소 품질 기준은 [기존 네 지역 배경](../../../output/pixel-art-v01/images/bg_four_regions_draft.png)이다. 단순한 색면과 큰 블록으로 과도하게 단순화한 `00-field-composite.png`는 불합격이며 후속 배경의 기준으로 쓰지 않는다.

새 배경은 [bg-four-regions-quality-r2.png](bg-four-regions-quality-r2.png). 마을·들판·폐광·길바뀜의 틈을 위에서 아래로 배치한 4개 합성 장면이다. 기존 시안을 직접 참고 입력으로 사용했다. 식생 덩어리, 건축 재질, 지형 겹침, 동굴의 깊이와 의도적으로 배치한 픽셀 디테일을 유지한다. 배경에 캐릭터용 단순화 조건을 과하게 적용하지 않는다.

이 파일은 품질 기준 합성본이다. 256×64 게임 타일, 먼/중간/가까운 3층, 조명 겹침, 좌우 무봉제 연결과 최종 명도 검사를 완료했다는 뜻이 아니다. 생성 결과의 마을 창과 폐광 등불은 켜져 있으므로 기본 배경/조명 분리 단계에서 처리해야 한다. 지역별 시설 배치도 P2 최종 사양과 대조해야 한다.

## 제작 방식과 현재 범위

- 검토한 문서: `docs/art/PROMPTS.md`, `prompts/P1_character.md`, `prompts/P2_world.md`, `prompts/P3_scenes.md`, `ASSET_ORDERS.md`, 아트 스프라이트 사양. 작업 중 갱신된 PROMPTS v1.2의 NPC 전신 기준도 반영했다.
- P1·P2·P3는 전체 제작 목록이다. **이 폴더는 추가 제작 묶음이며 캐릭터 388프레임 및 세계·이벤트 장면 전체 완료본이 아니다.**
- 사용자 요청에 따라 새 스프라이트는 문서의 자홍색 대신 실제 투명 PNG를 요청했다. 원본 픽셀을 코드로 자르기·축소·배경 제거·양자화하지 않았다.
- Windows 파일 복사와 읽기 전용 PNG 메타데이터/알파 히스토그램 확인만 수행했다. D56의 게임용 정규화·앵커·프레임 JSON 생성은 수행하지 않았다.
- 파일명의 48은 논리 목표 규격이다. 실제 생성 해상도나 정확한 셀 치수를 뜻하지 않는다. O02의 사용자 비교 시험을 대신하거나 48 규격 최종 채택을 선언하지 않는다.
- 동일 이름 `.prompt.txt`에 프롬프트 전문을 보관한다. 재시도 원본도 삭제하지 않는다. 입력과 검토 결과는 아래 표를 따른다.

## 알파와 크기

읽기 전용 확인에서 기존 `assets/game` 7개 PNG는 모두 인덱스 모드 P, 알파 0/255 두 값이었다. 새 스프라이트 원본은 RGBA이고 대부분 실제 alpha=0 배경을 포함하지만 **불투명하게 보여야 할 내부에도 반투명 픽셀이 많이 남아 있다.** 단순히 '투명 PNG'라는 이유로 게임용 알파 검사를 통과한 것으로 취급하지 않는다. 코볼트 r3는 alpha=0 픽셀이 0개다.

최종 치수·알파 수치와 추가 제작 결과는 [REVIEW.md](REVIEW.md)에 기록했다. PNG 23장과 실제 사용 프롬프트 23개를 보관했으며, 23장 모두 생성 원본과 SHA-256이 일치한다. 몸체·천옷 E, HR01 3자세, 피격 검 3칸, 코볼트 배경 복구 r4도 추가됐다. 색 수, 레이어 합성 일치, 프레임 재생, 520×64 화면, 타일 이음과 런타임 정규화 검수는 별도 작업이다.
