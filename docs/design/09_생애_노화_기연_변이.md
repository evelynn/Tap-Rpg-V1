# 09 생애, 노화, 기연, 변이

버전 0.2 · 작성일 2026년 9월 22일 · 상위 문서 00_문서지도.md, 01_핵심규칙_수치기준.md

한 인물의 생애가 시작하고, 무르익고, 늙고, 끝나는 규칙을 정한다. 은퇴와 사망의 절차, 은퇴한 인물이 다음 세대에 남는 방식, 생명 연장 기연(F02)과 흡혈귀 변이(TM01)의 기계적 규칙을 다룬다. 사건 원문은 11 문서가 쓰고, 이 문서는 규칙과 시스템 문장만 쓴다.

관련 문서: 01_핵심규칙_수치기준.md(§1, §2.2, §6.3, §7, §14), 04_생활순환_행동결정.md(귀환 규칙), 06_특성.md(TM01), 07_전투_사냥_던전_모험.md(§5.6 관문 도전 조건), 08_아이템_경제.md(§7 장비 평가, CP08, R03), 10_사건_시스템.md, 11_사건_목록.md(F02, F03, S03, S04, S07, S08 원문), 12_세대계승_가문.md(계승, 별칭, 후손 반응), 13_오프라인_저장.md(생애 단계 경계 정지), 14_일지_문체_가이드.md, 15_아트_스프라이트_사양.md(노화 외형)

**소유 범위(00 §2.4)**: 생애 단계, 노화, 은퇴 절차와 은퇴 역할, S07 빈도, F02·F03의 기계 규칙, 흡혈귀·갈증, 생애 시간표. 사건 원문은 11, 별칭과 가문 플래그의 후손 반응은 12가 소유한다.

## 1 생애 단계

### 1.1 단계 요약

| 단계 | 나이 | 유효 진행 분 구간 | 예상 레벨(01 §2.4) | 길드 등급 흐름 | 주 활동 장소 |
| --- | --- | --- | --- | --- | --- |
| 새내기 | 18~29 | 0~144 | 1 → 10~11 | 견습 → 동패 | T00, H1, H2, H3, A1, A2, D1(후반) |
| 전성기 | 30~49 | 144~384 | 11 → 20 | 동패 → 은패 → 금패 | H3, H4, D1, D2, A2, A3 |
| 숙련기 | 50~64 | 384~564 | 20 → 26 | 금패 → 별패 | H4, H5, D2, D3, A3, A4 |
| 노년기 | 65~은퇴 | 564~600(표준) / ~720(연장 78세) | 26 → 27 (연장 시 30, 75.4세 도달) | 별패 | H5, D3, A4, T00 체류 증가 |

- 단계 경계(30세, 50세, 65세)에 도달하면 `[성장]` 중요 기록을 남기고 외형 단계를 바꾼다.
- 13 문서의 `생애 단계 경계 정지`가 켜져 있으면 오프라인 정산이 이 경계에서 멈춘다(01 §15).

### 1.2 단계별 상세

#### 새내기 (18~29세)

| 항목 | 내용 |
| --- | --- |
| 게임 안 변화 | 레벨이 빠르게 오르고(레벨 2까지 4분), 첫 출정에서 첫 장비 교체와 첫 판정(D21), 첫 귀환을 겪는다. 레벨 8에서 A2와 F01 조건이 열린다 |
| 사건 풀 | 생활 L01~L12, L19, L21. 연속 C02 전체. 운명 F01(레벨 8 이상). L04는 이 단계 전용 |
| 외형 | `어린 모습`: 큰 눈, 짧은 앞머리, 몸보다 큰 배낭 |
| 기록 톤 | 들뜨고 서툴다. 실패도 가볍게 넘긴다. 예: `[사냥] 들쥐에게 신발끈을 물렸다. 창피했다.` |

#### 전성기 (30~49세)

| 항목 | 내용 |
| --- | --- |
| 게임 안 변화 | 전문화 이후 성장 방향이 뚜렷해진다. 폐광 상층·중층 관문을 넘고 가정을 꾸린다(S01, 28~34세). 수입과 지출이 가장 크다 |
| 사건 풀 | L13~L20(폐광·산길), L22 시작. 연속 C01 전체. 운명 F03(35~64세, A4 진입 후 — 실제로는 숙련기에 주로 만난다, 9절). 시스템 S01, S02 |
| 외형 | `성숙한 모습`: 키 1픽셀 차이 없이 얼굴 윤곽과 앞머리만 바뀐다(15 문서). 배낭이 몸에 맞는 크기로 바뀐다 |
| 기록 톤 | 자신감과 책임. 가족 이야기가 섞인다. 예: `[던전] 집에 두고 온 아이 생각에 한 방 더 가지 않았다.` |

#### 숙련기 (50~64세)

| 항목 | 내용 |
| --- | --- |
| 게임 안 변화 | 50세에 지식·의지 +1, 60세에 힘·민첩 −1. 회복 계수가 0.9 → 0.8로 떨어진다. 심층(D3)과 길바뀜의 틈(A4)은 모험적 기준 약 57세부터 열린다(9절) |
| 사건 풀 | L22, L24(숙련기 전용 시작). 운명 F02(50세 이상). F03은 64세까지 |
| 외형 | `희끗한 모습`: 옆머리에 흰색 2픽셀, 눈가 주름 1픽셀 |
| 기록 톤 | 여유와 회고. 옛 사건을 떠올리는 문장이 늘어난다. 예: `[모험] 이 갈림길, 스물다섯에도 헤맸었다.` |

#### 노년기 (65세~은퇴)

| 항목 | 내용 |
| --- | --- |
| 게임 안 변화 | 은퇴 준비. 65세 도달 시 유품 등록 안내를 한 번 띄운다(12 문서). 표준 진행에서는 약 3년(36분)이다 |
| 사건 풀 | 새 연속 사건을 시작하지 않는다(진행 중인 연속 사건은 계속). `[가족]`·`[인연]` 기록 가중 ×2. 은퇴 전 마지막 목표 기록 |
| 외형 | `흰 머리`: 머리 전체 흰색, 자세 1픽셀 숙임, 걷기 동작 속도 ×0.9 |
| 기록 톤 | 담담하고 차분하다. 농담을 줄인다. 예: `[휴식] {name:은/는} 오래 불을 바라보다 잠들었다.` |

## 2 나이 진행

### 2.1 규칙

- 나이는 유효 진행 12분마다 1씩 오른다(01 §1.1). 인물 생성 시점을 0분으로 센다.
- 나이가 오르는 순간이 전투나 방 진행 중이면 **다음 판단 지점**에서 나이 효과를 적용한다. 진행 중인 판정은 이전 나이 기준으로 끝낸다.
- 나이는 다음 동안 멈춘다: 일시정지, 운명 사건 선택 대기, 계승 화면 대기, 생애 단계 경계 정지.

### 2.2 노화 효과 적용 (01 §2.2)

| 도달 나이 | 효과 | 기록 문장 |
| --- | --- | --- |
| 30 | 외형 `성숙한 모습` | `[성장] 서른이 되었다. 배낭이 조금 가벼워졌다.` |
| 50 | 지식 +1, 의지 +1, 회복 계수 0.9, 외형 `희끗한 모습` | `[성장] 쉰 살. 서두르지 않는 법을 알았다.` 상세 `(지식 +1, 의지 +1)` |
| 60 | 힘 −1, 민첩 −1, 회복 계수 0.8 | `[성장] 예순. 오르막이 조금 길어졌다.` 상세 `(힘 −1, 민첩 −1)` |
| 65 | 외형 `흰 머리`, 유품 등록 안내 | `[성장] 머리가 하얗게 셌다. 남길 것을 생각할 때다.` |
| 70 (연장 시) | 힘 −1, 민첩 −1, 회복 계수 0.7 | `[성장] 일흔. 검이 조금 무거워졌다.` 상세 `(힘 −1, 민첩 −1)` |
| 80 이상 10년마다 (흡혈귀 제외, 연장 상한 내) | 힘 −1, 민첩 −1, 회복 계수 0.6 | `[성장] 여든. 오늘도 신발끈은 스스로 맸다.` |

- 능력치 감소로 최대 HP가 줄면 현재 HP는 새 최대값을 넘지 않게 자른다.
- 능력치는 1 아래로 내려가지 않는다. 50세 보정으로 지식·의지가 자연 상한 8을 넘게 되면 8에서 멈춘다.
- 60세 감소로 주 무기 능력치가 떨어지면 08 §7 장비 평가가 다시 계산되어, 민첩 무기에서 힘 무기(또는 반대)로 바꾸는 판단이 생길 수 있다. 이 교체는 `[장비]` 기록에 이유를 남긴다: `손목이 예전 같지 않아 가벼운 단검으로 바꿨다.`

## 3 은퇴

### 3.1 은퇴 나이 도달

```text
나이 ≥ 은퇴 예정 나이 (기본 68, F02 마신다 시 78)
  → 플래그 retire_pending = true
  → 이후 04의 행동 결정에서 "새 출정" 후보를 모두 제외
  → 현재 출정 중이면 다음 판단 지점에서 귀환 시작 (04의 귀환 규칙)
  → 마을 도착 시 S03 은퇴 사건
```

| 도달 시점의 상태 | 처리 |
| --- | --- |
| 마을 대기·정비·치료 중 | 현재 행동이 끝나면 S03 |
| 사냥·모험 출정 중 | 다음 조우·장면 사이에서 귀환 시작. 귀환 이동은 04 규칙을 따른다 |
| 던전 방 진행 중 | 현재 방을 끝낸 뒤 귀환 시작. 다음 방으로 가지 않는다 |
| 관문 전투 중(치명 포함) | 전투를 끝까지 판정한다. 치명 활동의 위험을 무효로 하지 않는다(v0.1 §10.2). 생존하면 귀환 |
| 야영 중 | 야영을 끝내고 귀환 |
| 선택 대기 중 | 나이가 멈춰 있으므로 도달하지 않는다 |
| 중상으로 치료 중 | 치료를 마친 뒤 S03. 치료비는 평소대로 낸다 |

- 은퇴 대기 중에 사망 조건(치명 활동 최후 판정 실패)이 먼저 오면 S04가 우선한다.
- 은퇴 대기 중에도 생활 사건은 마을 안에서 일어날 수 있다. 운명 사건은 새로 제시하지 않는다.

### 3.2 S03 은퇴 사건의 흐름

1. `환호` 대신 `앉기와 식사` 동작으로 마을 여관 앞에 앉는 장면 8초.
2. 한 줄 기록: `[은퇴] {name:은/는} 오늘 배낭을 내려놓았다.`
3. 은퇴 후 역할 결정(4절)과 역할 기록: `[은퇴] {name:은/는} 오늘부터 길드 앞 작은 여관을 맡기로 했다.`(v0.1 §15.1)
4. 12 문서의 계승 절차 1단계(생애 종료)로 넘어간다.
5. 12 §1.1 2단계에서 생애의 책을 엮는다(18 §2.1).

### 3.3 조기 은퇴

| 항목 | 규칙 |
| --- | --- |
| 조건 | 마을 대기 또는 마을 정비 상태, 선택 대기 없음, 25세 이상 |
| 25~29세 | 확인을 한 번 더 받는다(01 §14) |
| 결과 | 정상 은퇴와 같다. 유품 2개, 돈 20% 이전 |
| 은퇴 예정 나이 | 기록상 `조기 은퇴 (n세)`로 남는다 |

첫 확인 문구:

> **{name:은/는} 지금 {age}세입니다.**
> 여기서 모험을 마치면 남은 길은 다음 세대가 걷게 됩니다. 은퇴하면 되돌릴 수 없습니다.
> [은퇴한다] [조금 더 걷는다]

30세 미만 두 번째 확인 문구:

> **아직 새내기의 시간입니다.**
> 가정을 꾸리기 전이라면 후계자는 친척이나 가문이 맡은 아이가 됩니다. 그래도 은퇴할까요?
> [은퇴한다] [돌아간다]

### 3.4 은퇴 반복 악용 방지

v0.1 §10.2의 "잦은 조기 은퇴만으로 보상을 모으지 못하게"를 다음 규칙으로 지킨다.

1. 조기 은퇴는 25세부터 가능하다. 한 생애에 최소 84분(7년)의 유효 진행이 필요하다.
2. 가문 업적과 해금 조건에 **은퇴 횟수, 세대 수, 생애 수**를 쓰지 않는다(12 문서 8절).
3. 후계자 후보는 생애 종료 전 기록으로 정해지고, 계승 화면을 다시 열어도 바뀌지 않는다(12 문서 10절).
4. 은퇴 자체는 경험치, 동전, 장비를 새로 만들지 않는다.

## 4 은퇴 후 인물의 역할

### 4.1 역할 결정

은퇴한 인물은 세 역할 중 하나로 가문 기록과 후계자의 생애에 등장한다. 역할은 은퇴 시점에 점수로 정하고, 동점이면 `편지를 보내는 가족`이다.

| 역할 | 점수 조건 (각 +1, 표시된 것은 +2) | 후계자에게 주는 것 |
| --- | --- | --- |
| 길드 앞 작은 여관 주인 | 교섭 숙련 3단계 이상, TA04 보유(+2), TI08 보유, 여관 휴식 누적 60회 이상 | 후계자 30세까지 여관비 50% |
| 길드 교관 | 근접 숙련 4단계 이상, TA05 보유(+2), 전문화 `수호자`, EB02 격파 | 교육 사건 2회(각 회: 후계자가 고른 숙련의 누적 사용 횟수 +20) |
| 편지를 보내는 가족 | 기본 1점, 가정 형성(S01) 완료, 60세 이후 은퇴 | S07 편지에 작은 선물(야영 식량 2개 또는 회복약 T1 1개) |

- 역할 점수가 모두 1 이하이고 가정이 없으면 `편지를 보내는 가족` 대신 `길드에 이름을 남긴 선배`로 서술만 바꾼다(효과는 편지 가족과 같다).
- 여관비 할인과 교육 사건은 후계자 30세(유효 진행 144분)에서 끝난다. **현역 때의 능력치, 특성, 종족 보너스는 어떤 형태로도 넘기지 않는다**(v0.1 §10.2).
- 교육 사건의 숙련 보너스는 한 숙련에 한 번만 받는다. 두 번째 교육은 다른 숙련을 고른다.

### 4.2 S07 은퇴한 부모의 편지

| 항목 | 값 |
| --- | --- |
| 기간 | 후계자 18~30세 |
| 발생 확인 | 후계자가 마을에 귀환할 때마다 12% |
| 최소 간격 | 유효 진행 15분 |
| 최대 횟수 | 6회(교관 역할이면 교육 사건 2회 포함) |
| 마무리 | 후계자가 30세가 된 뒤 첫 귀환 때 마무리 편지 1회 |

마무리 편지는 역할(4.1절)별로 첫 줄만 바뀐다. **원문은 11 S07이 소유한다**.

- 은퇴하지 못한 이전 인물(사망)은 S07이 없다.
- 긴 잠(S08)에 든 흡혈귀 인물은 S07 대신 후계자 생애 중 한 번 `달그늘에서 온 편지`만 보낸다(7.9절).
- 마무리 편지는 앞 세대 책의 후기가 된다(18 §3.6).

## 5 사망

### 5.1 발생 조건

사망은 **치명 활동에서 HP 0 → 최후 판정 실패**로만 일어난다(01 §6.3, D09). 첫 검증판의 치명 활동은 **EB03 관문 전투뿐**이다(D26). 운명 사건의 `치명` 선택지는 확장용이며 첫 검증판 사건에는 없다. 일반 활동의 패배, 자연 1, 노화로는 죽지 않는다.

EB03에 들어가려면 `치명 위험 허용`(관문 전투)이 켜져 있고, 치명 관문 위험 한도(01 §7.1: 안정적·모험적 위험 차 ≤ −1, 도전적 ≤ +2)와 07 §5.6 체력 조건을 모두 만족해야 한다. 사용자가 목적지를 고정해도 이 관문 조건은 면제되지 않는다.

### 5.2 S04 연출 순서

| 순서 | 화면 | 시간 | 설명 |
| --- | --- | --- | --- |
| 1 | `쓰러짐` 동작 5프레임, 마지막 프레임 유지 | 3초 | 적과 배경은 흐리게. 피나 상처 표현 없음 |
| 2 | 인물 곁의 등불이 깜빡이다 꺼짐(공용 효과) | 2초 | 배경 채도를 낮춘다 |
| 3 | 인물 스프라이트가 사라지고 배낭과 무기 한 점이 남음 | 4초 | 남은 물건은 유품 등록 1위 장비의 외형 |
| 4 | 마을 배경으로 바뀌고, 길드 편지가 펼쳐짐(계승 화면 1단계, 03 §8. 원문은 생애의 책 맺는 장에 실린다, 18 §3.4) | 사용자 확인까지 | 기본 창은 `선택 대기`와 같은 중요 표식만 표시 |

- 기본 창 한 줄: `[사망] {name}의 등불이 꺼졌다.` 소리는 켜져 있어도 낮은 종소리 한 번만 낸다.
- 전체 흐름 동안 유효 진행과 나이는 멈춘다. 오프라인 정산 중이면 여기서 멈추고 복귀 요약에 표시한다(13 문서).

### 5.3 길드 편지

편지는 사망 장소에 따라 3종 중 하나를 고르고 서명은 N01 하델이다. **원문은 11 S04가 소유한다**(00 §2.4). 첫 검증판에서 쓰이는 편지는 1번(종소리 폐광)뿐이고, 2·3번은 확장용이다(D26). `{relic}`은 12 §5.2의 사망 시 이전 유품 1개이며, 편지는 연대기에 원문 그대로 보존한다.

### 5.4 사망 원인 기록

v0.1 §8.1의 "운이 나빴다로만 표시하지 않는다"를 지키기 위해 사망 원인을 세 항목으로 남긴다.

```text
[사망] {name} ({age}세 · Lv{level}) — {place}
  진입 위험 : {risk_line}
  누적 부상 : {injury_line}
  결정적 순간 : {final_check_line}
```

두 예시 모두 01 §7.1의 치명 관문 위험 한도 안에서 들어간 경우다. 위험 차 = 관문 적 레벨(EB03 L29) − 유효 레벨(01 §7.2).

**예시 1 — 도전적 인물의 첫 관문 도전**

```text
[사망] 해솔 (63세 · Lv27) — 종소리 폐광 심층 관문
  진입 위험 : 치명(부서진 종의 파수꾼), 위험 차 +2(보통, 도전적 한도 +2 이내), 치명 위험 허용 켬(관문 전투)
  누적 부상 : 경상 1(민첩 −1), 관문 진입 시 체력 72%, 회복약 2개 → 3단계에서 모두 소진
  결정적 순간 : 최후 판정 주사위 6 + 의지 4 + 행운 1 = 11 / 난이도 15
```

**예시 2 — 연장된 노년의 재도전**

```text
[사망] 노을 (72세 · Lv28, 은퇴 예정 78세) — 종소리 폐광 심층 관문
  진입 위험 : 치명(부서진 종의 파수꾼), 위험 차 +1(보통, 도전적 한도 이내), 치명 위험 허용 켬(관문 전투), 귀환의 방울 없음
  누적 부상 : 중상 누적 3회(오래된 상처), 70세 노화(힘·민첩 −1), 회복 계수 0.7
  결정적 순간 : 최후 판정 주사위 2 + 의지 3 + 행운 1 = 6 / 난이도 15
```

- 예시 1은 위험 차가 한도 안이어도 주사위 한 번으로 생애가 끝날 수 있음을 보여준다. 예시 2는 노화와 누적 부상이 결정적 순간의 보정을 깎은 경우다. 원인 기록은 두 경우를 구별해 읽히게 한다.

### 5.5 다음 세대 방침 확인 화면

사망 원인 기록 바로 아래에 현재 방침과 바꿀 수 있는 항목을 보여준다. 계승 절차 3단계(후계자 결정) 전에 한 번 확인한다.

```text
┌ 다음 세대에 이어갈 방침 ─────────────────────┐
│ 태도            도전적      [바꾸기]           │
│ 위험 허용 상한   높음        [바꾸기]           │
│ 치명 위험 허용   켬(관문)    [끄기]  ← 강조     │
│ 목적지          심층 고정    [자동으로]  ← 강조 │
│                                  [확인]       │
└──────────────────────────────────────────────┘
```

- 사망에 직접 관여한 방침(치명 위험 허용, 목적지 고정, 위험 허용 상한)은 강조 표시한다.
- 여기서 바꾼 방침은 후계자 출발부터 적용한다. 바꾸지 않아도 된다.

## 6 생명 연장 — F02 별잠 샘물

사건 원문과 연출은 11 문서가 쓴다. 이 절은 기계적 규칙만 정한다.

### 6.1 제시 조건

| 조건 | 값 |
| --- | --- |
| 장소 | A4 길바뀜의 틈 모험 장면 |
| 나이 | 50세 이상(01 §12.3) |
| 횟수 | 생애 1회. 한 번 제시되면 선택과 무관하게 다시 나오지 않는다 |
| 제외 | TM01 흡혈귀 상태에서는 제시하지 않는다(변이 후 연장 불가, 01 §14) |
| 가중 | 기연 등장 가중 ×(1 + 0.05 × 행운)(01 §2.1) |

### 6.2 선택지 규칙

| 선택 | 즉시 효과 | 대가 | 남는 기록 |
| --- | --- | --- | --- |
| **마신다** | 은퇴 예정 나이 +10년(68 → 78) | 희귀 이상 등급의 **유물 슬롯** 장비 1개를 샘에 바친다. 없으면 대체 대가: 행운 −2(현 생애, 최저 0) | 연대기 `별잠 샘물을 마셨다`, 가문 플래그 `fam.f02_drank` |
| **유안에게 양보한다** | 없음 | 없음 | 연대기 `샘을 양보했다`, 가문 플래그 `fam.f02_gave_yuan`(후대 반응은 12 §7.6) |
| **병에 담는다** | R03 `별잠 물병` 획득(1회용, 08) | 없음(연장 없음) | 연대기 `샘물 한 병을 담아 왔다`, 가문 플래그 `fam.f02_bottled` |
| **그대로 돌아선다** | 없음 | 없음 | 기록만. 사전 방침 `거절하고 계속`의 자동 선택 |

- **바칠 유물 선택**: 착용 중, 가방, 수령 대기함의 희귀 이상 유물 중 선택 창에서 사용자가 고른다. 후보가 여럿이면 기본 선택은 유품 등록이 안 된 것 중 기준 가격이 가장 낮은 것이다. 유품으로 등록된 유물을 고르면 `이 유물은 다음 세대에 남길 물건입니다` 경고를 한 번 띄운다.
- **대체 대가**: 행운 −2는 현 생애에만 적용한다. 행운이 1이면 0이 된다. 선택 창에 `알려진 대가: 행운 −2 (현재 {luck} → {luck_after})`를 표시한다.
- **되돌림**: 세 선택 모두 되돌릴 수 없다. 선택 창에 `되돌릴 수 없음`을 표시한다(v0.1 §11.3).
- **사전 방침**: `새로운 운명 제안은 거절하고 계속`이 켜져 있으면 F02는 자동으로 `그대로 돌아선다`(연장 없음, 기록만)로 처리한다(10 §8.4). 선택지 원문은 11 F02가 정한다.

### 6.3 연장 규칙

| 항목 | 값 |
| --- | --- |
| 1회 연장 폭 | +10년 |
| 연장된 은퇴 나이 상한 | 98세(01 §14) |
| 첫 검증판 실제 최대 | 78세(연장 기연 1개) |
| 연장 후 노화 | 70세 도달 시 힘·민첩 −1, 회복 계수 0.7(2.2절) |
| 연장 후 생애 단계 | 노년기가 65~78세로 길어진다 |
| 연장 표시 | 인물 탭 나이 옆에 `은퇴 예정 78세 ✦` |
| 외형 | 연장 즉시 흰 머리에 은빛 광택 1픽셀 추가(`별잠 은발`, 가문 외형 해금 대상) |
| 유전 | 없음. 자녀의 은퇴 나이는 68세로 시작한다 |

- 연장 이후 F03으로 흡혈귀가 되면 긴 잠 나이는 `78 + 30 = 108`세다(7.6절). 반대로 흡혈귀가 된 뒤에는 F02가 제시되지 않는다.
- R03 `별잠 물병`은 **1회용**이다(D30, 08). 한 번 쓰면 빈 병 기념품이 되고 다시 채워지지 않는다. 쓰지 않은 R03을 유품으로 이어받으면 후계자가 그 1회를 쓸 수 있다(12의 잠재 상태 규칙은 그대로 적용). 매 세대 다시 채워지지 않으므로 계승 강화가 쌓이지 않는다.

## 7 흡혈귀 — TM01 달의 갈증

### 7.1 변이 시점

F03 `마지막 잔을 권하는 성주`에서 `잔을 받는다`를 고르면 즉시 변이한다. 제시 조건은 01 §12.3(35~64세, 모험적 또는 도전적 태도로 A4 진입, 생애 1회. D27)이다. 변이는 **명시적인 사용자 선택**으로만 일어난다. 사전 방침으로 자동 수락되지 않는다.

**선택 창 고지(D28)**: F03 선택 창의 `잔을 받는다`에는 아래를 빠짐없이 적는다. 문구 원문은 11 F03이 정한다.

| 구분 | 반드시 적을 내용 |
| --- | --- |
| 알려진 이익 | 밤 출정 명중 +1·피해 +10%·숨 고르기 회복 2배(7.3절), 힘·민첩·의지 +1, 이후 노화 능력치 감소 없음(7.2절) |
| 알려진 대가 | 낮 출정 모든 판정 −2·피로 +50%(7.3절), 치료소 대신 피의 휴식(7.4절), 사교 −1, **갈증이 100이 되면 {sleep_age}세 전에도 긴 잠에 든다**(7.5절) |
| 되돌림 | 되돌릴 수 없다. 이번 생애에만 적용되고 다음 세대에 이어지지 않는다 |
| 생애의 끝 | 긴 잠 예정 {sleep_age}세(7.6절) |

### 7.2 능력치

| 항목 | 변화 |
| --- | --- |
| 즉시 보정 | 힘 +1, 민첩 +1, 의지 +1, 사교 −1(최저 1) |
| 자연 상한 | 힘·민첩 9(인간 8). 지식·의지·사교·행운은 8 유지 |
| 노화 | 변이 이후 60세·70세·80세 능력치 감소를 적용하지 않는다. 이미 적용된 감소는 되돌리지 않는다 |
| 회복 계수 | 밤 출정 1.0, 낮 출정 0.7, 마을 0.9(나이와 무관) |
| 최대 HP | 공식은 그대로(01 §2.5). 변이 보정으로 오른 힘만큼 늘어난다 |

### 7.3 밤과 낮 (D11)

| 항목 | 인간 | 흡혈귀 |
| --- | --- | --- |
| 출정 시간대 확률 | 낮 70 / 밤 30 | 낮 20 / 밤 80 |
| 밤 출정 | 적 레벨 +1, 은밀·매복 +2, 시야 탐색 −1(01 §1.2) | 인간과 같은 보정 + 명중 +1, 피해 +10%, 숨 고르기 회복 ×2(8%), 시야 탐색 불리 없음 |
| 낮 출정 | 보정 없음 | 모든 판정 −2, 피로 획득 +50%, 회복 계수 0.7, 갈증 +5 |

- 사용자가 목적지를 고정해도 시간대 확률은 위 표를 따른다. 굶주림 단계(7.5절)에서는 밤 100%다.
- 낮 출정 기본 창 한 줄 예: `[이동] 햇빛이 따가워 {name:은/는} 그늘로만 걸었다.`

### 7.4 마을 이용 제약

| 시설 | 흡혈귀 규칙 |
| --- | --- |
| 여관 '도토리 모자' | 방을 쓰지 않는다. 대신 **여관 지하 저장고 휴식**: 비용은 여관비와 같고 시간 120초, 효과는 여관 휴식과 같다 |
| 대장간·잡화점 | 밤 출정에서 돌아왔을 때는 정상. 낮 출정에서 돌아오면 가격 +20%(문 닫기 직전 서둘러 거래) |
| 치료소 | 치료를 받지 않는다. 중상은 **피의 휴식**(마을, 유효 진행 6분, 무료, 갈증 +20)으로 치유한다. 경상은 자연 회복 또는 붕대 |
| 길드 출장소 | 정상 이용 |
| 생활 사건 | L23 생일 잔치는 `조용한 생일`(여관 지하에서 촛불 하나)로 바뀐다. L21 교관 대련은 밤에만 열린다 |

### 7.5 갈증

갈증은 0~100의 수치다. 변이 시 0에서 시작한다. **출정 중에만 오른다.** 마을 대기·정비·휴식·치료, 선택 대기, 일시정지, 계승 대기 중에는 오르지 않는다.

| 증가 | 값 |
| --- | --- |
| 출정 중 유효 진행 1분마다 | +2 |
| 낮 출정 1회 시작 시 | +5 |
| 피의 휴식(중상 치유) | +20 |

| 감소 | 값 |
| --- | --- |
| 밤 출정 중 전투 승리 1회(적 계열 무관) | −3 |
| 정예·보스 격파(시간대 무관) | −15 |
| CP08 **달빛 포도주** 1병 | −25 |

- CP08은 08이 소유하는 흡혈귀 전용 소모품이다. 가격, 판매처, 자동 구매 목표, 자동 사용 기준은 08을 따른다. 다른 소모품처럼 가방 칸을 차지하지 않는다(01 §2.5).

| 단계 | 수치 | 효과 | 기록 |
| --- | --- | --- | --- |
| 평온 | 0~39 | 없음 | — |
| 목마름 | 40~69 | 사교 판정 −1 | `[특성] 목이 말랐다. 달이 뜨기를 기다렸다.` |
| 굶주림 | 70~89 | 모든 판정 −1, 밤 출정 100%, 마을 사건 L02·L09·L22 차단 | `[특성] {name:은/는} 사람들 곁에 오래 머물지 않았다.` |
| 한계 직전 | 90~99 | 굶주림 효과 + **중요 표식**: 사용자에게 `은둔을 준비할까요?` 선택 제시(무시하면 계속 진행) | `[중요] 갈증이 한계에 가까워졌다.` |
| 한계 | 100 | 즉시 다음 판단 지점에서 귀환 시작, 마을 도착 시 **S08 긴 잠**(갈증의 한계) | `[중요] {name:은/는} 더는 견딜 수 없었다.` |

**기대 흐름** (07의 출정 길이와 전투 수, 모험적 활동 비중 30 / 45 / 25 기준)

| 출정 | 평균 길이 | 증가 | 감소 | 출정당 변화 |
| --- | --- | --- | --- | --- |
| 밤 사냥 | 10분, 전투 승리 9.5회 | +20 | −28.5 | **−8.5** |
| 밤 모험 | 7분, 전투 승리 1.5회 | +14 | −4.5 | +9.5 |
| 밤 던전 | 10분, 방 전투 승리 2.5회, 관문 30% | +20 | −7.5 − 4.5 | +8.0 |
| 낮 출정(종류 무관) | 9분, 감소 없음 | +5 + 18 | 0 | **+23** |

- 밤 출정만 가중 평균하면 출정당 약 +3.7이다. 사냥 비중이 큰 운영은 갈증이 내려가고, 모험·던전 비중이 크면 천천히 오른다.
- 흡혈귀 기본 시간대(밤 80%, 7.3절)로 섞으면 출정당 약 +7.6, 유효 진행 1시간(출정 약 4회)에 약 +30이다.
- 08의 CP08 자동 사용(갈증이 높아지면 1병 −25)으로 약 50분마다 1병을 쓰면 갈증은 **40~70 사이에서 오르내리고 100에 닿지 않는다.** 표준 운영의 비용은 레벨 기준 단계 회복약 2병 값 정도다.
- 갈증이 100에 닿는 경우: 사용자가 낮 위주로 몰거나(굶주림 전까지 시간대 확률은 7.3절을 따른다), 중상이 잦아 피의 휴식(+20)을 반복하거나, 동전이 모자라 CP08을 사지 못할 때다. 이 경우 90 이상에서 `은둔을 준비할까요?` 표식이 먼저 뜬다.

### 7.6 긴 잠 — S08

| 항목 | 규칙 |
| --- | --- |
| 정해진 시점 | min(변이 시점의 은퇴 예정 나이 + 30, 118)세. 표준 68세 인물은 98세, F02 연장(78세) 인물은 108세 |
| 갈증의 한계 | 갈증 100 도달 시 정해진 시점보다 먼저 긴 잠 |
| 자발적 은둔 | 마을에 있을 때 사용자가 `은둔한다`를 고르면 긴 잠(조기 은퇴와 같은 확인 절차, 3.3절 문구의 `은퇴` → `긴 잠`) |
| 도달 처리 | 은퇴와 같다(3.1절 표). 새 출정 금지 → 귀환 → 마을 도착 시 S08 |
| 계승 취급 | 은퇴와 같다. 유품 2개, 돈 20% 이전(12 문서) |
| 장소 | **달그늘 지하**. 마을에서 출발해 길바뀜의 틈을 지나 달그늘 영지 지하의 잠자리로 간다(이동 연출만, 유효 진행 없음) |
| 연출 | `잠` 동작 → 머리맡에 잔을 두고 촛불이 꺼짐(등불 소등 효과 재사용) → 달빛 효과 한 번 |
| 한 줄 기록 | `[은퇴] {name:은/는} 낡은 잔을 머리맡에 두고 긴 잠에 들었다.` |

- 긴 잠 예정 나이는 인물 탭에 `긴 잠 예정 98세 ☾`로 항상 표시한다(v0.1 §10.4, 선택 화면에서도 알림).
- 긴 잠 이후 레벨 상한 30은 그대로다. 흡혈귀라도 레벨 30을 넘지 않는다.
- 긴 잠 뒤 계승 2단계에서 생애의 책을 엮는다(18 §2.1). 이 책은 닫는 문장으로 끝나지 않은 잠을 알린다.

### 7.7 장비 상호작용

| 장비 | 흡혈귀 규칙 |
| --- | --- |
| R04 `성주의 은잔` | 저주 불리(낮 출정 피로 +20%)가 적용되지 않고 이익(밤 출정 피해 +20%)만 남는다. 흡혈귀 밤 피해 +10%와 더해 +30% |
| 은 계열 장비(W08 `은빛 광맥 장검`) | 흡혈귀도 쓸 수 있다. 다만 착용 중 사교 판정 −1(은에 닿는 불편함). 08 §7 장비 평가에서 흡혈귀는 W08 점수 −10% |
| 그 밖의 장비 | 변화 없음 |

- F03은 생애 1회이므로 한 생애에서 `거절 → R04 획득`과 `수락 → 흡혈귀`를 모두 겪을 수 없다. **부모가 거절하고 남긴 R04를 유품으로 받은 후계자가 흡혈귀가 되는 경우**에만 R04와 TM01이 함께한다. 이 조합은 12 §7.5의 별칭 1순위(`{parent_call}의 잔을 비운 {name}`) 후보가 된다.

### 7.9 가정과 자녀

- 변이 이전에 생긴 가정과 자녀 후보는 그대로 유지한다.
- 변이 이후에는 S01 가정 형성과 S02 아이 소식이 일어나지 않는다. 가정이 없으면 후계자는 방계 또는 입양 후보가 된다(12 문서).

- 긴 잠에 든 인물은 후계자 생애 중 한 번, 후계자가 35세 이후 A4에 처음 들어갈 때 `달그늘에서 온 편지`를 보낸다(가문 플래그 `fam.f03_accepted`, 12 §7.6):

- 달그늘에서 온 편지는 잠든 인물 책의 후기가 된다(18 §3.6).
